## 摘要
随着大语言模型（LLM）智能体的日益普及，网络管理员和安全团队需要在不检查用户私密内容的情况下，审计组织网络内的智能体行为。网络流量提供了一种可观测的证据来源，但其能在多大程度上揭示智能体任务与操作仍不清楚。现有流量数据集缺乏评估这一问题所需的联合任务与阶段标注。我们提出 ANT（Agent Network Traffic），该数据集在提供网络流量的同时，还提供风险、场景和行为基元粒度上的智能体行为信息。ANT 包含跨 20 个任务和 5 个场景的 3,114 个执行片段，涵盖 276,417 条双向流和 40,049 个行为基元片段，并组织为 47 个宏组。我们使用 13 个具有代表性的流量分析基线方法，建立了面向智能体风险识别、场景识别和行为基元分类的基准。结果表明，现有方法能够恢复出有用但不均衡的行为信号。当恶意工作流与良性任务相似时，它们难以识别风险；对于流量模式相似的场景，它们也难以区分。与稀有或语义相似的宏组相比，行为基元分类在频繁出现的宏组以及具有独特流量模式的宏组上更为可靠。ANT 为基于网络流量开发更精确的智能体行为审计与取证分析提供了共同基础。我们的数据和代码可在 https://anonymous.4open.science/r/ant-main-suite-7BC0/ 获取。

## Abstract
The growing adoption of large language model (LLM) agents creates a need for network administrators and security teams to audit agent behavior within organizational networks without inspecting private user content. Network traffic offers an observable source of evidence, but how much it reveals about agent tasks and operations remains unclear. Existing traffic datasets lack the joint task and stage annotations needed to evaluate this question. We introduce ANT (Agent Network Traffic), a dataset providing agent behavior information at risk, scenario, and behavior primitive granularities alongside network traffic. ANT contains 3,114 execution episodes across 20 tasks and five scenarios, comprising 276,417 bidirectional flows and 40,049 behavior primitive segments organized into 47 macro groups. We establish a benchmark for agent risk identification, scenario recognition, and behavior primitive classification using 13 representative traffic analysis baselines. The results show that existing methods recover useful but uneven behavioral signals. They struggle to identify risk when malicious workflows resemble benign tasks and to distinguish scenarios with similar traffic patterns. Primitive classification is more reliable for frequent macro groups and those with distinctive traffic patterns than for rare or semantically similar groups. ANT provides a common basis for developing more precise auditing and forensic analysis of agent behavior from network traffic. Our data and code are available at https://anonymous.4open.science/r/ant-main-suite-7BC0/.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

构建一个**多粒度**的智能体网络流量数据集与基准，将可观测的包级流量与高层智能体语义（风险、场景、行为原语）通过时间线对齐，从而系统评估"流量 → 行为"的可推断性。

### 2.2 数据采集系统

- **部署架构**：跨地理分布式云服务器（国内 + 海外阿里云服务器）的自动化采集基础设施，总采集成本 US$2,176.50。
- **采集流程**：每个任务实例初始化独立虚拟网络命名空间 → 提供自然语言任务提示 → 启动智能体 → 智能体解释任务、查询模型、调用工具（Web 搜索、Shell 命令等）→ 记录模型调用、工具调用、工具输出、会话状态及时间戳 → `tcpdump` 同步抓取 PCAP 格式的全量入站/出站包。
- **环境控制（保证数据纯度与伦理）**：
  - 每个任务实例运行于独立虚拟网络命名空间，防止并发任务干扰。
  - 智能体只能访问其活动工作区和必要运行环境，防止"读取预存答案"等捷径。
  - 仅使用公开基准输入，无真实用户账号、私密通信或 PII。
  - 良性状态变更交互针对本地模拟服务；攻击执行隔离在 Docker 环境中。
  - 攻击代码生成仅使用 Meta PurpleLlama 公开释放的变异提示，不添加越狱、提示混淆或安全绕过策略，并排除纯拒绝型片段。

### 2.3 行为原语标注

- **边界划分**：按到达时间戳排序 PCAP 包，以会话日志中各行为原语的起始时间为边界分箱；跨边界的传输流包被逐包分配到对应段。
- **语义标注**：使用 **DeepSeek-v4-pro** 从对齐的日志证据中推导行为原语并分配标签（标注提示见附录 B.1）。第一个记录原语之前的流量保留为独立的"前奏（prelude）"段。
- **宏组合并**：用 **Jina Embeddings v5** 编码全部 3,295 个不同原语标签，采用**球面 K-means（余弦 K-means++ 初始化）**聚类，基于余弦轮廓系数、种子稳定性和最小组合规模选择 **K=47**，每个原语恰好归入一个宏组。

### 2.4 场景凝聚力分析（统计方法）

- **分布几何**：用**最大均值差异（MMD）** 在连续语义空间比较原语嵌入分布，核函数为多带宽高斯核（σ²=0.9569 由语料级中位数确定）；用 **Hellinger 距离** 比较离散宏组比例；用 **Sliced-Wasserstein 距离**（512 个方向）从最优传输角度验证。
- **序列结构**：用**二阶路径签名**的反对称分量（定向面积）捕捉语义排序信息；用**转移残差矩阵**（观测转移频率减去均匀排列下的精确期望）的对称/反对称分解刻画相邻偏好与方向偏好。
- **统计检验**：9,999 次场景标签随机重分配置换检验；1,999 次片段重采样估计执行变异性；所有主检验用 Holm 程序校正。
- **信息分解**：将原语宏组组成的经验变化分解为场景、场景内任务、任务内片段三个加性成分（条件互信息恒等式）。

### 2.5 基准设计

三个渐进细粒度的评估目标：
1. **风险识别**：判断智能体活动是否恶意（二分类，片段级）。
2. **场景识别**：识别智能体活动场景（五分类，片段级）。
3. **行为原语分类**：将每个行为原语段分类到 47 个宏组之一（段级）。

## 6. 主要结论与发现

### 6.1 风险识别
- 全部 13 个基线准确率 > 90%，但**超过半数召回率 < 50%**，AWF 和 FlowLens 仅 15% 和 20%。
- 恶意代码生成和沙箱逃逸：YaTC、NetMamba、TFusion、TrafficFormer 检测率为 **0.000**；Web 渗透检测率接近 1.000。
- **原因**：Web 渗透有直接网络交互（扫描、SQL 注入、XSS）留下独特流量线索；恶意代码生成和沙箱逃逸依赖代码内容和执行意图，加密后流量与正常编码任务高度相似。
- **结论**：意图不直接体现在流量中、且执行过程类似良性操作的攻击，是基线能力差距最大的地方。

### 6.2 场景识别
- 准确率范围 0.431–0.727，NetMamba 最佳（0.727）。
- 无基线在全部 5 个场景中均领先召回；加密流量分类器在 GKQA 和 IAO 上更好，WF 方法在 CAE 和 CM 上更好。
- **主要混淆**：科学证据评估与知识问答互相混淆（35.1% 的 SEA 被误判为 GKQA，22.8% 反之），两者共享检索、推理、答案生成流程，模型后端流量占比相近（57.44% vs 58.60%）。
- **流量范围消融**：仅模型调用平均提升 5.56 个百分点；去除模型调用平均降低 4.31 个百分点；其余流量仍支持 0.392–0.627 的准确率。
- **段清除消融**：清除代表性段平均降低 6.95 个百分点，清除非代表性段仅降低 3.77 个百分点。
- **结论**：相似场景仍难区分；模型调用携带强场景信号，任务对齐的行为原语段提供额外线索。

### 6.3 行为原语分类
- 8 个 WF 基线整体准确率 0.355–0.462，但组间差异巨大，单基线内召回可从 0.000 到 0.900。
- 最频繁的 10 个组占 72.44% 的测试段，却贡献 91.34%–96.09% 的正确预测。
- 语义相似组混淆严重：37/204 的 browser fetch 被预测为 search；527 个 search 中 38 个被预测为 api query、35 个为 browser fetch。
- **结论**：流量对原语宏组有预测信号，但现有基线对频繁组和流量模式独特的组更可靠，对稀有或语义相似组表现差。

### 6.4 场景凝聚力
- 场景内不同任务的原始嵌入 MMD 距离比跨场景对**小 15.46%**（p=0.0006），Hellinger 距离小 14.79%（p=0.0050）。
- 定向面积和转移残差的距离缩减分别为 6.74% 和 5.70%，其凝聚力增益超过保组成随机重排均值 5.77 和 5.24 个百分点（Holm 校正 p=0.0050）。
- 信息分解：场景成分 0.7703 bits，占总经验组成变化的 34.86%。

## 8. 缺点与局限

- **单一数据集内评估**：所有基准均在 ANT 自身划分上完成，未在独立采集的新数据或第三方智能体流量上做跨数据集泛化验证，模型是否学到"智能体通用流量模式"还是"ANT 采集环境特有条件"难以区分。
- **恶意样本与稀有类样本量偏小**：测试集仅 20 个恶意片段，风险识别的召回率、FPR 等指标置信区间较宽；部分行为原语宏组测试样本仅 2 个（如 N009、N047），类级召回几乎不可靠，报告的单类召回应谨慎解读。
- **攻击类型覆盖有限**：网络安全滥用场景主要围绕代码生成、解释器滥用、Web 渗透三类，缺少横向移动、数据外泄、持久化、供应链投毒等更丰富的攻击链；且攻击代码仅来自公开变异提示、未使用越狱或混淆策略，可能低估真实攻击者的规避能力。
- **采集环境的可控性 vs 真实性张力**：本地模拟服务、Docker 隔离、独立网络命名空间虽保证数据纯度与伦理，但也意味着流量缺少真实企业网络中的并发干扰、中间盒、代理、CDN、重传与拥塞等噪声，分布可能与生产环境存在差距。
- **智能体配置与模型后端有限**：5 种智能体配置、若干模型后端（DeepSeek、Qwen、Codex、Sonnet、MiMo），无法覆盖快速演进的智能体框架与工具生态；流量模式对具体工具链、SDK、HTTP 库高度敏感，配置迁移后结论可能变化。
- **输入特征仅限包头与侧信道**：屏蔽 IP 等标识字段防止捷径学习是合理的，但也放弃了 TLS 元数据、SNI、证书、端口等可能有用的弱标识特征，可能低估真实审计场景中可用的信息量。
- **基准任务定义的可操作性**：行为原语由 LLM（DeepSeek-v4-pro）从日志推导，标签质量依赖标注模型能力；虽然 47 个宏组由球面 K-means 与轮廓系数选定，但"语义相似组混淆"（如 search 与 browser fetch、api query）本身也反映宏组边界可能不够清晰。
- **未报告算力与训练成本细节**：论文给出硬件与轮数，但未报告各基线总 GPU 小时、训练时长、能耗，削弱了训练成本维度上的可比较性。
- **消融范围有限**：流量范围与段清除消融仅针对 8 个 WF 基线，未在加密流量分类基线上复现，结论的普适性有待检验。
- **统计与实用性的落差**：场景凝聚力分析显示统计显著（MMD 缩减 15.46%、p=0.0006），但场景识别准确率上限仅 0.727、原语分类上限 0.462，说明"分布可分"与"分类器可用"之间仍有明显鸿沟，论文对如何弥合该鸿沟的讨论较少。

## 9. 启示与未来方向

- **审计粒度应分层设计**：ANT 的三级任务（风险—场景—原语）表明，粗粒度风险识别相对容易（准确率 >90%），但细粒度行为归因困难。实际部署中应避免承诺"从流量精确重建智能体行为"，而应聚焦"异常信号 + 上下文关联"。
- **区分"流量可见型"与"意图隐藏型"攻击**：Web 渗透类攻击因网络交互丰富而可检测，代码生成与沙箱逃逸类攻击则几乎不可见。这提示审计系统需要与终端侧、代码仓库、进程监控等多源信号融合，而非仅依赖网络。
- **模型调用是强场景信号**：仅用模型调用流量即可平均提升 5.56 个百分点，说明对智能体而言，LLM API 流量的时序与包长模式是场景判别的核心。未来可围绕模型调用的流量指纹开展专门建模。
- **行为原语标注可作为通用中间表示**：47 个宏组为"流量—语义"桥接提供了可复用的中间层。若能在更多智能体框架上验证其稳定性，有望成为跨系统的行为审计通用标签体系。
- **统计方法学贡献可迁移**：路径签名、转移残差、MMD/Hellinger/Sliced-Wasserstein 的组合分析框架，不仅适用于智能体流量，也可迁移到其他"序列—语义"对齐任务的分布比较中。
- **待探索方向**：
  - 跨环境、跨智能体框架、跨模型的泛化评估；
  - 引入更丰富的攻击链与规避策略，测试检测鲁棒性；
  - 探索半监督/自监督方法缓解稀有类样本不足；
  - 融合网络与终端、日志、代码仓库的多模态审计；
  - 研究对抗条件下（流量填充、分片、时序扰动）基线的性能退化。

## 10. 总体评价

ANT 是一篇定位清晰、工程扎实、标注体系完整的数据集与基准论文。其核心贡献不在于提出新的分类算法，而在于**首次系统性地把"客户端 LLM 智能体的执行语义"与"包级加密流量"通过共享时间线对齐**，并配套了 47 个行为原语宏组、三大评估任务、13 个基线和多角度统计检验。论文在伦理与环境控制上的严谨性、在统计方法上的多样性、在消融实验上的针对性，均高于同类数据集论文的平均水准。

其主要短板在于：恶意样本与稀有类样本偏少、攻击类型覆盖有限、仅在自身数据集内评估、采集环境与生产环境存在差距。这些局限不影响其作为"智能体流量审计首个共同基础"的价值，但意味着后续研究必须在泛化性、鲁棒性和多模态融合上继续推进。总体而言，ANT 为智能体治理与取证研究提供了一个高质量、可复现、可扩展的起点，其"多粒度标注 + 严格时间对齐 + 分层评估"的范式值得后续数据集工作借鉴。
