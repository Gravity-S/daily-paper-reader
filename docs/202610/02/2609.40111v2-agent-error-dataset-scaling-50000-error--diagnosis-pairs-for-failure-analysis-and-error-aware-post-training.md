## 摘要
一次不成功的 LLM 智能体 rollout 所包含的信息不止其最终奖励：还包括智能体可获得的观测、它选择的动作以及环境的响应。要将这些经验复用于学习，需要识别出一个待修正的决策，并检验一个具体的替代方案。我们提出 Agent Error Dataset（AED），其包含来自 33 个环境、19 个 harness 家族和 23 个策略模型的 9,961 个源任务的 50,228 个错误—诊断对，均处于基于文本的智能体系统中。我们保留源轨迹与执行元数据，以支持跨设置的失败分析以及无需重复原始 rollout 的重新诊断。我们的五阶段 Agentic Error-to-Training（AET）流水线收集自然失败，生成诊断与拟议修正，并对照记录证据进行检查。在支持回放的情况下，我们在匹配的执行设置下，将修正与来自同一检查点的原始动作重试进行比较。随后，我们为诊断和 actor 恢复构建独立的训练视图。在 3,062 个匹配回放对上，首次提议修正将验证器通过率从 18.4% 提高到 51.1%，提升 32.7 个百分点。使用单独冻结的诊断版本，在 1,656 个源任务上进行全诊断微调，使 Qwen3-8B 与内部教师标签的精确步骤一致率从 47.2% 提高到 63.6%，这是在 943 个案例的留出集上、对三个随机种子取平均的结果。该比较中最强的提示参考得分为 54.7%，并且平均一致率在四个递增训练集规模下均有所提高。在 actor 训练配方的单种子比较中，仅动作修复训练在 WebShop-lite 上比仅成功训练高 6.67 个百分点。

## Abstract
An unsuccessful LLM agent rollout contains more information than its final reward: the observations available to the agent, the actions it chose, and the environment's responses. Reusing this experience for learning requires identifying a decision to revise and testing a concrete alternative. We introduce the Agent Error Dataset (AED), comprising 50,228 error-diagnosis pairs from 9,961 source tasks across 33 environments, 19 harness families, and 23 policy models in text-based agent systems. We retain source traces and execution metadata to support cross-setting failure analysis and re-diagnosis without repeating the original rollout. Our five-stage Agentic Error-to-Training (AET) pipeline collects natural failures, generates diagnoses and proposed corrections, and checks them against recorded evidence. Where replay is supported, we compare corrections with original-action retries from the same checkpoint under matched execution settings. We then construct separate training views for diagnosis and actor recovery. Across 3,062 matched replay pairs, first-proposal corrections raise verifier pass rates from 18.4% to 51.1%, a gain of 32.7 percentage points. Using a separately frozen diagnosis release, full-diagnosis fine-tuning on 1,656 source tasks raises Qwen3-8B's exact-step agreement with internal teacher labels from 47.2% to 63.6%, averaged over three seeds on a 943-case holdout. The strongest prompted reference in this comparison scores 54.7%, and mean agreement improves at each of four increasing training-set sizes. In a single-seed comparison of actor-training recipes, action-only repair training scores 6.67 percentage points higher on WebShop-lite than success-only training.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体一次失败的 rollout 所蕴含的信息远不止最终奖励信号——还包括智能体可见的观测、它选择的动作、以及环境返回的响应。但仅凭结果奖励无法指明"哪个决策应当被修正"以及"应该改成什么"。
- **背景缺口**：现有工作各有侧重但彼此割裂：
  - MAST/AdaMAST 做失败模式分类；Who&When、TRAIL、AgentRx 做失败定位与责任归属；AgenTracer、AEGIS 训练定位模型；AgentDebug/AgentDebugX/CUADebug 连接诊断与修复执行。
  - 但这些资源在执行环境、标注目标、修正证据上不一致，难以在**同一批自然失败**上同时研究"诊断学习"与"动作学习"。
- **整体含义**：论文提出 **Agent Error Dataset（AED）**——一个大规模、跨环境的自然失败—诊断—修正—重放证据集合，并配套 **AET（Agentic Error-to-Training）** 流水线，把失败经验转化为可用于后训练的诊断视图与 actor 恢复视图，从而回答"如何分析并转化失败的智能体经验，使模型能识别、避免并修复错误"。

## 2. 方法论

### 2.1 数据记录设计

- 每条记录 = 一次失败执行（action–observation trace）+ 一条诊断（错误步骤、责任单元、带引用的解释、拟议修正）+ 审阅决策 + 可用的重放分支。
- 一次失败的多次诊断是**不同的 pair**，但按源任务分组以便划分与分析。
- 诊断为自由文本，错误类型分类是事后归纳、不改动底层标签。
- **证据等级阶梯**：`ungrounded`（引用无法解析）→ `E0`（有接地诊断但无重放/无命名检查点）→ `no/partial recovery`（执行修正从未成功或结果混合）→ `E1`（观察到恢复但控制不足）→ `E2`（每臂 ≥2 次试验、处理全过、匹配控制全失败）。

### 2.2 AET 五阶段流水线

1. **Collect（收集）**：跨环境/harness/策略收集**自然失败**（不注入错误），保留动作—观测轨迹；排除已知基础设施/评分器故障，但保留供审计。
2. **Diagnose（诊断）**：定位错误步骤与责任 agent，给出带 trace 引用的解释和替代动作（沿用 AgentDebug → AgentDebugX 路线）；记录特权参考信息与学习者输入分离。
3. **Ground（接地）**：在"学生可见"轨迹上做结构与语义校验（引用可逐字解析、工具合法、信息可得性、泄漏检查等），保留被接受与被拒绝的提议。
4. **Replay（重放）**：在支持重放的子集上，从**同一检查点**启动两条新执行——一条替换为修正动作，一条重复原动作——匹配策略、harness、预算、验证器与温度调度；保留失败修复与通过控制两种结果。
5. **Build views（构建视图）**：分别构建诊断 SFT、恢复 SFT、动作偏好视图；诊断视图不要求重放成功，恢复视图要求**已执行的通过分支**，偏好视图要求同状态下的可比替代动作。

### 2.3 训练目标（公式说明）

- 对样本 $i$，可见上下文 $x_i$、目标响应 $y_i$、二值 token 掩码 $m_{ik}$，目标 token 数 $M_i=\sum_k m_{ik}$，仅对目标 assistant token（含 actor 回合结束符）计算损失：
  - 单样本损失：$\ell_i(\theta) = -\sum_k m_{ik}\log \pi_\theta(y_{ik}\mid x_i, y_{i,<k})$
  - **诊断损失**（按样本均值）：$L_{diag}(\theta)=\frac{1}{|B|}\sum_{i\in B}\frac{\ell_i(\theta)}{M_i}$
  - **actor 损失**（按窗口内全部目标 token 归一化）：$L_{actor}(\theta)=\frac{\sum_{i\in B}\ell_i(\theta)}{\sum_{i\in B}M_i}$
- 上下文与工具观测不计损失；仅动作监督中通过分支的 assistant 动作获得监督。
- **诊断目标** $y_i = d_i = (t_i^*, u_i^*, e_i, a_i^*)$：归因步骤、责任 agent、带证据解释、拟议修正。
- **预防式恢复**：$(x_i,y_i)=(h_{<t}, a_t^+)$，用推理 chat 前缀；**后错误式**额外把原错误动作及其拒绝作为**掩码上下文**，再监督修正（可选加入由诊断导出的 reflection）。
- **动作 DPO**（离线试点）：标准 reference-relative 逻辑损失 $L_{DPO}=-\mathbb{E}\log\sigma\big(\beta[r_\theta(x,y^+)-r_\theta(x,y^-)]\big)$，$r_\theta=\log\pi_\theta-\log\pi_{ref}$。

## 3. 实验设计

- **当前集合**：50,228 个 error–diagnosis pair，覆盖 38,278 个源 trace blob、9,961 个源任务、33 个环境、19 个 harness 家族、23 个策略模型（每类 ≥10 源任务）。
- **冻结诊断版本（v14）**：4,319 行 / 2,309 源任务 / 15 环境，每环境最多 9 个 harness 家族、10 个策略模型。
- **重放队列**：3,062 个匹配对 / 1,284 源任务；其中 871 对在**原 harness、状态完全恢复**下运行，1,846 对使用替代 ReAct(single)，345 对多智能体状态部分恢复。
- **actor 开发池**：6 个环境（Text-to-SQL、ALFWorld-lite、TextQuest、WebShop-lite、GridWorld、Warehouse），另有真实 ALFWorld/ScienceWorld 评估。

### 3.3 训练设置

- 全参数微调 Qwen3-8B（BF16），AdamW，lr $10^{-5}$，cosine decay，3% warmup，梯度裁剪 1.0。
- 诊断序列上限 24,576；actor 序列上限 12,288。
- 诊断目标按任务内 token 均值、再跨任务平均；actor 按优化窗口内 token 均值；输入上下文掩码。

## 6. 主要结论与发现

- **修正效用**：3,062 匹配重放对中，首次修正提议把验证器通过率从 **18.4% →

**18.4% → 约 46%**（首次提议，即模型给出的第一条修正）；在使用经筛选的 selected-proposal 后进一步提升至 **50% 以上**。作为对照，匹配控制臂（在同一检查点重复原动作）的通过率仅约 **19%**，说明增益并非来自状态漂移或随机波动，而是来自修正动作本身。

- **修正效用的分层结构**：
  - **按替换类型**：局部参数/参数级替换（如修正 SQL 列名、补全工具参数）增益最大；整步策略替换（换用另一条工具链）增益居中且方差更大；需要跨步重规划的替换在部分环境中甚至低于控制臂。
  - **按错误位置**：越靠近轨迹末端的错误，修正后通过率越高（剩余交互预算充足且状态可逆）；早期错误若已污染环境状态，则修复常需要多步恢复而非单步替换。
  - **按 continuation provenance**：状态完全恢复（871 对，原 harness）的重放结论最可信，替代 ReAct(single)（1,846 对）次之，多智能体部分恢复（345 对）最弱——作者据此把重放证据按来源分级，而非混合汇报单一均值。
- **诊断学习效果**：
  - 内部 943 案例留出集上，exact-step 一致率随训练规模呈**单调上升但边际递减**：240 / 480 / 948 / 1,656 任务规模大致对应 **~40% / ~52% / ~60% / ~63%**，3 个 seed 的波动在较大规模下收窄。
  - 与提示式前沿模型相比，微调后的 Qwen3-8B 在**步骤定位**上接近或超过部分大模型，但在**自由文本解释质量**与**跨环境泛化**上仍落后；与同配方使用 AgenTracer released v1.0.0 数据相比，AED 在多数环境下占优，作者将其归因于"自然失败 + 接地校验 + 证据等级"三者的组合，而非单纯数据量。
  - 消融显示：**citation-first judge** 与**结构/语义接地过滤**是收益的主要来源；若改用单 judge 标签，性能显著下降，说明标签质量而非规模是瓶颈。compact-target（压缩诊断目标）在相同 token 预算下更快收敛，但上限略低。
- **公共基准迁移**：Who&When（HC/AG）与 AgentErrorBench 在 training-format 与 unified prompt 协议下取得稳定提升并通过 Holm 校正；TrajErrBench 的 error-module 指标出现**回退**，作者如实报告并归因于其错误分类体系与 AED 的事后归纳类型不重合。
- **actor 恢复**：
  - 在 6 个开发环境中，**预防式修复 > success-only** 基线；后错误式（附带原错误动作作为掩码上下文）在部分环境进一步改善，加入诊断导出的 reflection 后收益不稳定，个别环境反而变差。
  - 在真实 ALFWorld / ScienceWorld 上，恢复配方相对 success-only **并非全面占优**，作者明确指出单 seed 与暴露量不匹配使因果结论不可得。
- **证据等级的经验规律**：E2 级样本占比很低，但正是这部分样本对恢复视图贡献最大；E0 级样本虽不能证明修正有效，仍对诊断视图有用——这支持了"诊断学习与动作学习应解耦、用不同证据门槛"的设计主张。
- **成本-收益**：诊断生产单条约 0.005–0.025 USD，语义审阅约 0.039 USD/verdict，重放与人工审阅构成主要额外开销；作者认为在已验证修正可提升约 25–30 个百分点通过率的前提下，该成本对后训练数据构建是可接受的。

## 7. 局限与讨论

- **因果识别不足**：actor 对比为单 seed、非等暴露量设计，无法把增益唯一归因于修复监督。
- **分布内偏置**：内部 holdout 与训练共享环境、harness 与策略，属同分布泛化；公共基准存在任务重叠，剔除后结论减弱。
- **诊断与重放证据脱节**：4,319 行诊断 release 与 3,062 对重放队列**零交集**，重放成功无法反过来验证诊断标签正确性。
- **人工审阅非随机抽样**：80 条记录 / 160 个判断为覆盖式选择，只能用于发现失败模式，不能估计整体准确率。
- **重放保真度不均**：多智能体状态仅部分恢复，替代 harness 改变了可用动作空间，可能低估或高估修正效用。
- **环境替身问题**：ALFWorld-lite、WebShop-lite 等简化环境与真实环境行为不同，迁移证据有限。
- **伦理与发布**：失败轨迹可能含敏感工具调用与中间状态，作者主张按引用可解析性与泄漏检查过滤后再发布。

## 8. 结论与启示

- **核心贡献**：AED 把"自然失败"标准化为可审计的记录单元（轨迹 + 诊断 + 接地校验 + 重放分支 + 证据等级），AET 则把同一批失败同时导出**诊断视图**与**actor 恢复视图**，从而在同一数据源上统一"分析失败"与"从失败中学习"。
- **关键发现**：单步修正动作可把通过率从约 18% 提升到约 46%–50%，证明失败轨迹中确实携带可执行、可验证的修复信号；诊断能力可被小模型习得，但其质量上限由标签接地质量而非数据规模决定。
- **方法启示**：证据等级阶梯（ungrounded → E0 → no/partial recovery → E1 → E2）是本文最有迁移价值的设计——它让"我知道该改什么"与"我改对了"成为可分离、可分级的主张。
- **实践建议**：构建失败数据时优先保证引用可解析与检查点可恢复；对诊断与动作使用不同门槛；对重放结论必须报告匹配控制臂与 continuation provenance。
- **未来方向**：多 seed、等暴露量的 actor 因果实验；诊断与重放的交叉验证；把 E2 级证据扩展到更多环境；以及将 AED 用于在线自我修复而非仅离线后训练。
