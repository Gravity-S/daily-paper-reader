## 摘要
多智能体通信旨在帮助智能体从彼此的信息中获益。然而，系统性能的提升留下了一个根本性的模糊之处：这些提升究竟反映的是有效通信、有利的智能体架构，还是仅仅增加了推理？由于通信方法通常是在其为之设计的系统内部进行评估，这些因素难以被厘清。最终准确率进一步将已纠正的错误和受污染的答案合并为单一结果，从而掩盖了通信如何改变决策。我们提出独立—沟通—修正（Independent--Communicate--Revise, ICR），一个受控框架，将通信评估为独立推理之后的答案修订。ICR 固定初始推理轨迹，以两个智能体的初始正确性为条件来度量纠正与保持，并使用无消息修订对照来量化超出额外推理的增益。在四个推理基准上，我们对文本通信和潜在通信的审计揭示，相似的总体准确率可能掩盖显著不同的修订行为。与仅传递答案相比，完整推理在所有四个基准上都增加了纠正，同时降低了保持，因此更丰富的信息会同样放大有益和有害的影响。在 MedQA 和 GPQA-D 上的接收方策略比较进一步表明，结构化验证策略使每个通道都转向更高的保持和更低的纠正，而其对选择性的影响因通道和任务而异。这些发现挑战了将通信质量视为通道固有属性的观点。因此，ICR 将评估重新聚焦于选择性修订，为考察消息内容和接收方策略如何共同产生收益与危害提供了统一框架。

## Abstract
Multi-agent communication aims to help agents benefit from one another's information. Yet improvements in system performance leave a fundamental ambiguity: do they reflect effective communication, a favorable agent architecture, or simply additional reasoning? Because communication methods are commonly evaluated within the systems they were designed for, these factors are difficult to disentangle. Final accuracy further merges corrected errors and corrupted answers into a single outcome, obscuring how communication changes decisions. We introduce Independent--Communicate--Revise (ICR), a controlled framework that evaluates communication as answer revision following independent reasoning. ICR fixes initial reasoning trajectories, measures correction and preservation conditional on both agents' initial correctness, and uses a no-message revision control to quantify gains beyond additional reasoning. Across four reasoning benchmarks, our audit of textual and latent communication reveals that similar aggregate accuracy can conceal substantially different revision behaviors. Compared with transmitting answers alone, full reasoning increases correction while reducing preservation on all four benchmarks, so richer messages amplify beneficial and harmful influence alike. Receiver-policy comparisons on MedQA and GPQA-D further show that a structured verification policy shifts every channel toward greater preservation and lower correction, while its effect on selectivity varies across channels and tasks. These findings challenge treating communication quality as an intrinsic property of a channel. ICR therefore recenters evaluation on selective revision, providing a unified framework for examining how message content and receiver policies jointly produce benefits and harms.

# 论文总结：超越最终准确率——审计 LLM 多智能体系统中的通信

## 1. 核心问题与整体含义

- **研究动机**：多智能体系统（如辩论、角色协作、协调工作流）被广泛用于扩展 LLM 能力，通信形式也从显式文本扩展到隐藏状态与潜在工作记忆。然而，现有评估方式存在根本性模糊：
  - 系统性能提升无法归因于**有效通信**、**有利的智能体架构**还是**单纯增加推理**；
  - 通信方法通常在其原生系统内评估，这些因素难以解耦；
  - **最终准确率**将"已纠正的错误"与"被污染的正确答案"合并为单一结果，掩盖了通信如何改变决策。
- **核心问题**：通信能否在修正初始错误答案的同时，保护初始正确答案不被误导性同伴信息破坏？
- **整体含义**：作者主张通信质量不应被视为通道的固有属性，而应在**消息内容**与**接收方策略**共同作用下，以"选择性修订"为评价重心。

## 2. 方法论：独立—沟通—修正（ICR）框架

### 2.1 核心思想

- 将通信评估为**独立推理之后的答案修订**：智能体先独立解题，再在固定初始轨迹基础上接收同伴消息并决定是否修订。
- 通过**固定的初始轨迹、按双方初始正确性分层的指标、无消息修订对照**，将通信增益从"额外推理"中分离出来。

### 2.2 关键技术细节

- **独立生成与缓存**：对问题 q，n 个智能体独立产生记录 z_i = (r_i, a_i, h_i)，分别表示推理轨迹、答案、潜在通道所需表示。这些记录被冻结并在所有条件间复用。
- **有向对与单跳修订**：对每个问题构造所有 n(n−1) 个有序发送者—接收者对（实验用 3 个智能体，得 6 个方向）。修订答案不会传播到其他评估事件。
- **消息构造与投递**：对方向 S→R，条件 c 构造消息 m(c)_{S→R} = G_c(q, z_S)，可文本或潜在；接收方修订答案 a′(c,p)_R = F_{θ,p}(q, z_R; D_c(m(c)_{S→R}))，其中 D_c 为通道特定投递操作（文本插入、隐藏态注入、KV 前缀附加），p 为修订策略。
- **正确性标签隔离**：参考答案与正确性标签仅用于离线选择、分层与评分，绝不进入消息构造或修订过程。

### 2.3 审计指标与公式

- **四个初始正确性分层**（基于接收方与发送方初始是否正确）：
  - **CR（修正率）** = Pr(b′_R=1 | b_R=0, b_S=1)：初始错误接收方 + 正确发送方；
  - **PR（保持率）** = Pr(b′_R=1 | b_R=1, b_S=0)：初始正确接收方 + 错误发送方，1−PR 为污染率；
  - **SR** = Pr(b′_R=1 | b_R=0, b_S=0)：双方皆错时的恢复率；
  - **SCR** = Pr(b′_R=1 | b_R=1, b_S=1)：双方皆对时的保持率。
- **选择性指数**：SI = (CR + PR)/2，等价于 SI − 1/2 = [CR − (1−PR)]/2，以等权平衡修正与污染。分析参考点：始终保留初始答案 → (0, 1, 0.5)；始终复制发送方答案 → (1, 0, 0.5)，说明 SI 必须与 CR、PR 联合报告。
- **与聚合准确率的关系**：Acc_rev = w01·CR + w10·PR + w00·SR + w11·SCR，其中 w_rs 为初始状态占比。聚合准确率同时依赖修订行为与各初始状态的分布。
- **配对归因控制**：以无消息修订为对照，ΔAcc = (N_gain − N_loss)/N，其中 N_gain 为有通信正确、无通信错误的事件数，N_loss 反之。

## 3. 实验设计

### 3.1 数据集与场景

- **主实验（Qwen3-4B）**：MedQA、ARC-Challenge、GSM8K、GPQA-Diamond，附录含 HumanEval+。
- **保留总体**：仅保留至少一个智能体初始错误的问题，得 430 题、2,580 个有向事件（含 840 个混合正确性方向）。
- **附加模型（Qwen3-8B）**：MedQA 与 GPQA-D，使用模型特定的初始轨迹，各含 46/54 个混合正确性问题，每个 CR/PR 分层 92/108 个事件。

### 3.2 对比方法（通信条件）

- **No Message**：无同伴信息但保留修订机会（区别于 Keep Initial）；
- **Answer Only**：仅发送方归一化最终答案；
- **Full Text**：发送方完整后思考响应（推理 + 答案）；
- **StateBridge**：适配对齐隐藏态传输（最后一层解码器状态经白化正交 Procrustes 映射到输入嵌入空间后插入）；
- **LatentMAS**：适配发送方派生的潜在工作记忆，以全层 KV 缓存作为因果前缀。

### 3.3 接收方策略对比

- **Critical Evaluation**（主审计）：批判性评估先前推理与外部消息，仅在发现具体错误时修改；
- **Structured Verification**：先按序检查外部主张、再检查自身推理，基于幸存主张作答。
- 在 MedQA 与 GPQA-D 上比较，各含 116/114 个事件/分层。

### 3.4 统计方法

- 采用**问题聚类自助法**（bootstrap）重采样，保持同问题内的方向与条件配对；
- 边际区间用 2,000 次重采样，配对差异分析用 10,000 次；
- 全集合准确率（Acc.†）使用对未观测结果的假设进行估计，明确区分实测子集准确率与估计全集合准确率。

## 4. 资源与算力

- **GPU**：主运行清单记录使用 **4 块 NVIDIA RTX 5090（每块 32 GB 显存）**。
- **软件环境**：Python 3.12.3、Transformers 4.51.3、PyTorch 2.7.1、CUDA 12.8，bfloat16 精度。
- **生成设置**：温度 0.6、top-p=0.95、top-k=20，两阶段均启用 thinking，最终生成预算 16,384 新 token，全局种子 42。

## 5. 实验数量与充分性

### 5.1 实验规模

- **主审计**：Qwen3-4B 在 4 个基准（+ HumanEval+ 附录）上对比 5 种通信条件；
- **附加模型**：Qwen3-8B 在 MedQA、GPQA-D 上重复 5 种条件；
- **策略对比**：2 种接收方策略 × 2 个数据集 × 多个通道；
- **对照实验**：随机投递参考（匹配 PR 的混合策略）、配对增益/损失分析、答案身份转移分析、截断敏感性分析、6 方向明细、策略特定通信增量等。

### 5.2 充分性与公平性评估

- **优点**：
  - 控制变量严谨：固定初始轨迹、接收方模型与修订策略，仅改变消息内容或投递接口；
  - 分层指标避免了聚合准确率的混淆；
  - 配对自助法保留问题内依赖，不把 6 个方向当作独立观测；
  - 明确的消融（无消息 vs 随机投递 vs 内容条件）与敏感性分析。
- **局限**：
  - 主实验仅 Qwen3-4B 与 Qwen3-8B 两个模型规模，未覆盖更多模型家族；
  - MedQA 使用固定本地文件，原始子集选择与选项置换过程不可考；
  - 全集合准确率依赖对未观测结果的假设（非概率抽样）；
  - LatentMAS 与 StateBridge 是机制适配而非原生系统复现；

## 6. 主要结论与发现

- **相似准确率掩盖不同修订行为**：GSM8K 上估计全集合准确率跨度仅 0.11 个百分点，但通信条件间 PR 差距达 27.17 个百分点。聚合准确率因包含大量全对问题，无法追踪混合正确性对上的表现。
- **更丰富消息放大有益与有害影响**：相对 Answer Only，Full Text 在所有 4 个基准上提高 CR（+11.96 至 +41.84 个百分点），同时降低 PR（−15.79 至 −37.93 个百分点）。更频繁修订不等于更准确，修正增益可能被其他状态下的损失抵消。
- **双方皆错时恢复罕见**：通信条件下 SR 仅 0.30%–2.55%，多数低于 No Message；而双方皆对时 SCR 保持很高（Full Text 在所有评估对中 100%）。
- **接收方策略显著改变平衡**：Structured Verification 使所有通道转向更高 PR、更低 CR；对 SI 的影响因通道与任务而异（MedQA 上 StateBridge 下降、LatentMAS 上升）。
- **通信质量非通道固有属性**：通道的修订行为不能脱离消息内容与接收方策略来解读；通道相对排序在不同任务间不一致（如 MedQA/GSM8K 上 StateBridge 的 SI 最高，ARC-C/GPQA-D 上 Full Text 最高）。
- **配对增益有限**：MedQA 上 Full Text 净增益仅 +11/720，StateBridge +15/720；GSM8K 上 Full Text 为 −5、LatentMAS 为 −4。

## 7. 优点

- **评价范式创新**：将通信评估从"最终准确率"转向"选择性修订"，以 CR/PR 双维度揭示被聚合指标掩盖的行为差异。
- **受控实验设计**：固定初始轨迹、接收方模型与修订策略，配合无消息修订对照，有效剥离额外推理的贡献。
- **统一文本与潜在通信**：为文本消息与潜在消息（隐藏态注入、KV 前缀）提供共享的行为评估目标，无需将潜在内容解码为文本。
- **正确的统计实践**：使用问题聚类配对自助法，避免方向级独立假设，并明确区分实测与估计指标。
- **丰富的消融与对照**：随机投递参考、策略特定无消息基线、截断敏感性分析、答案身份与正确性分离分析，增强了因果解读的严谨性。
- **可复现性**：提供匿名代码，记录 prompt 哈希、配置指纹、逐记录种子，并公开完整 prompt 模板。

## 8. 不足与局限

- **模型与任务覆盖有限**：仅两个 Qwen3 模型规模，未验证其他模型家族；HumanEval+ 仅作附录补充，样本小、生成失败多。
- **数据与流程不可完全复现**：MedQA 原始子集选择与 GPQA-D 选项置换过程不可考，HumanEval+ 未使用官方 EvalPlus 评估工具。
- **全集合准确率估计依赖假设**：Qwen3-4B 对未观测方向进行外推，Qwen3-8B 假设未观测方向保持初始正确性，这些假设未经验证，且未报告置信区间。
- **潜在通信实现为适配而非原生复现**：StateBridge 与 LatentMAS 的消息构造、注入位置与计算成本被记录，但评估的是"消息—接口组合"而非方法完整工作流。
- **成本比较不完整**：LatentMAS 消息大小在导出中为零（与文档冲突），未建立跨通道可比的端到端成本。
- **部分结论统计不确定**：多个关键对比（如随机投递参考、通道×策略交互）的 95% 区间包含零，无法确立显著性或等价性；区间也未捕捉未观测生成种子的变异。
- **修订截断与解析失败**：部分记录因生成截断或无法解析被计为错误，可能影响特定分层估计（GPQA-D 敏感性分析显示 SI 在过滤后整体下降）。
- **应用限制**：框架聚焦单跳修订，不评估多轮反馈传播；对需要长链条协作的实际多智能体系统，结论外推需谨慎。
