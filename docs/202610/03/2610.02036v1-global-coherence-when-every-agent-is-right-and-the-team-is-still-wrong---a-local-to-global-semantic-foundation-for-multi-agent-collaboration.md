## 摘要
AI 智能体可以各自做出局部有效的决策，却共同产生无效结果。我们将此称为全局一致性问题：这是共享状态的失败，而不仅仅是模型智能的失败。我们的观测混叠不可能性定理给出了精确边界。一个策略能够保证有效动作，当且仅当所有产生相同观测的世界都共享一个可容许动作。如果 k 个不可区分的世界要求两两不相交的动作，那么最佳随机化最坏情况成功率为 1/k；更多的推理、角色、消息或样本都无法恢复缺失的区分。更强的模型可以在其上下文内更好地推理，但无法看到上下文之外。随后，我们给出局部到全局的运行时语义 X = (H, C, G, F; D)：拓扑 H 记录重叠的作用域；范畴 C 支配改变状态的动作；群胚 G 保留可逆转换；层 F 检验局部视图能否粘合为一个世界；最小历史 D 仅保留会改变合法未来的区分。模型提出建议；运行时框架拥有共享状态并管理提交。九项研究检验了该失败及其边界。在一个受控修订基准上，同一个前沿模型在决定性事件可见时得分为 40/40；当该事件被隐藏时，受测各组得分为 12--17/40，与随机水平（1/3）一致；恢复一个权威事实后得分回到 40/40。在 TeamBench 上，普通团队在 5/5 次运行中超出共享预算，可见的实时计数仍留下 4/5 次违规，而提交强制执行留下 0/5。在 tau2-bench Telecom 中，静默回滚后当前状态检查得分为 0.07，而运行时框架得分为 1.00。当传统求解器已经拥有完整的相关状态时，它如预测那样与运行时框架打平。反直觉的结论是，局部智能无法替代缺失的全局状态。

## Abstract
AI agents can each make locally valid decisions yet jointly produce an invalid result. We call this the global coherence problem: a failure of shared state, not merely of model intelligence.   Our Observation-Aliasing Impossibility Theorem gives the exact boundary. A policy can guarantee a valid action exactly when all worlds producing the same observation share an admissible action. If k indistinguishable worlds require pairwise-disjoint actions, the best randomized worst-case success is 1/k; more reasoning, roles, messages, or samples cannot recover the missing distinction. A stronger model can reason better within its context, but it cannot see beyond it.   We then give local-to-global runtime semantics X = (H, C, G, F; D): topology H records overlapping scopes; category C governs state-changing actions; groupoid G retains reversible translations; sheaf F tests whether local views glue into one world; and minimal history D keeps only distinctions that alter legal futures. Models propose; the harness owns shared state and governs commit.   Nine studies test both the failure and its boundary. On a controlled revision benchmark, the same frontier model scores 40/40 when the deciding event is visible; when it is hidden, tested arms score 12--17/40, consistent with chance (1/3); restoring one authoritative fact returns 40/40. On TeamBench, ordinary teams exceed a shared budget in 5/5 runs, a visible live count leaves 4/5 violations, and commit enforcement leaves 0/5. In tau2-bench Telecom, current-state checks score 0.07 after silent reverts, while the harness scores 1.00. Where a conventional solver already owns the complete relevant state, it ties the harness as predicted. The counterintuitive conclusion is that local intelligence cannot substitute for missing global state.

## 1. 核心问题与整体含义（研究动机和背景）

- 论文提出并命名了 **全局一致性问题（global coherence problem）**：在多智能体、人机协作或分布式系统中，每个参与者只看到局部状态，单步决策在本地看都合理，但组合结果违反某个全局规则或无法对应任何真实全局状态。
- 作者强调，这不是单纯的“模型不够强”问题，而是 **状态问题**：更强模型只能在其上下文内做更好的局部推理，不能看到上下文中不存在的信息，也不能保证局部有效的片段能拼成全局一致的世界。
- 两类核心失败：
  - **观测混叠（observation aliasing）**：两个不同世界产生相同观测/上下文，但需要不同甚至不相交的有效动作。此时任何只依赖该观测的策略都无法保证正确。
  - **局部一致但无法粘合（non-realizability / gluing failure）**：每个局部检查都通过，但局部片段之间不匹配，或共享约束无人拥有，导致没有单一全局状态能解释全部局部状态。
- 典型例子：TeamBench 中 Planner、Executor、Verifier 共享 20 次命令预算，每个 agent 的支出都合法，但团队总支出约三倍；τ2-bench Telecom 中用户和助手控制不同环境部分，普通当前状态检查会提交过期报价或忽略已提交变更被静默撤销。
- 论文的整体含义：多智能体可靠性不能只靠更强模型、更长上下文、更多角色、更多消息或更多采样；需要明确 **哪些区分必须被保留、哪些共享状态必须由运行时框架拥有、哪些变更必须在提交时检查**。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心分离：模型提议，harness 决定是否允许。**
  - 模型负责“提议智能”：解释意图、规划、选择工具、起草变更。
  - Harness/运行时负责“状态、可容许性与提交”：持有权威语义状态，检查提议，接受、修复或拒绝，只有被接受的变更才改变世界。
- **观测混叠不可能性定理（Observation-Aliasing Impossibility Theorem）**
  - 设世界集合 \(X\)，动作集合 \(A\)，观测映射 \(\Omega:X\to Y\)，可容许动作集合 \(C(x)\subseteq A\)。
  - 存在确定性策略 \(\pi\) 使得对所有 \(x\)，\(\pi(\Omega(x))\in C(x)\)，当且仅当每个观测纤维 \(\Omega^{-1}(y)\) 中的所有世界共享至少一个可容许动作。
  - 若 \(k\) 个不可区分世界的可容许动作两两不相交，则任意随机策略最坏情况成功概率至多 \(1/k\)。
  - 若额外提供 \(b\)-bit 语义提示，最坏情况成功至多 \(1/\lceil k/2^b\rceil\)；要保证最坏情况超过 \(1/2\)，通常至少需要 \(\lceil\log_2 k\rceil\) bit。
  - 多轮通信、角色分解、消息传递、随机化、更长推理都不能创造缺失的外部区分；它们只处理已有信息。
- **精确语义抽象**
  - 运行时只需保留能改变“哪些动作合法”的区分。
  - 精确验证可行当且仅当抽象 \(\phi\) 不会合并可容许动作集合不同的世界：\(\phi(x)=\phi(x')\Rightarrow C(x)=C(x')\)。
  - 最小精确状态是商空间 \(x\sim_C x'\iff C(x)=C(x')\)。
  - 找到最小充分观测/字段集合是 NP-hard，等价于 Set Cover 类问题；贪心近似基本是最优多项式近似。
- **局部到全局框架：\(X=(H,C,G,F;D)\)**
  - **H 拓扑**：谁与谁在哪些状态上重叠；重叠结构若是 join tree/无环，局部两两一致通常足以推出全局一致；若存在环，则两两检查可能不够。
  - **F 层/粘合条件**：局部片段在重叠处一致时，是否存在唯一全局世界粘合它们；失败即“每个局部都对，整体无世界”。
  - **G 群胚**：表示之间的可逆翻译/编码。一致性要求沿任意环组合翻译回到恒等；可用生成森林在 \(O(|V|+|E|)\) 内检查，独立环数 \(\beta_1=|E|-|V|+c\)。
  - **C 范畴**：真正改变状态的动作及其组合。重表达（单位换算、格式转换）不改变对象，通常无需提交检查；改变状态的动作必须提交检查。
  - **D 历史状态**：只保留会改变未来合法动作的历史，类似 Myhill–Nerode 最小自动机；例如剩余预算、已读版本、依赖来源、已提交后置条件。
- **共享预算与不变量**
  - 跨多个 agent 的共享预算不能被独立局部检查保护；需要：
    - 权威 ledger 在提交时检查总量；或
    - 将预算拆成 per-role escrow quotas，\(B_i\) 满足 \(\sum_i B_i=B\)。
- **提交语义**
  - 每个提议记录其依赖的读集和版本；提交时原子检查这些版本未变，再安装写集。
  - 若读集完整且提交原子，则提交执行等价于按提交顺序串行执行。
  - 对 LLM agent，难点在于读集应包括所有进入上下文并影响提议的权威状态项，而不仅是最终工具调用触及的字段。
- **团队设计规则**
  - 每个角色上下文必须包含其决策所需的区分。
  - 每个跨角色约束必须有拥有者：ledger、escrow、锁、预留或保守停止。
  - 根据读集/写集判断并行或顺序；无冲突则并行自由，有冲突则顺序、提交时版本检查或重构依赖。
  - H 尽量保持低宽度/树状；环需要全局检查或 hub 结构。
  - 角色间编码翻译要显式保留并检查环一致性。
