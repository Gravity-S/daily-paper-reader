## 摘要
小语言模型（SLM）智能体需要安全控制，能够以很小的监控开销追踪跨工具调用的后果。例如，一次私有读取在后续动作将该数据发送到系统外部时就会变成泄露。我们提出 CARB（Conformal Agent Risk Budget，保形智能体风险预算），它利用停止前已发生危害的账本来校准何时停止智能体。在可交换回合假设下，标准保形风险控制对校准与未来回合期望中的这一声明损失给出上界。G-CARB 沿着从私有源到外发动作的可观测依赖关系选择评分器证据。账本仍然覆盖整个已执行历史，且计算门控分数不需要额外的语言模型推理。在具有两个 14B 基座模型的 AgentDojo 回放中，G-CARB 在中等风险预算下将评分器输入记录大致减半，同时相对于全前缀评分提高了自主任务完成率；相同规模的随机上下文也取得了类似增益。受控示例表明，保留相关依赖关系可以进一步避免停止良性工作。

## Abstract
Small language model (SLM) agents need safety controls that track consequences across tool calls with little monitoring overhead. A private read, for example, becomes a leak when a later action sends that data outside the system. We introduce CARB (Conformal Agent Risk Budget), which calibrates when to stop an agent using a ledger of harm incurred before stopping. Under exchangeable episodes, standard conformal risk control bounds this declared loss in expectation over calibration and a future episode. G-CARB selects scorer evidence along observable dependencies from private sources to outgoing actions. The ledger still covers the entire executed history, and computing the gate score requires no additional language-model inference. On AgentDojo replay with two 14B backbones, G-CARB roughly halves scorer-input records at intermediate risk budgets while improving autonomous task completion relative to full-prefix scoring; random context of the same size achieves similar gains. Controlled examples show how retaining the relevant dependency can further avoid stopping benign work.
