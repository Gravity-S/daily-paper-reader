## 摘要
对不良工具返回的鲁棒性意味着以该返回所要求的方式回应它，而这取决于工具出错的方式。一个已失败的工具与一个返回形式良好的虚假信息的工具是不同的问题，需要不同的补救措施。我们探究这两者在返回到达的那一刻是否已经有所不同。这是一项定性试点研究：我们为单个决策点打分，而不是将智能体运行至完成。我们将受控故障注入到零售客服领域，并从模型的对数概率中读取两个通道：返回内容在工具模式单独作用下的似然以及在完整轨迹下的似然，以及其在合法动作上的分布，同时读取其形状和质量所在位置。不完整的返回在每种情况下都是可辨识的，因为它在模式单独作用下的概率处于一个任何其他条件都不会进入的范围，并且它会在有移动空间的地方将质量移向重新读取状态的工具。不一致的返回则不触碰模式通道，而在其真实值已由上下文逐字携带的字段上，于似然比较中被记录，而非在矛盾贯穿领域策略的字段上。动作分布为每个条件提供了独特的签名，但将其按返回对下一个动作的影响程度而非故障类别排序。因此，识别是不对称的：每个条件在某个通道中可辨识，而没有任何通道在所有条件下都可辨识。

## Abstract
Robustness to a bad tool return means answering it in the way that return calls for, which depends on how the tool went wrong. A tool that has failed and a tool that returns a well-formed falsehood are different problems with different remedies. We ask whether the two already differ at the moment the return arrives. This is a qualitative pilot study: we score single decision points rather than running agents to completion. We inject controlled faults into a retail customer-service domain and read two channels off the model's log-probabilities: the likelihood of the returned content under the tool schema alone and under the whole trajectory, and its distribution over the legal actions, read for both shape and where the mass sits. An incomplete return is legible in every case, being improbable under the schema alone in a range no other condition enters, and it moves the mass toward the tools that re-read state wherever there is room to move. An inconsistent return leaves the schema channel untouched and registers in the likelihood comparison on the field whose true value the context already carries verbatim, not on the one whose contradiction runs through the domain policy. The action distribution gives each condition a distinct signature, but orders them by how far the return bears on the next action rather than by fault family. Recognition is therefore asymmetric: each condition is legible in some channel, and no channel is legible on all of them.

- **核心问题**：工具型智能体面对“不完整返回”（工具调用失败、返回截断或错误字符串）与“不一致返回”（格式合法、但内容与事实或上下文矛盾）时，需要采取不同补救措施（前者应重试或优雅降级，后者应交叉核对），因此必须在返回到达的瞬间就识别出返回属于哪一类故障。
- **研究动机**：已有鲁棒性诊断主要用逐步推理熵（step-wise reasoning entropy）或语义熵，但都只能报告“出了问题”，不能区分“出了什么问题”；且噪声/故障并非单一类型，单一曲线无法同时捕捉两类故障。
- **整体含义**：研究尝试回答——工具失败与工具返回“形式良好的虚假信息”在返回到达的那一刻是否已经可区分，并提出在工具返回边界上同时读取多个通道（似然与动作分布）来支撑故障类别的即时识别。

## 2. 方法论：核心思想、关键技术细节与公式

- **核心思想**：在 ReAct 式循环的“工具返回边界”处，对返回字符串在两种条件下的对数概率进行对比，并读取动作分布的熵与位置，从而区分故障家族。
- **关键设置**：使用“教师强制”（teacher forcing）逐决策点打分，而非将智能体运行至完成；注入点固定为 `get_order_details` 的第二次及以后调用，替换单个工具返回，保证此前上下文逐字节一致。

## 3. 实验设计

- **数据集 / 场景**：τ²-bench 的零售（retail）客服领域，共 114 个任务、16 个工具。
- **注入设计**：注入点为 `get_order_details` 的首次调用之后（位置 ≥ 2），构造四个臂：
  - C（干净对照）：保留原始返回；
  - F（失败返回）：用环境自带的错误字符串替换负载，代表“不完整家族”的极限；
  - Ns（不一致-订单状态）：把订单状态改写为枚举中的另一个合法值，矛盾需通过领域策略理解；
  - Nm（不一致-支付标识）：改写支付方式标识符，真实值已在前缀中逐字出现，矛盾是字面冲突。
- **合格任务**：参考动作序列非空、存在合格注入点且其后至少还有一个动作、重放无错误、干净基线不与用户已知信念冲突。53/114 个任务合格，共 189 个打分决策点（各臂独立进入：F n=53，Ns n=46，Nm n=37）。
- **对比方式**：不是与传统方法对比，而是对同一任务同一决策点做“臂间配对对比”，并额外追踪注入后 k=1,2,3 步（k≥1 时被评分字符串在所有臂中逐字节相同），用于分离“字符串本身属性”与“上下文遗留效应”。
- **模型与实现**：Qwen3-8B，bfloat16，HuggingFace Transformers 5.15.0 + PyTorch 2.6.0+cu124，batch size 1，sdpa attention，关闭 TF32 和 KV cache。

## 4. 资源与算力

## 5. 实验数量与充分性

- **实验规模**：
  - 53 个合格任务、189 个注入点；四个臂分别 53/46/37 行；
  - 对每个臂同时读取似然差距（ΔS₀、ΔG）、熵变（ΔH）、领先动作变化和分组质量变化（π(V)、π(W)、πr）；
  - 追踪注入后 k=0–3 共 4 步，并做符号检验（F 在 k=1 时 51/51 行 ΔG>0，p<10⁻¹⁵）和“有熵余量”子集分析（22 行）。
- **充分性评价**：
  - **客观**：所有量都是配对差分，且用同一任务的干净行作对照，控制较好；注入字段、分组条件均在打分前固定。
  - **公平**：各臂进入条件按其目标字段是否存在，计数在各臂内精确、跨臂仅作指示；不是 53×4 完全对称设计，但作者明确说明。

## 6. 主要结论与发现

- **似然通道的不对称性**：
  - 不完整返回（F）在“模式单独”通道上完全可辨：ΔS₀ 全部为正且进入任何其他条件都无法到达的区域；ΔG 也在 45/53 行上升。
  - 不一致返回（Ns/Nm）在模式通道上不动，且仅在“注入值与前缀中已有字面值相撞”时（Nm 对 30/31 行）被 ΔG 捕获；若矛盾需通过领域策略推断（Ns），ΔG 不反应（约半对半）。
  - 因此：G 注册的是“字符串与字符串的字面冲突”，而不是“声明与规则的冲突”。
- **动作分布通道**：
  - 三个臂各有独特签名，但按“返回对下一步动作的影响程度”排序：F 使分布锐化并转向“重读状态”工具；Ns 是唯一能制造不确定性的臂（两行从低熵跳到 >0.5 nats）；Nm 几乎不动分布。
  - F 在 18 个有移动空间的任务上全部提高 π(V)；Ns/Nm 无一致方向。
- **注入后遗留效应（k≥1）**：
  - F 使后续每一步的 ΔG 都上升（k=1 时 51/51 行，中位数 +0.085 nats/token），随后逐渐衰减；Ns/Nm 在任何后续步骤都不移动 ΔG。
  - 领先动作层面：F 和 Ns 都能将 a★ 从参考动作上移开，但方向相反——F 移向重读状态的工具（16/28），Ns 移向写动作（9/15，其中 8 个是同一个写动作），Nm 在任何步骤都不移动。
- **总体判定**：两类故障在返回边界处已经可区分，但**不存在单一数量能同时携带所有故障信号**；识别是不对称的——每个条件在某个通道可读，但没有任何通道对所有条件可读。

## 7. 优点

- **实验设计精巧**：教师强制 + 配对差分 + 字节级一致前缀，使每个注入效果都可归因于单一返回的变化，因果清晰。
- **多通道联合读取**：同时使用“模式条件似然、轨迹条件似然、动作熵、领先动作、分组质量”等多个信号，比单一熵曲线信息量更大。
- **注入设计有区分力**：对不一致家族构造了“字面冲突”（Nm）与“策略冲突”（Ns）两种变体，能精确检验量测通道到底检测的是字符串碰撞还是策略矛盾。
- **控制严谨**：用模式通道来验证注入没有“污染”模式外特征；用 k≥1 的“同字节返回”控制来分离前缀效应与字符串本身效应。
- **诚实限定**：明确说明这是定性试点、单领域单模型、结果不能外推为任务成功率。

## 8. 不足与局限

- **实验覆盖有限**：仅一个域（零售客服）、一个模型（Qwen3-8B）、一个注入站点（`get_order_details`），且采用模板而非对抗性噪声。
- **评价层面限制**：所有决策点都在教师强制下打分，没有把智能体运行至完成，因此读到的只是“即时反应”而非“任务结果”，无法回答故障识别对最终任务成功率的实际影响。
- **统计宣称强度有限**：跨臂计数因字段存在性而不同（53/46/37），不是完全平衡矩阵；部分结论基于很小的子集（如 14/8/6 行）或“有熵余量”的 22 行。
- **不可观测条件**：未注入“无关返回”和“歧义返回”两类故障，作者承认这些是预测而非结果。
- **理论盲区**：作者指出，若一个返回“不矛盾任何已有内容但仍具有误导性”（如关于无法被其他工具确认的退货政策的说明），现有通道都可能完全无反应，因为缺少“观察×策略联合”的量。
- **外推风险**：仅 53 个合格任务，干净基线本身在后续步骤已有 1/3 到 1/2 的参考动作不再是最可能动作，因此尾部读数只在 k≤3、且仅在配对差分意义上可信。
