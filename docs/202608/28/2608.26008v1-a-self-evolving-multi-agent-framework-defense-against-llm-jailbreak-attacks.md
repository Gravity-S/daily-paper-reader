## 摘要
大型语言模型（LLM）仍然容易受到越狱攻击的影响，这些攻击利用角色扮演、混淆、代码转换和多步间接等手段来诱导有害输出。随着越狱策略不断涌现，防御措施也在持续上演的猫鼠游戏中激增，但大多数防御措施仍然是静态的：其安全行为在部署时固定，无法积累防御经验或适应未见过的策略。我们提出了一种围绕持久化、跨交互规则记忆构建的自我进化测试时防御机制：当攻击成功时，该框架将该失败抽象为一条方法级规则，捕获结构性攻击包装而非有害主题，并将其用于抵御未来的输入。由于规则是方法级的，一条衍生规则可泛化至整个攻击家族，且随着新型包装的出现，标签空间也随之扩展。该机制完全通过外部记忆和提示操作，无需更新参数，适用于开放权重和黑盒API模型。我们将其实现为四个协作模块，但核心贡献在于基于记忆的适应机制，而非模块分解。在四个黑盒越狱家族和多种模型上，我们的方法显著降低了攻击成功率，同时保持了良性实用性，在自适应复合包装攻击下保持鲁棒性，且不会随着记忆增长而增加过度拒绝。

## Abstract
Large language models (LLMs) remain vulnerable to jailbreak attacks that exploit techniques such as role-playing, obfuscation, code transformation, and multi-step indirection to elicit harmful outputs. As jailbreak strategies keep emerging, defenses have proliferated in an ongoing cat-and-mouse game, yet most remain static: their safety behavior is fixed at deployment, so they cannot accumulate defensive experience or adapt to unseen strategies. We propose a self-evolving test-time defense built around a persistent, cross-interaction rule memory: when an attack succeeds, the framework abstracts that failure into a method-level rule capturing the structural attack wrapper rather than the harmful topic, and reuses it against future inputs. Because rules are method-level, one induced rule generalizes across an entire attack family, and the label space expands as novel wrappers appear. The mechanism operates entirely through external memory and prompting, with no parameter updates, and applies to both open-weight and black-box API models. We realize it as four cooperating modules, but the contribution is the memory-based adaptation mechanism, not the module decomposition. Across four black-box jailbreak families and multiple models, our method substantially reduces attack success rates while preserving benign utility, remains robust under an adaptive composite-wrapper attack, and does not increase over-refusal as the memory grows.

## 论文提出的方法论

### 核心思想
- 围绕**持久的跨交互规则记忆**（rule memory）构建防御：当一次攻击成功时，框架将该失败抽象为一条**方法级（method-level）防御规则**，该规则描述的是攻击的结构性包装（attack wrapper）而非具体有害主题，因此一条规则可以泛化覆盖整个攻击家族。
- 所有适应都发生在**外部记忆**中，不依赖梯度或参数更新；记忆的标签空间随着结构性新攻击包装的出现而自动扩展。

### 规则形式
- 每条规则 ri ∈ R_t 采用规范化形式：**"[label=Li] If the request uses Pi, then Di"**，其中 Li 是方法级攻击标签（如 roleplay-nested-persona），Pi 描述攻击包装结构，Di 规定拒绝约束。

### 五类关键算子与流程
- 攻击模式分类器 φ：将输入映射为方法级标签（benign / 已有标签 / other），标签集不预先固定，而是随新型包装的出现动态扩展。
- 规则检索匹配：根据 z(t) 从记忆中检索最多 K=2 条规则；匹配采用三级判定：标签优先匹配 → LLM 相关性打分 → 词汇重叠启发式。
- 策略算子 g（Policy Decision）：将触发的规则映射为三种动作——**hard-refuse**（高危请求，执行性有害指令）、**soft-refuse**（中危请求）、**allow**（默认无触发）；冲突时按 hard-refuse ≻ soft-refuse ≻ allow 排序。
- 违规检测器 h：使用 LLM-as-judge，对 1–10 分的 harmfulness 评分（阈值 τ=7）判定攻击是否成功；该检测器和评估用的外部 GPT-4o-mini 是不同模型，避免优化评估器本身的偏差。
- 规则归纳 F 与记忆更新 U：当检测到违规且输入非 benign 时，从交互中蒸馏新规则，并通过语义去重和每标签容量上限（C=4）更新记忆。

### 四智能体实现
- A1（规则触发）：实现 φ 和 match，选出当前输入相关的规则子集。
- A2（策略决策）：实现 g，将触发规则转换为响应策略。
- A3（响应生成）：按策略动态注入系统指令，硬拒绝模式下施加安全契约，禁止提供操作细节、代码、命令等。
- A4（自反射）：运行 h，并在检测到违规时执行 F 和 U 更新记忆。
- 作者强调，四智能体仅是机制的实现载体，**真正的贡献是记忆驱动的适应机制**，而非模块分解本身。

## 论文的主要结论与发现

- 所提出的自进化防御在 **4 个越狱家族、3 个模型**上始终取得最低 ASR（例如 DeepInception 下 ASR-gpt 降至 0.1–3.5%，CodeChameleon 下低至 0.8–1.9%），显著优于无防御、静态提示、Self-Reminder 和 AutoDefense。
- 良性任务效用保持稳定：MMLU 和 GSM8K 的准确率与无防御模型差距在约 2 个百分点以内。
- 自进化分析显示：记忆在第一轮失败后即可覆盖对应攻击的结构包装，后续轮次的 ASR 降至接近零；无防御基线则始终脆弱，证明改进确实来自记忆积累而非模型自身鲁棒性。
- 消融实验证明**规则触发、策略强制、反射归纳**三个组件缺一不可；去掉任一组件 ASR 均大幅上升。
- 自适应复合包装攻击无法有效规避规则触发，框架仍保持鲁棒。
- 记忆增长不会导致过度拒绝显著加剧：XSTest 上从冷启动的 3.6% 仅上升至记忆积累后的 9.6%。
- 核心结论是：**持久、跨交互、方法级规则记忆驱动的测试时适应**能带来静态防御无法实现的、随交互流持续提升的鲁棒性。

## 优点

- **机制创新性**：将失败抽象为可复用的方法级规则而非实例级修补，实现跨交互知识积累，且无需参数更新——这一机制可以适配从开源权重到黑盒 API 的广泛模型。
- **泛化能力强**：一条规则覆盖整个攻击家族，标签空间自动扩展，无需预先定义全部攻击类型。
- **实验设计严谨**：冷启动流式协议避免了评测数据泄漏；学习信号与评估信号来自不同模型，避免了对评估器自身的优化；同时用关键词和 LLM 两种指标交叉验证。
- **推理开销可控**：稳态下平均约 3 次 LLM 调用，并选择性地触发规则，而非盲目拼接所有规则，维持了良性任务的可用性。
- **分析层次完整**：除主实验外，还包括自进化动态、消融研究、超参敏感性、过度拒绝测试、自适应攻击鲁棒性和案例说明，形成较完整的证据链。

## 不足与局限

- **攻击覆盖有限**：仅评估四个提示级、单轮、黑盒越狱家族，未覆盖多轮对话攻击、agentic/工作流攻击或更广的最近涌现攻击；作者也在 Limitations 中明确承认这一点。
- **长期记忆管理缺环**：当前只有语义去重和每标签容量上限（C=4），没有显式的规则剪枝或冲突消解机制，对于极长交互流中大型规则记忆的效率和一致性仍是开放问题。
- **分类器与检测器精度依赖**：φ 和 h 本身是提示式 LLM 组件，继承基础模型的判断误差，可能将 XSTest 中设计好的同音/多义词陷阱（如“kill a process”）误判为攻击，带来 9.6% 的残差过度拒绝——这是分类器精度问题而非记忆积累的必然效应。
- **ASR-rej 的局限**：论文自己也指出，基于拒绝短语的 ASR-rej 可能被注入了显式拒绝语的系统低估攻击成功率，因此仅作为辅助指标。
- **外部模型依赖与实践成本**：需要调用多个 LLM（分类器、策略决策、响应生成、反射），延迟和 API 成本高于单次调用，虽然相对 AutoDefense 有竞争力，但对低成本场景仍构成门槛。
- **评估模型种类有限**：额外基线对比只在 Qwen2.5-7B 上进行，跨模型的基线泛化性缺少更完整验证。
