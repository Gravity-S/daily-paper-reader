## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）常常表现出复杂的失败模式，这经常导致智能体产生错误的结果。这推动了智能体失败归因任务：给定一条失败的多智能体轨迹，识别出有问题的智能体及其对应的错误类型。现有方法主要依赖LLM来执行失败归因，要么通过直接提示、在合成数据上进行微调，要么通过复杂的智能体流水线。虽然有效，但这些方法由于长上下文处理、昂贵的后训练和手工设计的工作流而产生了大量的计算开销。此外，经验证据表明，即使是最先进的模型在现有基准上也只取得了有限的准确性，这表明仅扩大模型规模是不够的。在这项工作中，我们重新审视了这一任务，并质疑这种昂贵的生成式解决方案的必要性。我们引入了AFANet，一个轻量级的基于图的框架，通过步骤级语义信号和智能体级关系对交互轨迹进行建模。我们表明，在参数显著更少且推理成本几乎为零的情况下，AFANet（i）在域内基准上与基于LLM的基线（包括微调模型）相当或更优，（ii）在不同GNN架构下保持稳健的性能，并且（iii）可以通过廉价的测试时适应在OOD基准上进一步改进。我们的结果表明，有效的智能体失败归因并不需要沉重的LLM推理，轻量级的结构化方法也能实现强性能。

## Abstract
Large language model (LLM)-based multi-agent systems (MAS) often exhibit complex failure modes, which frequently cause agents to produce incorrect outcomes. This motivates the task of Agent Failure Attribution: given a failed multi-agent trajectory, identify the faulty agents and their corresponding error types. Existing approaches predominantly rely on LLMs to perform failure attribution, either through direct prompting, fine-tuning on synthetic data or complex agentic pipelines. While effective, these methods incur substantial computational overhead due to long-context processing, expensive post-training and handcrafted workflows. Moreover, empirical evidence shows that even state-of-the-art models achieve limited accuracy on existing benchmarks, suggesting that scaling model size alone is insufficient. In this work, we revisit this task and question the necessity of such expensive generative solutions. We introduce AFANet, a lightweight graph-based framework that models interaction trajectories through step-level semantic signals and agent-level relationships. We show that with significantly fewer parameters and near-zero inference cost, AFANet (i) matches or outperforms LLM-based baselines, including fine-tuned models on in-domain benchmarks, (ii) maintains robust performance across different GNN architectures and (iii) can be further improved with inexpensive test-time adaptation on the OOD benchmark. Our results suggest that effective agent failure attribution does not require heavy LLM reasoning and a lightweight, structured approach can achieve strong performance.

## 2. 方法论：AFANet

**核心思想：** 失败模式不仅体现在单轮文本的语义内容中，更体现在智能体行为随时间的**演化模式**与**跨智能体的交互结构**中。因此，用图结构显式建模轨迹的时序和智能体关系，即可取代昂贵的 LLM 推理。

### 2.1 轨迹 → 对话图（Conversation Graph）

- **节点**：轨迹中的每一轮对话（turn）作为一个图节点，共 T 个节点。
- **节点特征**（每轮拼接三部分）：
  - **偏差特征（deviation features）**：先对每轮文本计算 TF-IDF（以整个轨迹为语料库），再截断 SVD 得到低维稠密向量，进而计算多种偏差信号：
    - 与上一轮的余弦偏差（时序突变）；
    - 与同智能体历史发言均值的偏差（自不一致性）；
    - 与全局对话中心均值的偏差（对话共识偏差）；
    - 与其他智能体发言均值的偏差（跨智能体偏差）；
    - 同智能体发言内部一致性、同智能体前一轮相似度、词汇稳定性、与初始问题对齐度等。
  - **统计特征（statistical features）**：位置编码（归一化轮次位置、首/尾标志、同智能体参与累积比例）、长度统计（归一化长度、z 分数）、结构统计（参与比例、发言位置离散度）、数字标记等。
  - **语义特征（dense semantic features）**：由预训练 Sentence-BERT（all-MiniLM-L6-v2）编码轮次文本得到的高维稠密嵌入。
- **边（两种类型）**：
  - **时序边**：相邻轮次之间的双向边，保留对话顺序；
  - **同智能体边**：同一智能体产生的所有轮次两两连接，捕获长程一致性。

### 2.2 图神经网络消息传递

- 初始节点特征先经线性投影 + ReLU + LayerNorm 进入隐空间；
- 叠加 L 层 GNN（默认 2 层 GCN，也支持 GAT、GraphSAGE），每层带残差连接；
- 每轮更新的公式本质上是邻居消息聚合 + 自身表示相加。

### 2.3 智能体级池化与预测

- 对每个智能体，汇总其名下所有轮次的表示，采用 **均值池化 + 最大池化拼接**，得到智能体级表示；
- 经多层投影头（含瓶颈层、Dropout）输出 K+1 维 logits：类 0 表示正常，其余 K 个类对应错误类型。

### 2.4 训练目标（双目标）

- **智能体级二分类目标**（加权 BCE）：判断该智能体是否故障，正类权重按批量内正常/故障比例设定；
- **错误级多分类目标**（CE）：仅对故障智能体计算错误类型分类损失；
- 两者加权求和作为总损失。

### 2.5 推理

- 每个智能体的故障分数 = 所有错误类 softmax 概率之和；
- 采用**阈值解码**（在验证集上扫阈值，先选智能体阈值，再选错误阈值）或**排序解码**（用于 OOD 的 Who&When，每个对话只取故障分数最高的智能体）。

## 3. 实验设计

### 3.1 数据集与 Benchmark

| 数据集 | 角色 | 规模 |
|---|---|---|
| AEGIS-Bench | 域内（in-domain） | Train 7,146 / Val 1,787 / Test 600 |
| Who&When | 域外（OOD） | Test 184（每个轨迹恰好一个故障智能体） |

- 错误类型共 **14 类**，分为三大家族：规范问题（FM-1.x）、智能体间不对齐（FM-2.x）、任务验证失败（FM-3.x）。
- 评估指标：Agent 级、Error 级、Pair 级三个粒度的 **Micro-F1** 和 **Macro-F1**。

### 3.2 对比方法

- **预训练 LLM**：Qwen2.5-7B/14B-Instruct、Qwen3-8B-NT/T；
- **微调 LLM**：Qwen2.5-7B/14B-It+S（SFT）、+S+G（SFT+GRPO）、Qwen3-8B 变体；
- **专有 LLM**：GPT-4.1、GPT-4o-mini、o3、Gemini-2.5-Flash/Pro、Claude-Sonnet-4；
- 所有 LLM 基线采用 "All-at-Once" 提示策略（一次性输入完整轨迹并要求输出故障智能体和错误类型）。
- AFANet 使用 2 层 GCN（隐藏维度 64，瓶颈 32），Adam 优化器，lr=1e-2，最多 100 epochs，早停 patience=10，batch size=2000，dropout=0.1。

## 6. 主要结论与发现

1. **轻量模型可以取代重型 LLM 推理**：AFANet（65K 参数）在 AEGIS-Bench 的 Pair 级别指标上达到 top-1，在 Who&When 上也保持较高的 Pair 级表现，平均性能优于或匹配所有 LLM 基线——包括经过 SFT 和 GRPO 后训练的模型。
2. **效率优势极为显著**：训练时间仅约 1.1 小时，推理时间约 1 秒，相比 7B/14B 级 LLM 有高达 70x–300x 的加速。
3. **结构信息是关键**：去边、去 GNN、去偏差/统计特征均导致性能下降；时序边和同智能体边提供互补信号。
4. **架构鲁棒**：GCN/GAT/GraphSAGE、1–3 层均表现稳定，敏感度低。
5. **廉价 TTA 可行**：基于熵最小化的测试时适应（仅调整 LayerNorm 参数、30 步 Adam）可持续改善 OOD 性能，其中 "Pair-Faulty" 策略平均效果最好。

## 8. 不足与局限

- **OOD 泛化仍受限**：在 Who&When 上的绝对性能（Pair μF1≈6.9%）仍然偏低，说明分布偏移下归因仍是开放难题；作者也承认跨不同多智能体设置泛化仍具挑战。
- **语义推理能力有限**：某些失败类型需要深层的意图理解和长程因果推理，纯结构化模型可能力不能及；作者建议未来将 GNN 与 LLM 结合。
- **统计可靠性不足**：未报告多次运行的方差或显著性检验，指标波动可能导致结论不够稳健；部分 LLM 基线复现结果与原文差异大，增加了横向对比的不确定性。
- **OOD 数据规模较小**：仅 184 条，TTA 结论的统计效力有限。
- **特征工程依赖人工设计**：TF-IDF/SVD、各类偏差和统计特征需要针对轨迹结构专门定制，跨框架迁移可能需要重新设计。
- **仅覆盖两类基准**：没有在更多真实多智能体系统（如编码 agent、网页导航等）上验证，外部效度有待加强。
