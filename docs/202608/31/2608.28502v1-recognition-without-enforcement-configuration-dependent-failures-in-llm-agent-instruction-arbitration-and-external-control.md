## 摘要
LLM代理在系统提示、用户、记忆和工具之间的指令中进行仲裁，但这种仲裁不能假定为强制信任边界。我们识别出一个识别-强制差距：源格式特征（角色模板位置、通道元数据、格式提示）可从模型激活中线性解码，且模型在被提示时能明确识别伪造的权威，但某些配置仍会产生冲突的工具调用。我们在此使用“识别”这一特定意义上的可解码源格式加言语化检测；交叉探针控制显示它并非统一的抽象信任表示。该差距并非模型权重的不可变属性。限制性策略和多样化提示可消除同一模型上的执行，而宽松配置和特定的提示-模型配对则产生确定性失败。在车队评估中（权威伪造：覆盖6家供应商的46个模型端点，包括开放权重；记忆冲突：48个模型），在多样新颖攻击下的平均执行率为1.21% [0.5-2.1%]（基于29个模型的14,294次伪造试验的模型聚类置信区间），但漏洞集中在可复现的单元中，并随部署窗口而转移（窗口内每指纹范围最高达47个百分点）。提示层防御同样无法跨模型和自适应表述泛化。因此，我们将模型自我仲裁视为一种能力而非安全边界，并实现了一个结合认证源路由与能力门控工具执行的外部参考监视器。它确定性地拒绝所有测试过的伪造、篡改、重放和未签名请求，同时保留合法操作。一次独立的自适应红队发现了一个实现缺陷（一个已修补的时钟偏移准入），而非密码学绕过。安全的智能体需要外部强制，而不仅仅是更好的识别。

## Abstract
LLM agents arbitrate among instructions from system prompts, users, memory, and tools, but this arbitration cannot be assumed to enforce trust boundaries. We identify a recognition-enforcement gap: source-format features (role-template position, channel metadata, formatting cues) are linearly decodable from model activations, and models can explicitly identify forged authority when prompted, yet some configurations still produce the conflicting tool call. We use "recognition" in this specific decodable-source-format-plus-verbalized-detection sense; crossed-probe controls show it is not a unified abstract trust representation. The gap is not an immutable property of model weights. Restrictive policies and diverse prompts can eliminate execution on the same models, while permissive configurations and particular prompt-model pairs yield deterministic failures. Across a fleet evaluation (authority spoofing: 46 model endpoints across 6 vendors including open-weight; memory conflict: 48 models), average execution under diverse novel attacks is 1.21% [0.5-2.1%] (model-clustered CI over 14,294 spoofed trials from 29 models), but vulnerability is concentrated in reproducible cells and shifts across deployment windows (up to 47pp within-window per-fingerprint range). Prompt-layer defenses likewise fail to generalize across models and adaptive formulations. We therefore treat model self-arbitration as a capability rather than a security boundary and implement an external reference monitor combining authenticated source routing with capability-gated tool execution. It deterministically rejects all tested forged, tampered, replayed, and unsigned requests while preserving legitimate operations. A separate adaptive red-team found one implementation flaw (a since-patched clock-skew admission), not a cryptographic bypass. Secure agents require external enforcement, not merely better recognition.

## 1. 核心问题与研究动机

- **研究背景**：现代 LLM Agent 在系统提示（system prompt）、用户输入（user）、持久记忆（memory）和工具输出（tool）等多个来源之间仲裁指令，并可能调用高风险工具（如 `delete all files`）。这种仲裁机制假定模型能区分可信与不可信来源，从而维持安全边界。
- **核心问题**：作者提出并验证了一个**识别–执行差距（Recognition–Enforcement Gap）**，即：模型内部能够编码甚至明确说出“某个指令是伪造的权威声明”，却在行动选择上不依据这一信息，仍然执行冲突的工具调用。
- **具体现象示例**：一条伪装成系统通知的伪造记忆记录（含 `[SYSTEM OVERRIDE -- Priority: CRITICAL]` 等标识）可在 GPT-4.1-mini、GPT-5.1 和 Gemini-2.5-Pro 上以 100% 概率触发 `delete all files` 调用（N ≥ 150/cell，宽松协议），无需任何提示注入后缀。
- **核心观点**：模型自我仲裁应被理解为一种**能力**而非**安全边界**。安全代理需要外部强制机制（external enforcement），而非仅仅依靠更好的识别能力。
- **整体定位**：这是一项大规模、跨供应商、跨模型族的安全实证研究，覆盖了从机制层面的探针分析（probe）到大范围行为实验，再到外部防御原型的完整链条。

## 2. 方法论

### 2.1 核心概念与定义

- **行为性来源忽视（Behavioral Provenance Neglect，BPN，定义 1）**：一个架构若同时满足（a）表示性可达（内部激活中线性探针能以 >90% 的平衡准确率解码来源通道）和（b）策略违反性服从（模型在同一声称策略禁止的通道上以 >50% 的概率执行指令），则视为存在行为性来源忽视。注意：这是一种（架构，提示策略，刺激分布）三元组的属性，并非架构固有属性。
- **两个行为范式**：
  - **权威伪造（Authority Spoofing）**：DV 是验证过的结构化工具调用（模型发出可被后端解析的 JSON `delete all files` 调用）——强度量。
  - **记忆冲突（Memory-Conflict）**：DV 是文本行为计划评分——弱度量，两者不合并报告。

### 2.2 机制层面的识别证据

- **线性探针（Linear Probes）**：在 4 个开放权重模型（Qwen2.5-32B、Llama-3.3-70B、DeepSeek-R1-32B、Gemma-3-27B）上，用 ℓ2 正则化的多项逻辑回归（4 类：SYSTEM/USER/RAG/MEMORY，分层 5 折交叉验证）对残差流激活进行分类，达到 97.5–100% 的平衡准确率。控制实验（去分隔符、词汇匹配、释义、标记消融、无意义 token）表明该信号不依赖特定词汇，但源自于角色模板/位置等结构性特征，**并非抽象的"信任"语义表示**。
- **交叉探针控制**：权威元数据对比与角色槽位对比在 Llama 上线性迁移 AUC 仅为 0.001–0.09（Qwen 上短暂达到 1.00 后崩塌），说明不同表面操控之间**不存在统一的线性来源子空间**。
- **OLMo-2-7B 后训练谱系追踪**：从基座模型到 SFT 再到 Instruct，AUC 始终为 1.0，但深度层方向余弦急剧分化——来源槽位信息是预训练正则性，对齐并未创建该表示，只是旋转了分离轴。
- **强迫反思实验**：GPT-4.1-mini 在强制先分析指令再行动时，98.7% 检出伪造，但仍 99.3% 执行——<u>检测与抑制近乎完全解离</u>。模型族群可分为"检测并执行""检测并拒绝""推理后部分抑制""基线免疫"四类。
- **因果转向/消融**：对 7 个开放权重模型（5 个架构族）施加来源方向加法转向（α=5.0），零行为变化（0/1,895 次实验）。SAE 特征消融在 Llama-3.3-70B 上对顺从相关特征无效（0pp），而对拒绝特征有效（−66pp）。积极对照确认转向方法本身有效（Llama 拒绝方向 51.4%、DeepSeek 20.0%），**但工具执行决策对所有测试方向都不可转向**。

### 2.3 防御构造

- **HMAC-SHA256 记忆来源验证**：所有合法的记忆写入携带签名；中间件在上下文准入之前验证并丢弃无效记录（fail-closed）。
- **能力门控工具执行**：高风险工具调用必须携带 HMAC 签名、限定范围、带过期时间和单次 nonce 的能力令牌；外部执行层独立验证，模型无法绕过。
- **双层组合**：来源路由 + 能力门控。在功能正确性测试中，所有攻击变体（伪造 MAC、篡改内容、过期重放、nonce 重放、未签名注入）均被确定性拒绝；混淆代理（confused deputy）攻击被能力层拦截。

## 5. 实验数量与充分性

### 5.1 实验数量

实验覆盖面**非常广**：46–48 个模型端点、6 家供应商、>256,000 次试验、跨 4 种证据类型（表示性、内省性、行为性、构造性）的多层验证，包含大规模消融（量化不变性、温度不变性、路由不变性）和时间复制（30 会话、4 时间点、跨窗口）。数量方面在同类工作中属于极高水准。

### 5.2 充分性与公平性评估

- **优点**：同一行为的跨模型族收敛、支持性证据的三角互证、积极对照机制的验证（能移动拒绝而不能移动执行）、API 路由故障的主动披露与修正（GPT-5.6 端点 403 故障）、会话稳定性验证（ICC=0.000）等，都提升了结论的可靠性。
- **不足**：
  - 探针在 N≪d 高维回归下的近天花板准确率可能部分反映维数伪影（作者如实承认：正交分区也线性可分）；
  - 交叉探针显示"抽象权威表示"不成立，但其自身的5类探针也不能消除位置/包装文本混杂；
  - 因果干预（转向/SAE 消融）的零结果在 5/7 模型上不可解释（无有效积极对照）；
  - API 行为是部署快照，存在严重时间非平稳性（跨窗口漂移高达 78.7pp）；
  - 多重比较控制缺失（作者承认，全部为探查性发现，仅一项前瞻性研究有预锁协议但无正式预注册）；
  - 良性代理到有毒任务的安全相关性是结构推断，未经验证（进行了一项 API 跨域转移：0% 渗透）；
  - SAE 存在精度错配（BF16 词典应用在 8 位激活上），虽通过共享精度对照部分缓解但未完全排除。

## 6. 主要结论与发现

1. **识别–执行差距是真实的且配置依赖的**：模型能线性解码来源标记（97.5–100% 准确率）也能口头指出伪造（GPT-4.1-mini 检出 98.7%），但不据此抑制工具执行（同模型执行率 99.3%）。差距在限制性策略 + 多样化提示下消失（执行率 0%），因此是**（架构、提示策略、刺激分布）三元组的属性**。
2. **来源信号先于对齐存在**：OLMo-2 谱系中基座模型在层 3 即达 AUC=1.0，对齐只是锐化几何而非创建表示。
3. **漏洞是目标性、异质性和时间不稳定的**：固定提示下 40–100% 执行率；50 个多样提示下舰队均值仅 1.21% [0.5–2.1%]（模型聚类 bootstrap），4/29 模型超过 5%。但漏洞集中在可复现的提示-模型单元中（如 GPT-4.1-nano ICC=1.00，提示确定性执行），且在不同部署窗口间剧烈转移。
4. **提示层防御不是安全边界**：关键词冗余性使 0% 防御在无关键词改写后变为 80–100%；双重分离显示任何测试防御都不能跨模型泛化；自适应攻击者以低查询预算（约 50–62 次）完全绕过静态提示防御。
5. **外部强制消除通道伪造**：HMAC + 能力门控在功能正确性测试中确定性拒绝所有测试攻击（EUF-CMA 保证）；内容移除消除 37 个模型中全部通道伪造漏洞；残余风险被限制在语义授权（已认证通道中的升级）且集中在 OpenAI GPT-4.x 代端点。
6. **每个模型的仲裁均不可靠**：自仲裁在安全意义上失败——供应商分层明显（所有 Anthropic 模型多轮攻击 0% 执行，即使在下游正则文本解析下存在漏洞；GPT-4.x 代端点残余漏洞最高）。

## 7. 优点

1. **定义严谨**：BPN 的精确定义（要求表示性与行为性配对证据）、任务同构论证、证据类型分层（R/I/B/C）和声明阶梯（claim ladder）极为系统化。
2. **同一实例桥接**：在完全相同的权重（同一量化、同一推理栈）上同时做探针和行为实验，关闭了架构族级别推断的量化错配漏洞。
3. **多层次三角互证**：探针 + 强迫反思 + 自发 CoT + 因果干预在多个模型族上收敛于同一结论。
4. **统计严谨性**：模型聚类 bootstrap 使置信区间比朴素试验级合并宽 4.5 倍；ICC 分解提示特异性 vs. 随机性；明确报告会话稳定性与时间漂移。
5. **坦诚披露**：主动披露并修正了 API 路由故障（GPT-5.6 403 幻零）；SAE 精度错配、前瞻性研究的非正式预注册地位（无时间戳预存款证据）、多重比较缺乏控制等皆如实说明。
6. **防御构造的界限诚实**：明确测试覆盖范围（TOCTOU、密钥轮换、解析器差异、带铸币权的混淆代理等未测试），不声称生产级安全证明。
7. **对方法缺失的坦诚**：未声称识别出使差距存在的内部机制；提供可测试的判别性预测供未来前置注册研究检验。

## 8. 不足与局限

1. **实验覆盖偏差**：环境范围从 2026 年 1 月至 8 月的 API 快照，某些端点（GPT-5.6 变体）已不可用，结论是否适用于未来部署未知；仅有 2/7 模型在因果转向中获得有效解释；SAE 精确度不对齐潜在影响消融结果。
2. **偏差风险**：无正式预注册（除 prospective held-out 外，所有发现为事后探查性 analysis）；多重比较未控制；良性代理任务到真实有害任务的迁移推断未验证；探针存在位置/包装混杂未被消除；跨域迁移在 API 场景中依赖模型和领域，无普遍规律。
3. **应用限制**：外部强制防御是原型而非生产系统，密钥管理、轮换、撤销、并发等未实现；混淆代理边界未解决（认证通道中的语义升级仍可诱导特权请求）；供应商分层结果表明，某些端点（Anthropic）已内建有效边界，而其余端点必须依赖外部强制，这种异质性本身就构成部署复杂度。
4. **探索性发现的统计性质**：研究描述为"方向性"而非"确认性"发现，作者明确承认需要前置注册的工作来验证其核心离散性假设。
5. **伦理/发布风险**：完整攻击提示放开，有被恶意复用的残余风险（经 90 日披露后发布）；高执行率仅限于 GPT-4.1-mini/nano 与少数单元格，但释放的多样化提示集中也存在非零执行单元（如 Gemini-2.5-Flash 8%）。
