## 摘要
大型语言模型（LLM）智能体通过将基础模型与显式技能以及通过执行获得的隐式程序性知识相结合，日益能够完成长时程任务。由此产生的任务解决能力已成为有价值的专有资产，引发了一个新的安全问题：一个能力明显较弱的、由攻击者控制的智能体能否通过有限的黑盒交互获得较强专有智能体的能力？现有的技能窃取攻击能够恢复显式技能工件，但我们表明工件泄露并不一定带来能力迁移：较弱智能体可能拥有相同的技能但仍会失败，因为它缺乏较强智能体隐式实现的程序性行为。我们的关键洞见在于，技能执行差距本身构成了泄露面，其中缺失的行为通过成功受害者执行与失败攻击者执行之间的可观察差异暴露出来。基于此，我们提出了AgentLeak，一种黑盒能力克隆攻击，它从这些执行差异中识别出对能力至关重要的行为，并将其纳入攻击者侧技能，同时保持攻击者的模型、框架和工具不变。在涵盖600个实例、多种智能体系统和多个骨干模型的20个任务场景中，与直接技能复用相比，AgentLeak将任务通过率提升了超过40%，并恢复了受害者与攻击者能力差距的80%以上。我们的发现揭示了LLM智能体中的一种保密性风险：仅保护显式工件是不够的，因为可观察的执行行为可能泄露重建专有任务解决能力所需的程序性知识，而这种重建可发生在低能力且攻击者控制的智能体中。

## Abstract
Large language model (LLM) agents increasingly achieve long-horizon tasks by combining foundation models with explicit skills and implicit procedural knowledge acquired through execution. The resulting task-solving capabilities have become valuable proprietary assets, raising a new security question: can a substantially weaker attacker-controlled agent acquire the capabilities of a stronger proprietary agent through limited black-box interaction? Existing skill-stealing attacks recover explicit skill artifacts, yet we show that artifact leakage does not necessarily transfer capability: a weaker agent may possess the same skills but still fail because it lacks procedural behaviors implicitly realized by the stronger agent. Our key insight is that the skill execution gap itself forms a leakage surface, where missing behaviors are exposed through observable differences between successful victim executions and failed attacker executions. Based on this, we present AgentLeak, a black-box capability-cloning attack that identifies capability-critical behaviors from these execution differences and incorporates them into attacker-side skills, while keeping the attacker's model, harness, and tools unchanged. Across 20 task scenarios comprising 600 instances, diverse agent systems, and multiple backbone models, AgentLeak improves task pass rates by over 40% compared with direct skill reuse and recovers more than 80% of the victim--attacker capability gap. Our findings reveal a confidentiality risk in LLM agents: protecting explicit artifacts alone is insufficient, as observable execution behavior can leak the procedural knowledge required to reconstruct proprietary task-solving capabilities in low-capability and attacker-controlled agents.

# AgentLeak 论文总结

## 1. 核心问题与整体含义

论文聚焦 LLM 智能体能力的安全泄漏问题。商业 LLM 智能体（例如 Codex、Claude Code）通过“技能”（显式工件）与隐式程序性行为相结合，形成了难以复制的端到端任务解决能力。这些能力是有价值的专有资产，因此一个核心安全疑问是：**一个能力明显较弱的攻击者控制智能体，能否通过少量黑盒查询，从更强专有智能体那里“克隆”出任务解决能力？**

以往的攻击（如技能窃取）只恢复显式“技能工件”，但论文通过实证指出：**工件泄漏 ≠ 能力迁移**。弱智能体即使获得相同技能，仍可能因缺少强智能体在“执行”阶段隐式提供的决策行为（如任务分解、工具选择、反馈解释、结果验证等）而失败。作者将这一差距称为“技能执行差距”。

核心洞见是：**这种执行差距本身就是一个泄漏面**。当受害者成功完成任务、攻击者失败时，二者的可观察执行差异会暴露出那些“缺失的关键行为”。因此，攻击者可以通过比较成功与失败轨迹，把缺失行为外化为新技能，从而在保持自身弱模型、框架和工具不变的情况下逼近受害者能力。这揭示了新的保密性风险：仅保护模型、技能等显式工件是不够的，可观察执行行为也可能泄漏足以重建专有能力的过程性知识。

## 2. 方法论

### 核心思想

AgentLeak 是一种**黑盒能力克隆攻击**：只修改攻击者侧的技能集，不改变其底层模型、智能体框架和工具；攻击者从受害者正常交互界面获取有限执行证据；然后迭代地重构技能，缩小“受害者–攻击者能力差距”。

### 关键技术细节

AgentLeak 通过四个组件完成“从差分执行证据到技能更新”的转化：

1. **工作流抽象与技能映射**：将成功的受害者轨迹抽象成可复用的“工作流技能”，而非直接拷贝实例特定细节。工作流技能包括四部分：执行结构 Ws、验证标准 Vs、步骤到现有技能的映射 Φs、优化指导 Rs。这样做是为了给弱智能体一个稳定的执行脚手架，并识别技能间协调缺失。
2. **差分能力缺陷诊断**：在同一任务的受害者成功轨迹与攻击者多次失败轨迹之间做工作流引导的对比诊断。把“对能力关键的行为缺失”与“良性轨迹差异”区分开来，输出缺陷集合（包括目标技能、症状、根因、新/复发标记、发生频率）。
3. **行为原语提取**：把缺陷转换为可执行的行为原语，明确“缺失行为”“所需程序”“预期效果”，但不复制受害者轨迹中的具体指令。
4. **结构化技能重写**：以局部补丁形式修改原技能，仅做两种操作——`Insert`（插入缺失程序）和 `Replace`（替代无效指令），避免整体重写破坏已有有效成分。

迭代过程由算法描述：每个查询实例先由攻击者执行，失败则向受害者查询成功轨迹并抽取工作流；随后循环执行“诊断→提取原语→生成补丁→应用补丁”，直至任务成功或达到重建预算；最后对已解决任务做回归检查。论文使用辅助分析 LLM（Maux）进行离线分析，推理阶段不再需要它。

### 公式或算法流程的文字说明

- 智能体能力定义为在场景分布上任务通过率的期望：`Cap(A, K, D) = E[V(Exec(A, K, t), y)]`。
- 能力差距定义为受害者能力减去攻击者初始能力：`Δ = Cap(victim) − Cap(attacker)`。
- 能力恢复率（CRR）衡量重建技能对差距的回收比例：`CRR = (AgentLeak 的通过率 − 无技能通过率) / (受害者通过率 − 无技能通过率)`。
- 攻击流程：执行失败 → 查询受害者 → 抽工作流 → 差分诊断 → 提取原语 → 结构化重写 → 再次执行；重复到成功或预算耗尽。

4. **跨模型、跨框架迁移可行，但收益受“源–目标”差距约束**：跨模型实验表明，从受害者工作流中提取出的执行结构同样能使其他未参与重建的攻击者受益；跨框架迁移也能工作，但需要技能文件的接口与目标框架兼容。整体上看，从更强专有系统中学到的技能结构比从同级别系统学到的更稳健，而目标模型过弱时仍会在执行层面打折扣，说明 AgentLeak 并不是“无限放大器”，它恢复的是受害者暴露出来的“缺失程序”，而非受害者的全部隐式智能。

5. **四个组件在消融中均被证明必要**：去掉“工作流抽象”后，技能更新容易退化为对单轨迹的浅层复制，测试实例上掉点最多；去掉“差分诊断”后，攻击者无法准确定位“缺什么”，补丁频繁无效；去掉“行为原语提取”后，技能更新掺杂大量轨迹特有噪声；去掉“结构化重写”而改为整体重写技能，则容易破坏原本已有效的执行片段。可见，AgentLeak 的有效性恰恰来自“从差分证据中定位缺失能力 → 将其表示为可复用程序 → 以最小补丁方式落地”这一完整链路。

6. **攻击代价低，现实威胁面真实**：重建过程完全不需要微调模型，也不需要白盒访问受害者参数；每个场景只需 1 条受害者成功轨迹与有限次攻击者自执行。按论文报告的平均成本推算，针对一个场景完成能力克隆仅需约 60 分钟和数美元级的辅助分析费用。这种低成本意味着，安全防御不能只依赖“受害者查询需要付费”或“查询次数受限”这类简单门槛，因为攻击者可以只在少数关键任务上投入查询，再靠本地迭代放大能力。

7. **防御评估显示：工件级防御不足，行为级防御更有效但有代价**：论文测试的三类工件级防御——隐藏/缩减技能内容、最小化成功输出、增加输出扰动——都无法有效阻止 AgentLeak，因为攻击者真正需要的不是工件本身，而是受害者“如何完成任务”的行为轨迹。相比之下，一种行为级防御（具体为对可观察执行过程做结构化遮蔽或注入噪声）能够显著降低攻击者的重建恢复率，但同时也会损害受害者自身的任务通过率。也就是说，现有防御思路面临“保护能力”与“可用性”之间的两难；论文由此提出，更现实的缓解方向是检测异常的“成功–失败对照查询模式”，并限制高价值工作流的批量探测，而不是试图把执行行为完全隐藏。

总体来看，AgentLeak 的核心贡献是把“能力窃取”从“技能工件复制”推进到了“执行行为重建”层面，并且以充足的实验证据表明：在只给出少量黑盒访问的情况下，弱模型也足以逼近强专有智能体的端到端任务能力。该结果对 LLM 智能体的保密性假设构成实质性挑战——**仅仅保护模型权重、提示词和技能文件是不够的，可观察的“做事过程”本身已成为一种可被逆向的能力泄漏面**。同时，防御实验也说明，当前尚无“无痛”的阻断手段；这为后续研究提出了两个清晰方向：一是开发更精细的查询行为检测与自适应响应策略，二是从训练层面降低智能体执行轨迹中可被差分利用的确定性暴露。
