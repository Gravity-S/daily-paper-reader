## 摘要
学习得到的世界模型正成为通用智能体不可或缺的一部分：通过预测动作后果，它们支持规划与决策，同时减少对昂贵试错的依赖。这种依赖带来一个根本性的歧义：当由世界模型引导的决策失败时，仅凭轨迹可能无法揭示造成损失的是智能体的决策规则还是世界模型。我们将这一失败归因问题形式化为回报损失的反事实分解，并证明其分量无法从被动交互中辨识，即使对有限时域规划器亦然。这一障碍促使我们提出 Dual-Frontier，一种学习原则：仅当世界模型引导决策的预测优势超过与决策相关的世界模型误差的已认证界时，才接纳该决策；否则，将证据分配用于世界模型验证。动作条件价值界与闭环扩展保证被接纳决策的回报非递减。校准门控与同时置信序列支持自适应证据复用，并给出充分且必要的验证界。受控的学习模型实验验证了所预测的失败模式与认证行为，而跨骨干工具使用基准在真实智能体世界模型流水线中实例化了相同的“先验证后提升”规则，持续提升决策质量与可靠性。

## Abstract
Learned world models are becoming essential to general-purpose agents: by predicting action consequences, they support planning and decision-making while reducing reliance on costly trial and error. This reliance creates a fundamental ambiguity: when a world-model-guided decision fails, the trajectory alone may not reveal whether the agent's decision rule or the world model caused the loss. We formalize this failure-attribution problem as a counterfactual decomposition of return loss and prove that its components are not identifiable from passive interaction, even for finite-horizon planners. This obstruction motivates Dual-Frontier, a learning principle that admits a world-model-guided decision only when its predicted advantage exceeds a certified bound on decision-relevant world-model error; otherwise, evidence is allocated to world-model verification. Action-conditioned value bounds and a closed-loop extension guarantee non-decreasing return for admitted decisions. Calibrated gates and simultaneous confidence sequences support adaptive evidence reuse, with sufficient and necessary verification bounds. Controlled learned-model experiments validate the predicted failure modes and certification behavior, while cross-backbone tool-use benchmarks instantiate the same verify-then-promote rule in realistic agent world-model pipelines, consistently improving decision quality and reliability.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：学习型世界模型正成为通用智能体的核心基础设施。通过预测动作后果，世界模型支撑规划与决策，减少对昂贵在线试错的依赖。代表性系统包括 DreamerV3、TD-MPC2、导航/操作/驾驶/网页交互等领域的世界模型，以及 WorldEvolver、CoMAP、PaW、GenEnv 等自适应或协同演化系统。
- **核心歧义（研究问题）**：当由世界模型引导的决策失败时，仅凭轨迹无法判断损失来源是**智能体的决策规则**还是**世界模型本身**。同一失败轨迹既可能源于"不充分的规则忽略了准确预测"，也可能源于"不准确的预测误导了原本合理的规则"。作者将这一问题称为**失败归因（failure attribution）**。
- **形式化障碍**：论文将失败归因形式化为回报损失的反事实分解 `R = A + W`，其中 `A = J* − J(π°)` 为智能体固有遗憾，`W = J(π°) − J(π̂)` 为世界模型效应（带符号）。**定理 1** 证明：即使对有限时域规划器，仅凭被动交互（含无限次被动重复）也无法辨识这两个分量，极小极大误差下界为 `c/2`，端点分类误差为 `1/2`。
- **操作含义**：对误导性世界模型进行学习可能强化坏决策；而在预测已充分时继续采集数据则浪费证据。全局预测精度无法解决该问题——感知质量与闭环成功可以背离，任意小的转移误差可能反转几乎打平的动作，而无关坐标上的大误差可能毫无影响。
- **核心主张**：可靠性应在**决策边界**上判断——关键不是模型是否全局准确，而是当前证据是否足以支持依赖它的那个具体动作。这促成了"**先验证后提升（verify-then-promote）**"原则。

## 2. 方法论：核心思想、关键技术细节与公式流程

### 2.1 反事实归因与不可识别性

- **设定**：任务 `z` 下真实世界 `Mz = (S, A, Pz, rz, ρz, H)` 与学习世界模型 `M̂z = (S, A, P̂z, r̂z, ρz, H)` 共享状态/动作空间、初始分布与有限时域。固定算子 `Aϕ` 将世界映射为策略，仅替换世界得到 `π̂ = Aϕ(M̂)`、`π° = Aϕ(M)`。
- **分解**：`R := J* − J(π̂) = [J* − J(π°)] + [J(π°) − J(π̂)] = A + W`，其中 `R, A ≥ 0`，`W` 为带符号的世界模型效应。
- **定理 1（被动不可识别性）**：对任意 `c ∈ (0, R̄]`，存在两步真实世界族（由 `λ ∈ [0,c]` 索引），使得 `(A, W) = (λ, c−λ)` 且任意多次部署回合的观测律完全相同。任何基于这些回合、已知算子与供给世界模型的归因估计器满足 `sup_λ Eλ|Â − λ| ≥ c/2`。构造中供给世界模型在部署占用上甚至可以完全精确，歧义全部隐藏于未尝试动作中。
- **Proposition 1**：不存在通用模数 `ω(ε)` 能统一界定 `|W|`——预测可靠性不识别黑箱算子的模型效应。
- **Proposition 2（干预恢复）**：在固定参考策略下，用 `m` 条独立回合可得到 `|Â − A| ≤ 2t + ω`、`|Ŵ − W| ≤ 2t`，说明干预可恢复缺失信息，但需付出代价。

### 2.2 世界模型可靠性认证（定理 2–3）

- **请求定义**：`x = (z, M̂, π0, π1)`，`ΓM(x) = JM(π1) − JM(π0)`，`ℓC(x) = inf_{N∈C} ΓN(x)`。`ℓC > 0` 即认证改进；未认证不等于有害。
- **Bellman 残差恒等式（定理 2）**：
  - 定义 `∆πt = r − r̂ + (P − P̂)V̂π_{t+1}`
  - 精确恒等式：`J(π) − Ĵ(π) = Σ_t E_{μπt} ∆πt`
  - 误差界：`|J(π) − Ĵ(π)| ≤ εI(π) = Σ_t E_{μπt}[|r−r̂| + span(V̂π_{t+1})·TV(P,P̂)]`
  - 两策略对比下界：`J(π1) − J(π0) ≥ Ĵ(π1) − Ĵ(π0) − εI(π1) − εI(π0)`
- **Corollary 1（规划遗憾）**：若 `Ĵ(π̂) ≥ sup_π Ĵ(π) − δp`，则 `J* − J(π̂) ≤ sup_π εI(π) + δp + εI(π̂)`。
- **Corollary 2**：任意小的均匀转移误差可反转世界模型贪心动作排序；TV 为 1 可同时对所有策略值精确——认证必须比较预测误差与所涉优势。
- **定理 3（闭环可靠性）**：固定参考策略 `π0`，对候选核 `κt` 定义局部优势 `dt(s)`、`d̂t(s)` 与不确定半径 `Bt(s)`。令 `Tt = St − Bt − ξt`，门控 `gt = I{Tt > 0}`，`νt = gt κt + (1−gt)π0,t`，则 `J(ν) − J(π0) ≥ Σ_t ∫ gt(s)Tt(s) ρνt(ds) ≥ 0`，严格改进在正裕度干预以正概率被触达时成立。均匀误差下 `bt = (H−t)εr + ½(H−t)(H−t−1)R̄b εp`。

### 2.3 Dual-Frontier 学习原则（第 5 节）

- **三个量**：`S(x)` 估计预测优势 `Γ̂(x)`；`B(x)` 界定世界模型失真；`ξ(x)` 界定估计误差。
- **认证裕度**：`T(x) = S(x) − B(x) − ξ(x)`。
- **双前沿**：
  - 世界模型前沿 `FW = {x : S(x) > ξ(x), B(x) ≥ S(x) − ξ(x)}`（有前景但未认证，需验证）
  - 智能体前沿 `FA = {x : T(x) > 0}`（已认证改进，可采纳）
  - `S ≤ ξ` 的请求被延后（第三类，避免把"证据不足"误判为模型无知或智能体无能）
- **校准不确定性（Proposition 7）**：用分裂共形预测，拟合非负分数 `u` 于独立校准请求，`qj = ej − u(xj)`，`k = ⌈(n+1)(1−α)⌉`，`B(x) = [u(x) + q(k)]+`，则 `P{e(x) > B(x)} ≤ α`。若 `P{Γ̂ ≥ S − ξ} ≥ 1−δ`，则错误提升风险 `P{T > 0, ΓM ≤ 0} ≤ α + δ`。
- **自适应证据复用（定理 4）**：有限平稳任务下用 `an = √((D log2 + log(4m/α))/(2n))` 构造世界置信集 `C`，令 `K = R̄b H(H−1)`、`ui = max_{s,a} min{1, TV(P̄, P̂i) + an}`，仅当 `Ti = Si − K ui − ξi > 0` 时接受。坏提升概率 `≤ α + Σ δi`。一次审计成本 `mn`，与后续比较次数无关。
- **进展与证据代价**：`J(πn) − J(π0) ≥ Σ Ti`；固定正裕度只能出现有限次：`|{i : Ti ≥ τ}| ≤ (HR̄b − J(π0))/τ`。充分审计样本量 `n > 2K²/a²·[D log2 + log(4m/α)]`；必要下界（Proposition 10）为 `n ≥ kl(1−δ, δ)/(16γ²)`，即 `Θ(γ⁻²)` 的逆平方统计代价。
- **可选微分扩展（定理 5–6）**：对可微策略给出梯度误差球 `b̂θ`，若 `b̂θ < ‖ĝ‖₂` 则真实梯度与想象梯度夹角为锐角；局部改进 `J(θ+) − J(θ) ≥ ηh[(1−Lη/2)h − b]`，当 `h > b` 时取 `η = (h−b)/(Lh)` 保证 `(h−b)²/(2L)` 改进。
- **自适应新验证（定理 7）与优先级核算（定理 8）**：允许任意任务切换，但需每轮支付新的验证代价 `εk`；无迁移、单调优先级假设下完成成本 `B = B* + m`。

### 2.4 算法流程（文字化）

1. 给定请求 `x`，世界模型提出候选策略 `π1` 与参考 `π0`；
2. 估计预测优势 `S(x)`，计算世界模型误差界 `B(x)` 与估计误差界 `ξ(x)`；
3. 若 `T(x) = S − B − ξ > 0`，采纳候选（智能体前沿）；
4. 否则若 `S > ξ` 且 `B ≥ S − ξ`，进入世界模型前沿，将证据分配至针对性验证（如动作条件查询、行审计）；
5. 验证后更新世界模型或置信集，重复；校准门控与同时置信序列保证自适应复用下的族错误率控制。

## 4. 实验结果：主要发现与证据

### 4.1 受控有限世界（6.1 节）

- **失败归因不可识别性被实证复现**：在 400 个配对构造中，被动观测在未观测动作上的隐藏世界效应完全无法区分；所有基于被动记录的无干预归因器在端点分类上接近 `1/2` 错误率，与定理 1 的极小极大下界一致。加入单个针对性行审计后，归因误差显著塌缩。
- **决策相对认证优于全局精度门控**：
  - 无条件接受正想象（Always-WM）在稀疏与链式世界上产生明显的**有害使用率**，因为小的转移误差足以反转接近打平的动作；
  - 仅凭不确定性拒绝（Confidence）能过滤部分噪声，但会同时拒绝大量本可安全采纳的请求，牺牲增益；
  - 决策相对认证在保持低有害使用率的同时保留了大部分真实增益，价值误差与更新方向余弦均更优。
- **在线运行**：在相等真实转移预算下，决策导向证据采集相比无门控与均匀门控取得更高净增益——均匀门控把审计预算浪费在对决策边界无关的坐标上。
- **证据复杂度标度**：实测必要审计样本量随裕度 `γ` 呈 `Θ(γ⁻²)` 增长，与 Proposition 10 的逆平方下界吻合；证据复用实验显示，一次审计（8 行、`m` 个比较）在 `K` 增大时坏提升概率保持在 `α + Σδi` 预算内，验证了定理 4 的族错误率控制。

### 4.2 智能体–世界模型基准（6.2 节）

- **总体趋势**：Dual-Frontier 在 BFCL v4、API-Bank、NexusRaven 上相对 Agent-only 取得一致的净增益，且有害使用率显著低于 Always-WM，证据开销低于 Confidence/Consistency 的过度拒绝代价。
- **骨干无关性**：Llama-3.1-8B-Instruct 与 Qwen3-8B 两个骨干上结论方向一致，说明门控收益不依赖特定基座模型。
- **与前沿模型对比**：前沿模型在原始任务成功率上仍具优势，但在"何时信任世界模型"的元决策上，Dual-Frontier 门控后的 8B 组合缩小了与前沿模型的差距，尤其在异构工具 schema（NexusRaven）上，认证机制有效抑制了世界模型对陌生 schema 的过度自信。
- **方法间对比**：Pessimistic 虽降低有害使用率，但因对未认证请求一律拒斥而损失增益；Dual-Frontier 通过双前沿把"证据不足"与"模型无知"分离，在增益–风险权衡上更接近理想前沿。

### 4.3 消融与机制分析

- **移除 `B(x)`（世界模型误差界）**：错误提升率显著上升，验证共形校准界是控制风险的关键。
- **移除 `ξ(x)`（估计误差界）**：在样本稀少时误采纳增加，说明需同时控制估计噪声。
- **移除第三类延后（`S ≤ ξ`）**：会把证据不足误判为模型无能或智能体无能，导致不必要的模型更新与证据浪费。
- **校准集比例**：20% 校准集在 α=0.05 下给出可接受的覆盖率与检验功效平衡。

## 5. 结论与整体贡献

- **概念贡献**：明确提出**失败归因**问题，并证明仅凭被动交互无法识别智能体固有遗憾 `A` 与世界模型效应 `W`，为"何时可以信任世界模型"给出可操作的形式化边界。
- **理论贡献**：给出 Bellman 残差恒等式、规划遗憾界、闭环可靠性定理，证明任意小误差即可反转动作排序，从而论证**决策相对认证**的必要性；并给出双前沿准则、共形校准的族错误率保证、证据复用的同时置信序列与 `Θ(γ⁻²)` 证据复杂度下界。
- **方法贡献**：提出 verify-then-promote 的 Dual-Frontier 学习原则与算法流程，把可靠性判断从"全局预测精度"转移到"决策边界上的认证裕度"。
- **实证贡献**：在受控有限世界与 LLM 智能体–世界模型基准上验证了理论预测，表明决策相对认证在增益、风险与证据开销三者间取得更好权衡。

## 6. 局限与未来工作

- **假设依赖**：定理 3、4 依赖固定参考策略、有限平稳任务与单调优先级等假设；在非平稳、任务分布漂移或参考策略频繁变化时，认证与复用保证需重新推导。
- **界可能保守**：均匀误差下的 `bt` 界在长时域、大值域下偏保守，可能低估可认证的请求比例。
- **审计成本**：针对性审计虽比全局探索高效，但在高维连续动作空间中，行审计与动作条件查询的可扩展性仍待验证。
- **微分扩展**：定理 5–6 的可微情形目前仅在局部改进意义下成立，全局收敛性与鞍点行为未充分刻画。
- **评测范围**：基准评测受限于所选三个函数调用/API 类 benchmark 与两个 8B 骨干，尚未覆盖导航、操作、驾驶等具身场景，也未评估更大规模或专有世界模型。
- **未来方向**：将认证扩展到部分可观测与多智能体设定；与主动探索、模型集成、贝叶斯世界模型结合以缩小 `B(x)`；探索把认证裕度作为世界模型训练的显式目标，从而让模型"在决策边界上更可靠"而非"全局更精确"。

---

## 7. 一句话总结

Dual-Frontier 的核心洞见是：**世界模型的可靠性不是一个全局属性，而是一个相对于具体决策的、可被认证的局部属性**——只有当预测优势超过世界模型失真与估计误差之和时，智能体才应采纳该建议；否则应进入世界模型前沿进行有针对性的验证，而非盲目信任或一味拒绝。
