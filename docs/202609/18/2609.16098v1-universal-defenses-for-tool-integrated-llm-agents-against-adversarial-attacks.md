## 摘要
大语言模型（LLM）智能体已在多个领域展现出令人瞩目的能力，尤其是在与外部工具集成以完成多步任务时。然而，它们越来越容易受到对抗攻击，包括直接提示注入、间接提示注入、记忆投毒和后门攻击，这些攻击利用了模型对提示注入和工具操纵的开放性。在本工作中，我们在一个统一框架内探索了针对这四类攻击的实用且可泛化的防御策略。我们引入了两种通用的基于工具的防御：攻击者工具过滤（Attacker Tool Filtering），其使用异常检测（例如 Isolation Forest）来识别并移除可疑工具；以及正常工具召回（Normal Tool Recalling），这是一种白盒方法，可在规划之前恢复智能体原有的工具集。此外，我们还结合了基于提示的防御：思维链提示（Chain-of-Thought prompting）和自我反思技术以增强推理，并通过任务复述来缓解攻击。在四个开源LLM（Gemma2-9B、Qwen2-7B、LLaMA3-8B和LLaMA3.1-8B）以及三个专有LLM（GPT-3.5、GPT-4和GPT-5）上的实验结果表明，我们的方法显著降低了攻击成功率（ASR），在许多设置中实现了0% ASR，同时保持甚至提高了原始任务成功率。这些发现凸显了简单、模块化、多层防御在增强工具集成LLM智能体的安全性和鲁棒性方面的前景。代码见 https://github.com/Xiaoyan-Lisa/Defenses-for-Tool-Integrated-LLM-Agents-Against-Adversarial-Attacks。

## Abstract
Large Language Model (LLM) agents have demonstrated impressive capabilities across a variety of domains, particularly when integrated with external tools for multi-step task completion. However, they are increasingly vulnerable to adversarial attacks, including direct prompt injection, indirect prompt injection, memory poisoning, and backdoor attacks, which exploit the model's openness to prompt injection and tool manipulation. In this work, we explore practical and generalizable defense strategies within a unified framework across these four attack types. We introduce two universal tool-based defenses: Attacker Tool Filtering, which uses anomaly detection (e.g., Isolation Forest) to identify and remove suspicious tools, and Normal Tool Recalling, a white-box method that restores the agent's original toolset prior to planning. Additionally, we incorporate prompt-based defenses: Chain-of-Thought prompting and self-reflection techniques to enhance reasoning and task paraphrasing to mitigate attacks. Experimental results across both four open-source LLMs (Gemma2-9B, Qwen2-7B, LLaMA3-8B, and LLaMA3.1-8B) and three proprietary LLMs (GPT-3.5, GPT-4, and GPT-5) show that our methods significantly reduce the Attack Success Rates (ASR), achieving 0% ASR in many settings, while preserving or even improving the original task success rate. These findings highlight the promise of simple, modular, multi-layered defenses for strengthening the security and robustness of tool-integrated LLM agents. The code is available at https://github.com/Xiaoyan-Lisa/Defenses-for-Tool-Integrated-LLM-Agents-Against-Adversarial-Attacks.

# 论文总结：面向对抗攻击的工具集成 LLM 智能体通用防御

## 1. 核心问题与研究动机

- **背景**：LLM 智能体越来越多地集成外部工具（API、数据库、搜索引擎、代码执行环境）以完成多步任务，这显著扩展了其现实影响力，但也放大了攻击面。
- **核心问题**：与传统的越狱攻击（主要影响文本生成）不同，针对工具的对抗攻击可导致**不可逆后果**——未授权数据访问、有害命令执行、与外部系统通信被劫持。
- **四类主要攻击**：直接提示注入（DPI）、间接提示注入（IPI）、记忆投毒（MP）、后门攻击（如 PoT 后门）。
- **现有防御的缺陷**：
  - 多为**攻击专用**，缺乏通用方案；
  - 以**黑盒**为主，忽视白盒/灰盒方法；
  - 聚焦于修改攻击提示，而非处理被攻击劫持的**工具本身**；
  - ASB 等大规模研究显示多数防御效果有限，且常**损害原始任务性能**。
- **研究目标**：提出轻量、模型无关、模块化的多层通用防御，兼顾工具调用完整性与原始任务效用。

## 2. 方法论

### 2.1 总体架构：三层防御

- **外层**（用户输入后、规划前）：CoT 提示 + 改写净化，针对 DPI 与后门攻击。
- **中层**：工具过滤，在工具被调用前检查工具描述并屏蔽不安全工具。
- **内层**：自反思提示，在执行前校验生成计划的正确性。

### 2.2 基于工具的防御（核心创新）

- **攻击者工具过滤（ATF）**
  - 核心假设：攻击者注入的工具在语义上通常偏离用户原有工具。
  - 流程：对每个工具描述 τᵢ 用句级嵌入模型 ϕ 编码得到 E = {ϕ(τᵢ)}；在 E 上训练带污染率 ϵ 的 Isolation Forest；判定 yᵢ=1 为异常、yᵢ=0 为正常；过滤得到 T_filtered = {τᵢ | yᵢ=0}，智能体仅基于过滤后工具集规划。
  - 特点：无监督、无需攻击先验、额外开销极小。

- **正常工具召回（NTR）**
  - 白盒方法：假设用户的原始工具集 T_user 已被安全保存；在规划开始前，将智能体当前可见（可能被污染）的工具集 T_current 直接覆盖为 T_user，即 T_effective ← T_user。
  - 规划形式化：P = LLM(p_sys, q, O, T_effective)，其中 q 为用户指令、O 为先验观测。
  - 特点：**无需检测攻击、无需识别恶意工具**，仅通过恢复可信工具配置强制工具集完整性，简单且精确。

### 2.3 基于提示的防御

- **思维链提示（CoT）**：采用结构化形式，要求以 JSON 格式生成至少两步计划，强制多步推理与安全工具选择，降低执行注入指令的概率。
- **改写净化（Paraphrasing）**：用 GPT-4o-mini 重写用户任务，在保留原任务语义的同时**显式引用良性工具**；既强化与用户意图对齐，又破坏绕过模式、伪造响应、隐藏触发词等对抗结构。
- **自反思（Self-Reflection）**：受 Reflexion 启发，LLM 同时充当反思模块与评估器，校验计划（至少两步、tool_use 非空、工具必须在允许列表内、步骤逻辑连贯），输出有效或修正后的 JSON，无需外部反馈。

## 3. 实验设计

- **Benchmark**：ASB（Agent Security Bench），包含 10 个领域专用智能体，每个智能体 400 个任务（200 攻击性 + 200 非攻击性）。
- **攻击设置**：
  - DPI/IPI：Naive Attack、Escape Characters、Context Ignoring、Fake Completion；
  - MP：Fake Completion + Context Ignoring 组合策略；
  - 后门：PoT 后门攻击，触发词分非词型（如 "@_@"）与短语型（如 "with perspicacious discernment"）。
- **评测模型（7 个）**：开源 Gemma2-9B、Qwen2-7B、LLaMA3-8B、LLaMA3.1-8B；闭源 GPT-3.5、GPT-4、GPT-5。
- **评价指标**：攻击成功率 ASR（越低越好）、原始任务成功率 OTSR（越高越好）。
- **对比基线**：
  - 无防御（attack-only）；
  - DPI 与后门：ASB 的 Paraphrasing（被视为最优 DPI 防御）；

## 6. 主要结论与发现

- **NTR 是最有效的单点防御**：在 DPI、IPI、MP、后门四类攻击中，NTR 组合方案可将 ASR 降至 0 或接近 0（如 GPT-3.5/GPT-4 的 DPI、所有模型的 MP），并在 GPT-5 上实现 0% ASR 且提升 OTSR。
- **ATF 有效但不稳定**：能降低部分模型的 ASR，但在 IPI/MP 等场景波动较大，偶尔伴随 OTSR 下降。
- **提示防御中 Paraphrasing 贡献最大**：单独使用效果有限，但与 NTR + CoT 组合后显著改善 ASR 与 OTSR；CoT 主要提升 OTSR；Reflection 对 Gemma2、LLaMA3/3.1 有益，但对 Qwen2 与 GPT 系列（尤其 GPT-3.5）反而降低 OTSR。
- **大模型不一定更安全**：无防御下 GPT-3.5/GPT-4 的 DPI ASR 高于小型开源模型，说明更强泛化能力可能反而更难区分恶意与良性提示。
- **鲁棒性—效用权衡**：GPT 系列在防御干预下 OTSR 常显著下降；小模型则更多同时受益于攻击抑制与任务完成提升。
- **模型间差异显著**：LLaMA3 本身已较鲁棒，叠加防御收益递减；GPT-5 推理能力强，但叠加过多防御提示会导致 OTSR 近 0。
- **总体判断**：多层、模块化、轻量防御可有效提升工具集成智能体的安全性与鲁棒性，但效果依赖攻击类型与模型。

## 7. 优点

- **统一性**：单一框架同时应对 DPI、IPI、MP、后门四类攻击，打破以往"一攻击一防御"的碎片化格局。
- **工具视角的创新**：将防御焦点从"修改攻击提示"转向"保护工具调用链路"，ATF 与 NTR 均不需攻击先验知识。
- **NTR 设计极简而有效**：仅需恢复可信工具集即可实现接近 0 的 ASR，无需检测、无需识别恶意工具，工程落地成本低。
- **白盒 + 黑盒融合**：ATF/NTR（工具层）与 CoT/改写/自反思（提示层）互补，形成纵深防御。
- **双指标评估**：同时报告 ASR 与 OTSR，避免"安全但不可用"的伪成功，并明确指出效用损失。
- **跨模型验证**：覆盖 4 个开源 + 3 个闭源模型，包括最新 GPT-5，结论具备一定普适性参考价值。
- **消融分析**：明确了各防御组件的边际贡献，为后续组合设计提供依据。

- **算力信息缺失**：未报告 GPU 型号、数量与耗时，可复现性与成本评估受限。
- **实验覆盖不全**：

- **结果内部一致性存疑**：如 GPT-3.5 在 ATF 下 ASR 与 OTSR 同时趋近 0，ATF 在 LLaMA3 上 ASR 升高，论文对此解释较为简略。
- **对比基线有限**：仅与 ASB 内置防御比较，未纳入近年其他提示注入防御工作。
