## 摘要
执行长时程操作任务的分层机器人系统必须做出高层语义决策，以协调具有随机性的低层技能。在此背景下，失败的 rollout 具有歧义性：较差的下游状态可能反映无效的高层决策、部分观测，或一个有效但物理执行失败的决策。传统监督学习缺乏此类恢复状态的数据，而强化学习则难以应对稀疏奖励和非局部信用分配。我们提出 MAGMA-GEN，一种在策略数据生成流程，可将模糊的失败 rollout 转换为经过验证的恢复监督。MAGMA-GEN 首先使用特权教练来假设早期决策层面的错误，并提出局部修正或恢复动作。由于该诊断可能出错，只有在匹配条件下从同一状态重执行能够改善下游进展时，候选方案才会被保留。这会从智能体自身的失败分布中生成监督样本，而无需逐步人工示范。在交互式长时程操作任务上评估时，MAGMA-GEN 在仿真和真实机器人执行中，在任务约束不断演化的条件下，相较于蒸馏和轨迹修复基线，提高了任务成功率和恢复能力。

## Abstract
Hierarchical robotic systems executing long-horizon manipulation tasks must make high-level semantic decisions that orchestrate stochastic low-level skills. In this setting, failed rollouts are ambiguous: a poor downstream state may reflect an invalid high-level decision, partial observation, or a valid decision whose physical execution failed. Traditional supervised learning lacks data for such recovery states, while reinforcement learning struggles with sparse rewards and non-local credit assignment. We propose MAGMA-GEN, an on-policy data-generation pipeline that converts ambiguous failed rollouts into validated recovery supervision. MAGMA-GEN first uses a privileged coach to hypothesize an early decision-level error and propose localized correction or recovery actions. Because this diagnosis is fallible, candidates are retained only if re-execution from the same state under matched conditions improves downstream progress. This produces supervised examples from the agent's own failure distribution without per-step human demonstrations. Evaluated on interactive long-horizon manipulation tasks, MAGMA-GEN improves task success and recovery capabilities, against distillation and trajectory-repair baselines under evolving task constraints in both simulation and real-robot execution.

# MAGMA-GEN 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：分层机器人系统在执行长时程（long-horizon）交互式操作任务时，高层策略需要输出语义决策（自然语言回复 + 工具调用），以调度带有随机性的低层技能（抓取、放置、关门等）。真实部署中，目标与规则会通过交互被逐步引入、修正甚至临时覆盖，智能体还需在部分观测下工作。
- **核心痛点——失败的歧义性**：一次失败 rollout 的负面结果可能来自三种完全不同的原因：
  1. 高层决策本身无效（决策错误）；
  2. 观测不完整（partial observation）；
  3. 决策本身有效，但物理执行随机失败。
- **现有方法的不足**：
  - 传统监督学习缺乏此类“恢复状态”的数据；
  - 强化学习面临稀疏奖励与长时程非局部信用分配困难；
  - 近期恢复导向方法（RAC、Fail2Progress）多聚焦低层视觉运动调整，或依赖人工监督；
  - 轨迹修复类方法（CLEANER、AutoTraj）缺少“局部诊断 + 匹配反事实验证”的组合机制。
- **整体含义**：论文主张——**不应把“失败”直接当作决策错误的标签**，而应把诊断视为可错的“假设”，用仿真器在同一状态下的匹配重执行来验证，从而把模糊失败转化为可信的监督信号。

## 2. 方法论

### 核心思想
- 用**特权教练（privileged coach，20B LLM）** 对失败子轨迹提出“早期决策级错误”的假设，并生成**局部干预**（纠正或恢复动作）；再通过**反事实重执行**筛选，仅保留能提升下游进展的候选，最终以标准监督学习目标训练 4B 策略。
- 关键立场：**教练诊断本身不是真值标签**，仿真重执行才是筛选器。

### 问题形式化
- 任务建模为 POMDP：`P = ⟨S, A, O, T, Ω, ρ₀⟩`；全状态 `s_t = (w_t, z_t, k_t)`，其中 `z_t = (g_t, R_t^u)` 为潜在任务（目标 + 活跃规则），`k_t` 为可观测结构化属性。
- 动作 `a_t = (a_t^u, a_t^m)`，即自然语言回复 + 工具调用 `(u_i^t, x_i^t)`；观测 `o_t = (k_t, q_t)`，`q_t` 为用户指令或工具反馈。
- 引入不可观测的**有效性变量** `valid(a_t, z_t) ∈ {0,1}`：无效 = 决策错误；有效但仍可能因随机执行失败。观测到的失败因此因果歧义。

### 关键技术流程
1. **按阶段切分**：每条轨迹按活跃目标/规则划分为阶段 j，子轨迹记为 τ⁽ʲ⁾。
2. **失败分型（failure typing）**：赋粗粒度失败类别 c⁽ʲ⁾（阶段级：目标失败、次优完成；接口级：缺失动作、非法工具调用、格式错误、文本一致性错误），用于限制干预空间。
3. **局部诊断**：理想干预点 ℓ⋆ = 首个违反任务规范的动作索引，但不可观测。因此教练建模为**提议分布**而非 oracle：`(ℓ, d⁽ʲ⁾) ~ q_diag^φ(· | τ⁽ʲ⁾, c⁽ʲ⁾, z⁽ʲ⁾)`，实现为受约束的 LLM 提示。
4. **反事实干预**：`I⁽ʲ⁾_φ ~ q_corr^φ(· | d⁽ʲ⁾, a_ℓ, z⁽ʲ⁾, U)`，候选子集为 `{ã_ℓ, ã_{ℓ+1}}`——前者为**纠正**（替换疑似错误动作），后者为**恢复**（在执行失败后的偏离状态上追加动作）。均在既有高层工具调用接口内操作，不修改底层感知/控制。
5. **Rollout 树与匹配重执行**：恢复仿真器到父状态 s_t，执行候选动作，再让当前策略继续，直至阶段成功或失败；原 rollout 与反事实分支共同构成树。同时在每个展开状态从策略采样 B 个动作（分支因子 B）以增密数据。
6. **结构化不确定性**：抓取不稳、不可达、部分检测、反馈缺失等扰动在每个阶段开始时采样一次，**兄弟分支间保持固定**，以保证分支比较公平。
7. **从树到监督数据**：
   - 子树立方成功率：`Succ_j(s_i, a) = (1/|R_K|) Σ 1{τ_r 完成阶段 j}`（K 条后代 rollout）；
   - 对每个状态选 `a⋆ = argmax_a Succ_j(s_i, a)`，且仅在 `Succ_j(s_i, a⋆) > 0` 时保留；
   - 所有动作（策略采样与教练提议）在同一候选集合中平等竞争，不偏袒教练答案；
   - 监督目标为标准 SFT：`L_MAGMA(θ) = −Σ log π_θ(a_t | m_t, o_t, U)`。
8. **工程细节**：阶段级树扩展控制（避免指数爆炸与过早坍缩到单轨迹）；SimUser（GPT-OSS-20B）在阶段边界生成自然语言指令但保持潜在目标/规则不变；对工具名、参数名、属性名、物体表述做接口随机化。

## 6. 主要结论与发现

- **恢复能力（Q1）**：MAGMA-GEN 平均恢复率 **26.25%**，比最强基线（Best-of-N 20B 重试，16.66%）高 **9.59 个百分点**，且其 rollout 策略仅 4B，弱于基线的 20B 专家。
- **长时程进展（Q2）**：CSR **16.79%**、CGC **30.74%** 均为最高，说明恢复监督并未以牺牲长时程表现为代价。绝对 CSR 普遍偏低，反映 18 步时程下的误差累积。
- **分支因子与真机（Q3）**：B 从 1 提升到 2，CSR 16.79% → **38.35%**，恢复率 26.25% → **40.0%**（同样 B=2 的专家蒸馏对照仅 26.99% / 18.33%）。真机 OOD：MAGMA-GEN 15/30，优于专家蒸馏 12/30 与 CLEANER 11/30；含学习感知与抓取栈时 11/24 vs 8/24 与 9/24。
- **机制必要性**：去掉重执行验证，恢复率跌至 5.00%；再去掉教练则跌至 1.66%；CSR 与 CGC 同序下降——**教练提议与重执行验证二者缺一不可**。
- **诊断的价值**：教练提议的反事实验证通过率 54.54%，显著高于 CLEANER 即时纠正的 30.97%，说明“先诊断出责任决策再纠正”提升了纠正质量。
- **随机执行失败训练的必要性**：注入执行失败使恢复率从 14.17 提升至 26.25，CSR 从 12.05 提升至 16.79。
- **收集效率**：更少的 20B 调用（3585 vs 6440+）换来更高的阶段覆盖率（77.56% vs ≤63.67%）与更多阳性样本（3769 vs ≤2137）。

## 7. 优点

- **方法层面的概念清晰**：把“失败归因”从“接受结果归因”转为“提出假设 + 执行验证”，有效回避了歧义失败导致的信用分配污染，同时避免了 RL 的稀疏奖励问题。
- **保持监督学习接口**：最终仍是标准 SFT，工程上简单、稳定，不需要奖励模型或策略梯度。
- **保留失败分布**：不同于轨迹修复（丢弃失败轨迹），MAGMA-GEN 保留失败 rollout 并**补充局部验证过的纠正**，使监督数据贴合策略自身的状态分布，覆盖专家数据中不存在的恢复状态。
- **引导式探索**：教练把额外的反事实试验**定向分配**到最可能导致失败的动作上，比盲目重采样更高效（表 2 的资源-产出比印证）。
- **验证协议的严谨性**：匹配重执行 + 阶段级扰动固定 + 子树立方成功率选择 + 不偏袒教练答案（所有候选同池竞争），保证了标签质量与比较公平。
- **消融设计有说服力**：两个核心组件单独剥离，且对“诊断是否提升纠正有效性”给出定量证据（54.54% vs 30.97%）。
- **兼顾仿真与真机**：真机使用冻结策略、无教练无仿真器，验证了方法的可部署性与 OOD 迁移可行性。
