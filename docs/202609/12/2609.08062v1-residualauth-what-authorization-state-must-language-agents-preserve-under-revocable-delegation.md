## 摘要
使用工具的语言智能体可以通过外部服务行事，同时委托和撤销权限。我们表明，两个授权历史可以具有相同的当前权限和相同的全对可达性，但在相同的直接边撤销后却需要做出相反的决策。我们将保留此类区分所需的信息形式化为残差授权状态。我们证明，指数多个未来可区分状态可以共享同一个固定传递闭包，并给出当委托冗余变化时，精确监控器所需状态的精确或紧渐近界。ResidualAuth 将这些构造编译为成对的语言智能体片段。在四个开放权重模型上，固定的 256 token 摘要解决了 0–2/16 对，虚假读取解决了 0/16，经认证的当前查询读取解决了 15–16/16。在一项单独的留出在线记忆诊断中，精确账本序列化在 768 和 1,024 token 两种上限下均能容纳所有 128 个四坐标对。在任一上限下，有事实依据的模型撰写记忆即使足以支持每个预先指定的延续，每个模型也最多解决 1/128 对。一个硬门控将观察到的八次未授权效果降至零，且未改变此前的尝试。这些结果区分了所需授权状态、可用决策信息、在线状态维护和效果中介。

## Abstract
Tool-using language agents can delegate and revoke permissions while acting through external services. We show that two authorization histories can have identical current permissions and identical all-pairs reachability yet require opposite decisions after the same direct-edge revocation. We formalize the information needed to preserve such distinctions as a residual authorization state. We prove that exponentially many future-distinct states can share one fixed transitive closure, and give exact or tight asymptotic bounds on the state required by an exact monitor as delegation redundancy varies. ResidualAuth compiles these constructions into paired language-agent episodes. Across four open-weight models, a fixed 256-token summary solved 0-2/16 pairs, sham reads solved 0/16, and authenticated current-query reads solved 15-16/16. In a separate held-out online-memory diagnostic, exact ledger serializations fit all 128 four-coordinate pairs at both 768 and 1,024 tokens. At either cap, factually supported model-written memories sufficient for every prespecified continuation solved at most 1/128 pairs per model. A hard gate reduced eight observed unauthorized effects to zero without changing the preceding attempts. These results distinguish required authorization state, usable decision information, online state maintenance, and effect mediation.

# ResidualAuth：在可撤销委托下语言智能体必须保留的授权状态

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：使用工具的语言智能体可通过邮件、支付、文件、基础设施等外部 API 行事，并能**委托（delegate）**与**撤销（revoke）**权限。权限随时间跨多轮演化，因此未来某个动作是否合法，可能取决于当前权限"是如何被创建出来的"，而不只是"现在谁能行动"。
- **核心反例（Fig. 1）**：根主体 o 委托给经理 m，m 再委托给用户 u；历史 A 中只有链式委托，历史 B 中额外存在 o 直接授予 u 的边（o→u）。两者**当前权限相同、全对可达性（transitive closure）完全相同**，但当撤销边 o→m 后，u 在 A 中失去权限、在 B 中仍被授权——同一撤销导致**相反决策**。
- **形式化表述**：TC(G_A) = TC(G_B)，但 ρ(h_A) ≠ ρ(h_B)，其中 ρ(h) 是历史 h 之后仍然合法的未来动作序列集合。
- **核心问题**：不是"智能体是否记住了当前状态"，而是"保留的状态是否足以支撑**所有未来**授权决策"。当前授权是可达性问题；而**边可寻址撤销（edge-addressable revocation）**下的未来授权取决于产生该可达性的**直接授权边（grant provenance / 直接边来源）**——这区别于数据流监控所研究的值/工具参数来源。
- **整体含义**：论文把这一区分形式化为**残余授权状态（residual authorization state）**，刻画并计数"未来可区分状态"，并进一步区分四个层次：**必需的授权状态 → 接口是否暴露可用决策信息 → 模型能否在线维护 → 执行层最终提交什么效果**。
- **作者明确定位**：不主张"撤销依赖图结构"这一观察本身的新颖性，也不提出通用生产级撤销协议；贡献在于"全未来残余商"、其状态复杂度定律，以及可执行的智能体评测。

## 2. 方法论：核心思想与关键技术细节

### 2.1 形式模型
- **主体与权限**：根主体 o，非根主体 N = n−1，权限 a ∈ [r]。每个权限对应一个有向图 G_a，边 i→j 表示 i 直接向 j 授予 a。非根主体被授权 ⟺ 从 o 可达。
- **动作字母表 A**：grant(i,j,a)、revoke(i,j,a)、use(j,a)。无效动作进入**吸收死状态 ⊥**（acceptor 约定：任一动作无效则整个历史无效）。
- **残余（residual）**：ρ(h) = { z ∈ A* : hz ∈ L_auth }。两个历史**未来等价** ⟺ 残余相同，记 ≡_auth；残余类数 N_res = |A*/≡_auth|。
- **命题 1（残余状态原理）**：精确确定性在线监控器需要且仅需要 N_res 个状态；零错误随机监控器同样至少需要 N_res 个状态。这是经典 Myhill–Nerode 等价的标准实例化（两个不同残余若映射到同一状态，则存在区分性延续迫使监控器给出相反答案）。

### 2.2 撤销语义（Table 1）
- **Monotone**：仅 grant/use，无撤销。
- **Persistent**：只删除被点名的那条边；源不可达后边仍保留，可能重新激活。
- **Cascading**：删除点名边后做清理 Clean(G) = {(i,j) ∈ G : i ∈ Reach_G(o)}。
- **Δ-parent cascading**：每个目标最多 Δ 个父边。
- **Canonical one-parent**：每个被授权非根主体恰有一个父节点（有根树），授予/撤销会连带子树。

### 2.3 三个核心理论结果
- **定理 1（相同可达性、不同未来）**：在一个传递闭包纤维（同一 TC）内，单权限至少包含 2^{N(N−1)/2} 个两两不同的残余状态；r 个独立权限下为 2^{rN(N−1)/2}。
  - **构造**：强制链 v₀→v₁→…→v_N 固定全序闭包；可选"前向捷径" vᵢ→v_j（j ≥ i+2）共 N(N−1)/2 条。区分性延续：先撤销 v_j 的所有其他入边，再 use(v_j)——v_j 可达当且仅当该捷径存在。
- **定理 2（冗余–记忆定律）**：
  - Monotone：N_res = 2^{rN} + 1 → Θ(rn) 比特；
  - Persistent：N_res = 2^{rN²} + 1（精确）；
  - Cascading：N_res = R_n^r + 1，其中 R_n = 2^{N²}(1 ± O(N·2^{−N}))；
  - Δ-parent：log₂ N_res^(Δ) = Θ(rNΔ log₂(eN/Δ))；Δ=1 时为 Θ(rN log N)。
- **推论 1（单父权衡）**：规范单父策略只有 2^{Θ(rN log N)} 个残余状态，但**无法保留冗余故障转移行为**（如 {o→a, o→b, a→b} 中任一条入边被撤另一条仍可支撑 b）——记忆的缩减来自**表达力的受限**。
- **定理 3（显式瓶颈下的近似监控）**：若 m 比特被残余"打散"（shattering）且 B ~ Uniform{0,1}^m，摘要 Y 满足 I(B;Y) ≤ b，则任意答案的期望误差
  - ε ≥ h₂⁻¹([1 − b/m]₊)，其中 h₂ 为二元熵（b=0 时误差下界 1/2；保留一半信息时约 0.11）。
  - **推论 2（无新通道时的计算无效）**：仅由 (Y, J) 与独立新随机性生成的链式思考、反思、多次自洽采样等，只要满足**条件独立** B → (Y,J) → Z，就服从同一下界；任何 I(B;Z | Y,J) > 0 的观测（重读账本、重读含来源的上下文、查询环境）才算开启新通道。

### 2.4 从定理到可执行基准的桥接命题
- **命题 2（选定谱系精化）**：在选定谱系假设下，具体账本的有效授予投影与抽象级联图机在**每个前缀**上可交换，具体与抽象的授权标签在每次尝试处一致（仅覆盖受审生成的受限子族）。
- **命题 3（新鲜查询证据）**：当前路径见证对更新后的残余查询**不充分**；对**单个固定查询**，"路径或割（path-or-cut）"是可靠且完备的证书方案；组件误接受概率 ≤ δ 时，路径总误接受 ≤ min{1, Nδ}，割 ≤ min{1, N²δ}。
- **命题 4（观测–读取–执行分离）**：仅凭 W 的预测器有 Pr(A≠Y) ≥ ½(1 − d_TV(P₀,P₁))；认证读取 R = Y 可实现零误差策略 A = R；硬网关 E_hard = A·Y 使 Pr(E=1, Y=0) = 0，但**不改变**此前的提案分布 A。

### 2.5 基准构造
- 把上述反例编译为**成对语言智能体片段**：同一检查点可达性、同一后续撤销、不同直接来源、**相反的终态标签**。
- **主指标：成对完备准确率（pair-complete accuracy）**——两臂都正确才算成功。恒定 allow/deny 策略单集可达 50%，但成对为 0%；独立均衡二值猜测期望成对准确率仅 25%。
- 受审发布前设有多重**失效关闭（fail-closed）**闸门：参考解、成对完整性、时间审计、划分与哈希校验。
