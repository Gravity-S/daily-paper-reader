## 摘要
针对基于LLM的多智能体系统(MAS)的拓扑引导安全防护措施，通过训练一个图神经网络(GNN)来利用智能体间的通信图，以定位风险智能体并干预拓扑结构——但这假设单一操作者能够汇集所有带标签的轨迹。跨组织时这一假设不成立：事件序列包含私有提示、工具输出和专有工作流，且没有任何单一数据孤岛能独自看到完整的攻击分布。我们将隐私保护的MAS安全防护视为图联邦学习问题，并实例化FGLGuard：每个操作者在其自身的评判者标记的事件图上拟合一个带边特征的图注意力检测器，仅共享模型更新。该方法结合了针对非独立同分布客户端的近端局部目标、域平衡聚合、过度拒绝约束的阈值校准、协同上游评分，以及针对被阻止答案的守卫重写。联邦并非可选：现成的迁移在分布偏移下崩溃（仅在域内重新训练后AUROC从0.51到0.70），因此可部署的防护必须在每个站点的私有轨迹上自适应。在Agent-SafetyBench、R-Judge和AgentDojo上，联邦FGLGuard在所有三个基准测试中均超过了域内集中式上限，且无需汇集任何数据——而监督式异常防护和仅本地训练则失败。一个跨四个不同域操作者联邦的防护在AUROC上与多域集中式相差0.03以内，而任何单域防护在其他域上崩溃。实时的FGLGuard在几乎无防护的效用、零API成本和可忽略的能力损失下，将AgentDojo的真实攻击成功率降低了43%。

## Abstract
Topology-guided safeguards for LLM-based multi-agent systems (MAS) train a GNN over the inter-agent communication graph to localize risky agents and intervene on the topology---but they assume one operator can pool all labeled traces. Across organizations that assumption breaks: episodes contain private prompts, tool outputs, and proprietary workflows, and no silo alone sees the full attack distribution. We cast privacy-preserving MAS safeguarding as graph federated learning and instantiate FGLGuard: each operator fits an edge-featured graph attention detector on its own judge-labeled episode graphs and shares only model updates. The method couples a proximal local objective for non-IID clients, domain-balanced aggregation, over-refusal-constrained threshold calibration, corroborated upstream scoring, and a guarded rewrite for blocked answers. Federation is not optional: off-the-shelf transfer collapses under distribution shift (AUROC 0.51 to 0.70 only after in-domain retraining), so a deployable guard must adapt on each site's private traces. On Agent-SafetyBench, R-Judge, and AgentDojo, federated FGLGuard exceeds the in-domain centralized ceiling on all three benchmarks without pooling any data---where unsupervised anomaly guards and local-only training fail. One guard federated across four different-domain operators comes within 0.03 AUROC of multi-domain centralization, while any single-domain guard collapses on the others. Live FGLGuard cuts AgentDojo's ground-truth attack-success rate by 43% at near-unguarded utility, zero API cost, and negligible capability loss.

## 2. 方法论

**整体框架（三阶段）**：
- 阶段①：联邦拟合一个带边特征的图注意力风险评分器 fθ。
- 阶段②：在隐私兼容前提下，按显式过度拒绝预算校准部署阈值 τ*。
- 阶段③：运行时干预算子，对上游邻居风险进行协同验证，并为被拦截答案提供最多一次守卫重写机会。

**关键技术细节**：

- **Episode 图构建**：用冻结句子编码器（MiniLM）将智能体话语、工具调用嵌入；节点特征取智能体自身话语历史的均值（xi = (1/T)∑t φ(uti)）；边特征取接收方每轮话语嵌入序列。相比 G-Safeguard 仅聚合入边，节点锚定到自身历史可避免稀疏拓扑孤立智能体无特征可用。

- **边特征风险评分器**：两层边条件图注意力层（edge-conditioned GAT）：
  - 边打分公式（式 2）：对源/目标节点特征与边特征拼接做 LeakyReLU 线性映射；
  - 注意力系数按入边归一化（式 3）；
  - 节点更新为入边注意力加权聚合（式 4）；
  - 线性头输出每个智能体的风险分数 sj = σ(wᵀhⱼ⁽ᴸ⁾ + b) ∈ [0,1]。

- **联邦近端训练**（对应式 5）：各客户端最小化本地 BCE 损失加上近端项 (μ/2)‖θ − θ^(r)‖²，μ=0.01。近端项防止持有少量不安全样本的客户端漂移向良性多数，缓解非 IID 数据下的客户端偏移。局部 E 轮后上传更新。

- **域平衡聚合**（对应式 6）：聚合权重 αk = (1/D)·Nk/(Σ_{k′∈Cd(k)} Nk′)：域内按节点数比例，域间每个域等总质量 1/D。D=1 时退化为 FedAvg；防止大孤岛通过体量或分片主导聚合。

- **预算化工作点校准**（对应式 7）：服务器在由各客户端本地计算的验证集标量对（ŝ, y）池上，求满足 FPR ≤ ρ 前提下最大化 Recall 的阈值 τ*；良性流量上等价于经验 (1−ρ) 分位数，理论上保证校准集上预算成立。

- **协同上游干预算子**（对应式 8、9）：
  - 协同决策分 ŝj = max(sj, max_{i:Aij=1} si)——不安全内容常来源于执行智能体的上游，其自身文本可能看似干净；
  - 决策规则 Π(uj)：未超阈值直接放行；超阈值则给予一次守卫重写（Rewrite），重写后用同一协同规则重新评分，仍不过则拒绝。
  - 理论保证：协同验证不会解除单凭自身分数会被拦截的智能体；在固定阈值下会同时提高检出率与假阳性，但重新按 ŝ 校准可吸收该代价。

## 6. 主要结论与发现

- **Q1（联邦逾越集中式天花板）**：联邦 FGLGuard 在 ASB、R-Judge、AgentDojo 上（0.726 / 0.895 / 0.680）超过同骨干域内集中式 G-Safeguard（0.695 / 0.810 / 0.676），却不交换任何原始轨迹；现成迁移与 local-only 均失败。本地-only 平均仅 0.666 / 0.762 / 0.584。
- **Q2（免费 judge 标签优于无监督/训练无关）**：无监督防护（BlindGuard/XG-Guard）在其原生植入攻击数据上看似强（0.788 / 0.880），但在有机 ASB/AgentDojo 上掉到机会水平甚至反向；训练无关防护同样不敌任何有监督行，且会过度阻止 17–54% 良性流量。
- **Q3（跨域联邦接近池化上限）**：一个在 tool-injection + ASB + R-Judge + AgentDojo 上联邦得到的防护，域间 AUROC 与多域集中池化相差不超过 0.03，且不存在代替加入联邦的捷径——任何他域专家在其他域上仅达 0.537–0.573。
- **Q4（实时 ASR 下降且效用保持）**：AgentDojo 定向 ASR 由 0.401 降至 0.230（降 43%），干净效用从 0.575 升至 0.650，95% Wilson CI 与无防护不相交；六个通用能力任务上能力损失 ≤4.2 点（三表内 ≤2.1）。
- **削除结论**：近端目标应对非 IID；类别重加权在低患率下有反效果（−0.093 AUROC）；团队规模越大证据越多但攻击面也越大，默认 n=4 并非最优但合理；随机型拓扑迁移到固定拓扑效果可，但固定到随机会崩塌；骨干换成 Qwen3-8B 所有防护绝对 AUROC 下降约 8–15 点但排序保持不变。
- **运行通道**：只守卫最终答案优于守卫工具调用；守卫重写后经协同规则重新评分能兼顾安全性与完成率。

## 7. 优点

- **问题选得好且意义明确**：把跨组织 MAS 安全防护的隐私障碍翻译成图联邦学习语言，定位了一个真实而未被现有拓扑防护方法覆盖的部署盲区。
- **方法设计环环相扣**：每个组件都对应一项部署现实（标签偏斜→近端目标；孤岛大小不均→域均衡聚合；误拦风险→预算校准；上游风险→协同验证；可挽救工作→守卫重写），且定理给出理论保证（如校准集上 FPR ≤ ρ；域均衡聚合的凸组合性质；协同验证不会解除自己分数本应拦截的智能体）。
- **实验严谨性强**：匹配梯度预算、5 种子标准差、统计检验（Wilson CI）、独立审计评判者、train/test 不重叠检查、同域 D=1 等价于 FedAvg 保证对照公平。
- **消融覆盖充分**：按刻度扫描非 IID 纯度、团队规模、通信拓扑转移矩阵、agent 骨干等在外不可控变量，并将运行通道、重写机制等部署决策逐个做受控消融。
- **实际可部署性**：0.5M 参数、约 50 ms/次 CPU 检查、零 API 成本，以可忽略能力损失换来 43% 的实时攻击成功率下跌。

## 8. 不足与局限

- **实验设置仍有模拟性质**：论文采用“模拟联邦”而非真实跨组织协作，R-Judge/AgentDojo 映射为链路图，真实场景的孤岛间梯度泄露风险（如更复杂的推断攻击）未被处理。
- **校准有部署特定性**：阈值需在部署数据上重新校准（ρ 预算随流量变化失效），且校准后的 FPR 保证仅对校准集成立，实际操作者需持续维护校准流程。
- **显式拒绝 benchmark 上改进有限**：未能显著缓解直接拒绝安全任务等问题；补充中 6/74 次重写通过揭示重写通道仍无法救回大量本该可完成的任务。
- **资源消耗未完全披露**：只说明检测训练为 CPU 分钟级，但实时部署部分（ASB shield 本地 A6000 + 托管 API 调用）的具体 GPU/API 成本、推理耗时汇总未提供全貌；API 费用也未量化。
- **仅覆盖 4-agent/gpt-5-nano 默认架构**：骨干为 Qwen3 替换实验虽保持排序，大型异构 agent（不同供应商模型混合、工具类型多样）的泛化尚未验证。
- **性能上限受特征编码约束**：MiniLM 冻结编码器面对短而嘈杂的替换骨干话语时性能绝对下降较多，提示编码器选择对防护影响大。
