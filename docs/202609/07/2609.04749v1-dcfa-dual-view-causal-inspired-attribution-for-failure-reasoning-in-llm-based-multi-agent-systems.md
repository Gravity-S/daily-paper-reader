## 摘要
基于大语言模型的多智能体系统近年来发展迅速。尽管前景广阔，此类系统仍较为脆弱，常表现出推理与协作错误，进而导致系统级故障。此类系统中的故障归因依赖于追踪智能体间的自然语言交互，以识别决定性错误——即最早可通过修正其来逆转系统故障的动作。存在两个关键挑战：1）浅层归因：现有方法常仅捕捉轻微偏差（如检索不完整或格式错误），这些可由验证机制纠正，而遗漏系统故障的决定性原因。2）上下文退化：随着系统轨迹长度的增加，模型的推理能力迅速下降。为解决这些挑战，我们提出了DCFA，一种免训练的故障归因框架。DCFA集成全局模块与局部模块：全局模块从系统轨迹中构建结构化因果启发的依赖图以识别初始决定性错误；局部模块应用局部反事实启发推理以细化因果启发归因。在Who&When基准上跨越六种LLM的实验表明，DCFA相较最先进的基线在步骤级准确率上最高提升8.27%。

## Abstract
Large language model (LLM)-based multi-agent systems have experienced rapid growth in recent years. Despite their promise, such systems remain fragile, frequently exhibiting reasoning and coordination errors that can lead to system-level failures. Failure attribution in such systems relies on tracing natural language interactions among agents to identify the decisive error, which refers to the earliest action whose correction can reverse system failure. There are two key challenges: 1) Shallow attribution: Existing methods often capture only minor deviations, such as incomplete retrievals or formatting errors, which verification mechanisms can correct, while missing the decisive cause of system failure. 2) Contextual degradation: As the length of the system traces increases, the model's reasoning ability rapidly deteriorates. To address these challenges, we propose DCFA, a training-free framework for failure attribution. DCFA integrates a global module that constructs structured causal-inspired dependency graphs from system traces to identify the initial decisive error, and a local module that applies local counterfactual-inspired reasoning to refine causal-inspired attribution. Experiments on the Who&When benchmark across six LLMs show that DCFA improves step-level accuracy by up to 8.27% over state-of-the-art baselines.

- **现有挑战**：

  2. **上下文退化（Contextual Degradation）**：随着系统轨迹长度增加（如接近 100 步），模型归因准确率由约 15% 降至接近 0%。

## 2. 方法论

- **核心思想**：构建“全局因果启发依赖图”以模拟交互间依赖关系，再从局部出发，用“反事实启发式评估”检验候选错误修正后对最终结果的影响，从而区分“浅层微小偏差”“贡献性错误”和“决定性错误”。
- **整体框架**：DCFA 由两个模块组成：
  1. **全局因果启发归因模块（GCA）**
     - **微小偏差识别**：从系统轨迹 \(T=\{\tau_1,\dots,\tau_n\}\) 中提取候选微小偏差事件集合 \(T^e\) 及文本解释 \(R^e\)。
     - **依赖图构建**：以检测到的偏差为中心构建有向因果启发依赖图 \(G=(V,E)\)；边 \(e:\tau_p \to \tau_q\) 需同时满足三个条件：
       - **时间性（Temporality）**：\(p < q\)；
       - **必要性（Necessity）**：若移除 \(\tau_p\)，则 \(\tau_q\) 不会发生；
       - **充分性（Sufficiency）**：若执行 \(\tau_p\)，则 \(\tau_q\) 会被诱发。
     - **假设生成**：基于系统轨迹、候选偏差、文本原因与依赖图，通过提示式全局推理生成初始决定性错误假设 \(\tau^\star\) 及理由 \(r^\star\)。
  2. **局部反事实启发增强模块（LCE）**
     - **双向依赖邻域搜索**：以全局假设为枢轴，在依赖图上沿前向（下游效果）与后向（上游原因）进行贪心搜索。
     - **反事实启发式评估**：构造“完全修正轨迹” \(\hat{T}\)，然后对每个位置 \(i\) 构造“前 \(i\) 个交互已修正、后续保持原始”的反事实轨迹 \(\tilde{T}^{(i)}\)；通过 LLM 仿真其输出 \(Y^{(i)}\)，用预训练编码器计算与真实结果 \(Y\) 的余弦相似度 \(S(\tau_i)\)，并定义边际修正增益 \(\Delta S(\tau_i)=S(\tau_i)-S(\tau_{i-1})\)。
     - **决定性错误决策**：前向与后向搜索返回的所有有正增益的候选交互组成局部候选集 \(T_c\)，由决策函数 DED 判定最终决定性错误 \(\tau^*\)。
- **免训练性**：全部过程只需 LLM 推理，无需微调或额外标注数据。

## 6. 主要结论与发现

- **性能提升**：DCFA 在 Algorithm-generated 数据集上相比最强基线平均提高 **12.51%**，在 Hand-crafted 数据集上平均提高 **4.02%**；六种 LLM 上最高步骤级准确率提升达 **8.27%**。
- **局部模块有效**：LCE 在长轨迹场景中发挥关键作用：在 GCA-only 基础上，LCE 在 Hand-crafted 数据集平均提升 3.45%，在 Algorithm-generated 数据集平均提升 1.93%。
- **长轨迹鲁棒性**：DCFA 在几乎所有长度层级都优于基线，尤其在第 5 级（最长轨迹）仍保持较好准确率，验证了局部反事实推理能缓解上下文退化。
- **浅层归因问题的缓解**：案例显示，DCFA 能够区分“可恢复的微小偏差”（如 WebSurfer 返回不完整信息）、“贡献性错误”（如 Orchestrator 传播不完整信息）和真正的“决定性错误”（如 Assistant 捏造缺失语义信息），避免仅识别表面错误。
- **模型差异**：高能力 LLM（如 DeepSeek-R1-671B、GPT-5）构造的依赖图更稳定和紧凑，小模型（如 Qwen3-Coder-30B）易产生过度稠密或稀疏的依赖图，但 LCE 的局部搜索仍可纠正结构噪声。

## 7. 优点

- **问题定义清晰**：将“决定性错误”定义为可修正并逆转系统失败的“最早动作”，比“任意错误检测”或“所有错误枚举”更具可操作性和实用性。
- **双视角设计有理论动机**：全局依赖图负责捕获轨迹级因果链，局部反事实评估负责精细验证，两者互补，兼顾归因深度与计算可控性。
- **免训练架构**：不依赖细粒度标注或微调，可直接采用各类 LLM，部署灵活。
- **依赖图构建标准严格**：要求时间性、必要性、充分性同时满足，有效过滤伪相关边。
- **实用性考量充分**：作者在成本分析中给出 GCA 与 LCE 各自的调用次数与 token 消耗（如 GCA 约与 ECHO 相同复杂度；LCE 额外本地推理），并说明了离线归因与潜在实时优化方向。
- **多维度实验验证**：除主实验外，还包含消融、长轨迹分层、鲁棒性、案例、偏差和复杂度分析，证据链较完整。

## 8. 不足与局限

- **依赖 LLM 能力**：当轨迹非常长时，即使是强 LLM 也难以保持稳定依赖图，全局步骤可能退化；小模型执行局部反事实评估时精度也受限。
- **极端长/复杂轨迹仍具挑战**：对于高度分支、深层嵌套的交互，双向搜索可能难以覆盖所有关键路径，规模扩展性有限。
- **成本较高**：相比简单基线，DCFA（尤其 LCE）需要多次 LLM 模拟，运行时间和 token 消耗明显增加（运行时从约 32 秒增至 300 秒；token 从 13k 增至 32k），对实时诊断不够友好。
- **归因误差受 LLM 内在幻觉影响**：如果错误来源是模型自身幻觉，归因结果不完全可靠；作者在伦理声明中也强调自动化归因不能替代人工责任判断。
- **重要局限性未被深入实验**：
  - 未在更大规模（上千条）真实 MAS 轨迹上评测；
  - 对每条轨迹的人工可解释性没有做用户研究或专家评估；
  - LCE 的反事实仿真依赖“纠正前缀 + 原始后缀”的简洁构造，忽略了纠正后可能导致后续行为完全分岔的情况；
  - ECHO 因无官方实现由作者重实现，可能存在不公平比较风险。
- **声称“causal-inspired”而非严格因果推断**：依赖条件由 LLM 判断实现，本质上是启发式结构，不保证统计学上的因果识别；论文对此有保留，但仍可能在应用中被高估。
