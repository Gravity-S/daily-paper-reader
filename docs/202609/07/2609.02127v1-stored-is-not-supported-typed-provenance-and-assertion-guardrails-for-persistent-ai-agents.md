## 摘要
持久化AI代理通过反思、检索和整合构建自传式状态。持久化改变的是可用性，而非认知地位：存储或检索到的材料并不因此获得支持。不可信输入、提示注入和模型推理因此可能进入持久状态，并在之后呈现为代理历史或用户承诺。我们针对自传式断言有界性规定了类型化溯源与断言护栏，这是一种系统相对的释放属性，要求关于代理、用户或命名关系的受治理陈述满足已接受证据、时间有效性和披露策略。类型化溯源图区分来源、依赖谱系、认知角色、有效性和披露范围。解析器评估授权的状态投影，并返回一个证据状态，以及正交的冲突、过时和扣留标志，以及一个受保护的决策见证。随后，一个生成-验证-修订中介在释放前检查候选语义单元，并呈现策略授权的状态响应。在关于提取、谓词正确性、解析完备性、视图脱密和通道中介的明确假设下，我们证明了条件性断言有界性契约。在一个包含24个人工撰写的合规用例的可执行套件中，类型化中介未通过任何19个不安全机会中的不合格项，同时保留了所有五个受支持的控制项。扁平/先前和源标签比较规则分别释放了19/19和18/19个不安全候选。这些结果验证了编码的解析器和中介义务；它们并不构成对语言模型或检索系统的端到端评估。

## Abstract
Persistent AI agents construct autobiographical state through reflection, retrieval, and consolidation. Persistence changes availability, not epistemic standing: stored or retrieved material is not thereby supported. Untrusted inputs, prompt injections, and model inferences can therefore enter persistent state and later be presented as agent history or user commitments. We specify typed provenance and assertion guardrails for autobiographical assertion boundedness, a system-relative release property requiring governed statements about the agent, user, or named relationships to satisfy accepted-evidence, temporal-validity, and disclosure policies. A typed provenance graph separates origin, dependency lineage, epistemic role, validity, and disclosure scope. A resolver evaluates authorized state projections and returns one evidential status, orthogonal conflict, staleness, and withholding flags, and a protected decision witness. A generate-verify-revise mediator then checks candidate semantic units before release and renders policy-authorized status responses. Under explicit assumptions about extraction, predicate correctness, resolution soundness, view declassification, and channel mediation, we prove a conditional assertion-boundedness contract. In an executable suite of 24 hand-authored conformance cases, typed mediation passed none of 19 unsafe opportunities unqualified while preserving all five supported controls. The flat/prior and source-tag comparison rules released 19/19 and 18/19 unsafe candidates, respectively. These results validate the encoded resolver and mediator obligations; they do not constitute an end-to-end evaluation of language models or retrieval systems.

### 1. 论文核心问题与整体含义（研究动机与背景）

- **核心痛点**：持久化 AI 代理（Persistent AI Agents）通过反思、检索和整合构建长期记忆，但**持久化只改变信息的可用性，不改变其认知地位**——被存储或检索到的内容并不因此获得"被支持"（supported）的资格。
- **安全威胁**：不可信输入、提示注入（prompt injection）以及模型自身推断可能进入持久状态，在之后的会话中被代理以第一人称权威语气表述为"代理历史"或"用户承诺"，例如代理声称"您要求我公开分享此信息"，而实际上这只是来自恶意文档的注入指令经记忆整合后的产物。
- **问题本质**：存储（storage/reachability）与支持（evidential support）是两种完全不同的判断。一个无瑕疵的记忆存储库也无法阻止 opaque 语言模型幻觉出自传式声明。
- **核心研究问题**：持久化代理能否区分"它存储了什么/底层模型普遍知道什么"与"该特定代理有证据、授权和有效范围去主张什么"？
- **本文立场**：不试图修剪模型的潜在参数知识（这被视作不可行的），而是将存储与支持分离，管制二者之间的显式认知角色转换，在输出边界建立形式化的发布契约。

### 2. 论文方法论：核心思想、技术细节与流程

#### 2.2 核心概念框架

- **覆盖的自传式语言 Lbio**：结构化命题的受限形式语言——主题限定为代理自身、认证用户或共享环境中的命名关系实体，谓词限定为体验性交互、偏好、权限、关系承诺、任务能力或历史事件。部署通过领域签名 Σ=⟨P_pred, A, M⟩ 参数化。
- **模型参数能力与已接受代理主张的分离**：模型能生成某命题 ≠ 该命题在代理历史状态中拥有地位。模型替换（m₁→m₂）在固定状态头下保持已接受声明集合 C_agent(h) 不变。
- **解耦的认知维度**：形式化区分状态接纳、源认证、证据支持、代理立场、披露授权与语义真理，明确任何单一维度都不蕴含其他维度（例如加密认证 ≠ 事实真实性；检索频率 ≠ 独立佐证）。

#### 2.3 关键技术机制

- **角色分区与提升演算**：认知角色被三分——X（接地历史角色：ObservedEvent、AttributedReport）、D（保留依赖的派生角色：DeterministicDerivation、MemoryInterpretation、RecordedBelief）、U（未验证/合成角色：ModelPrior、UnverifiedRetrieval、ProbabilisticInterpretation、Hypothesis）。角色间迁移是受管控的判定（Gh⊢κ vs→D vt:rt），且有严格禁止规则（U 中的源角色不可提升为 X 中任何角色）；新根接入 X 必须满足 CaptureOriginOK 或 ReportOriginOK 的源记录义务。
- **源独立性（Source Independence）**：两个实体的**终端根集合非空且互不相交**才构成独立佐证。该图论定义可抵御"Sybil 佐证"——多个 URL、语义嵌入或不同检索片段若收敛到同一上游根，不满足独立佐证要求。
- **认知解析器**：对授权投影执行解析，返回 ⟨E, F, S, W⟩ 四元组：E∈{Supported, Unknown, Unavailable}（单一证据状态）、F⊆{Conflicted, Withheld, Stale}（正交限定标志）、S（最小前提集）、W（受保护决策见证）。解析在视图边界内保障：Supported⇔前提集非空且满足策略；非 Supported 前提集为空。
- **决策见证**：见证须满足 BoundToHead（绑定状态头）、AccessBound（附加访问策略）、MinimalWitness（最小化载荷）和类别特定的 ObligationsMet（冲突见证、过时见证、扣留见证、不可用见证）。见证本身不能证明内容发布，只有 S 中的前提可以。空载荷见证 ⊥W 用于记录评估上下文但无证据载荷的情况。
- **扣留检测与接收者非干涉（Non-Interference）**：当语义相关信息在完整存储中存在但被投影过滤时，产生 Withheld 标志。为避免"存在性侧信道"（例如拒绝访问恰好证明记录存在），View_c 可将 Withheld、Unavailable、Unknown 映射到同一脱密视图，使渲染器输出统一、接收者安全的非确认性响应。
- **前向失效与状态缩减**：撤销操作以追加版本化描述符而非破坏性重写的方式执行；支持有效当且仅当至少存在一条完整的、未被撤销的依赖替代路径（递归验证）。
- **生成-验证-修订发布门**：⟨z,c⟩→extract→⟨v̄,Q̄,c⟩→resolve→⟨v̄,d̄,c⟩→gate→z_rel。候选单元经提取、逐条解析后通过发布谓词检查方可释放；失败的候选将被阻止或提供脱密诊断请求修订，修订后须重新进入提取阶段。
- **发布头时间验证（HeadUseOK）**：若上下文组装时的头 h_p 与发布时的头 h_e 不一致，需要快照授权和显式时间框定（如"As of the preceding session..."），否则必须针对当前头重新投影和再次中介。
- **发布可接受性谓词**：ContentReleaseOK 要求内容单元精确匹配支持前提集中的某命题（ExactMatch）、证据状态为 Supported、满足限定条件（QualOK）、披露授权（DisclosureOK）和头使用检查；StatusResponseOK 要求状态响应来自授权视图的渲染集合且通过头检查。
- **条件性断言有界性契约（命题2）**：在四个环境假设（E1 权威状态排序、E2 版本化闭包、E3 不可变策略绑定、E4 闭合通道中介）以及提取完备性、谓词正确性、解析完备性、视图脱密和通道中介等显式假设下，达到释放状态的所有覆盖语义单元均满足对应发布谓词。

### 7. 方法亮点与优点

- **清晰的概念分离**：将状态接纳、授权投影与断言中介分为三个独立强制面，分别对应不同安全属性，架构层次分明；
- **严格的认知维度解耦**：将真值、认证、支持、时间有效性与披露范围拆分为独立维度，并以形式化不等式（如 Authenticated(v) ⇏ True(φ)）明确消除混淆；
- **有意义的源独立性定义**：使用图根集合不相交性判断独立佐证，结构上抵御多源伪造共识，设计初衷合理；
- **条件性形式证明**：在明确的假设条件下给出断言有界性契约与可追踪性证明，使安全论证链透明、可审计；
- **非平凡安全的度量设计**：同时度量 UOR/RC 与 Coverage，防止模型通过"一刀切拒绝"取巧获得高安全分数；
- **审计可追溯**：决策见证、发布单元绑定结构（μv 与 ̄μz）以及前向状态缩减设计支撑可审计的发布记录；
- **对抗场景设计较系统**：覆盖来源伪造、Sybil 佐证、时间过期、跨用户/目的越权、撤销失效、注入与头竞态等多元威胁轨道。

### 8. 不足与局限性

#### 实验覆盖层面

- **非端到端评估**：仅对确定性结构化逻辑做一致性评测；未实施真实的 LLM 生成与自然语言语义单元抽取测试；
- **受限用例形态**：24 个手写结构化场景规模有限，且全部基于模板化、类型化命题，不能证明在非结构化动态对话中有效；
- **缺乏端到端部署验证**：附录 C 规划的端到端协议（5 部署范式、7 对抗轨道）并未在本论文执行——尚无真实检索系统或生产环境的性能/安全/延迟数据；
- **无消融实验**：未单独验证 Root_κ 独立分析、Equation 22 传递失效、HeadUseOK 时序检查与 View_c 脱密等各组件在真实端到端条件下的贡献。

#### 方法假设层面

- **假设较强**：前提条件包括提取完备性与正确类型化、解析完备性、谓词实现正确性、视图脱密正确性、无旁路的通道中介等——这些在现实持久代理系统中难以严格满足；
- **自然语言语义抽取缺口**：非结构化文本中的预设、隐含、情态转移或复合修辞结构可能绕过覆盖单元检测；
- **抽象边界**：以事务性存储/认证头为给定输入，自认对并发写入与崩溃恢复等底层实现细节不承担责任。

#### 应用与残余风险

- **不保证客观真值**：机制仅提供程序性/程序性边界，不裁决外部世界的真理性；恶意或假冒但已认证的源头仍可传递错误信息；
- **运营开销未知**：实时界面延迟约束下，缓存验证或模板驱动的效率问题尚未在真实部署中验证；
- **算法外通道管制缺失**：非受管侧信道（如调试日志、遥测、工具 API 旁路）仍然可能泄漏自传式信息；
- **存在性侧信道的缓解不完整**：View_c 的合并策略依赖观察假设（附录 E.1），无法保证密码学意义上的不可区分性；
- **无算力报告**：未披露模型训练或推理的资源使用，限制了对方案可扩展性的判断。
