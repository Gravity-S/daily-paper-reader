## 摘要
基于大语言模型（LLM）的智能体在处理复杂任务时展现出强大的多步推理潜力，但仍易受到执行失败的影响。因此，准确的失败归因对于提升智能体可靠性至关重要。现有的基于拓扑和谱的方法利用轨迹结构，但往往忽视细粒度语义；而基于LLM的归因方法能够捕捉语义线索，却因长轨迹导致长上下文退化问题。为应对这些挑战，我们提出DUOTRACE，一种即插即用的检测过滤器，用于基于LLM的失败归因。DUOTRACE遵循先检测后归因的范例：首先检测异常执行，然后向下游基于LLM的归因方法提供聚焦的轨迹证据。为在智能体轨迹上实现有效的基于VAE的异常检测，DUOTRACE整合了双视图语义-结构节点表示、基于Tree-LSTM的轨迹编码器，以及基于前缀链和LLM的数据增强，以处理异构节点、层次化执行结构和有限的失败数据。与六种基于LLM的归因基线进行的实验表明，DUOTRACE在智能体级和步骤级归因准确性上分别提高了8.7%和7.0%。

## Abstract
Large language model (LLM)-based agents have shown strong potential in solving complex tasks through multi-step reasoning, yet they remain vulnerable to execution failures. Accurate failure attribution is therefore critical for improving agent reliability. Existing topology- and spectrum-based methods exploit trajectory structures but often overlook fine-grained semantics, while LLM-based attribution methods capture semantic cues but suffer from long-context degradation over lengthy trajectories. To address these challenges, we propose DUOTRACE, a plug-and-play detection filter for LLM-based failure attribution. DUOTRACE follows a detect-before-attribute paradigm: it first detects anomalous executions and then supplies focused trajectory evidence to downstream LLM-based attribution methods. For effective VAE-based anomaly detection on agent trajectories, DUOTRACE integrates dual-view semantic-structural node representations, a Tree-LSTM-based trajectory encoder, and prefix-chain- and LLM-based data augmentation to handle heterogeneous nodes, hierarchical execution structures, and limited failure data. Experiments with six LLM-based attribution baselines show that DUOTRACE improves agent-level and step-level attribution accuracy by 8.7% and 7.0%, respectively.

### 一、核心问题与整体含义

- **背景与动机**：基于大语言模型（LLM）的智能体系统在处理长周期复杂任务时，往往呈现为高度耦合的分层执行树。早期细微错误容易静默传播，经级联放大后导致系统级失败。因此**失败归因（Failure Attribution, FA）**——即从系统级失败中追溯精确根因——对提升系统可调试性、可靠性和成本效率至关重要。
- **现有方法的双重困境**：
  - **拓扑/谱驱动方法**（如FAMAS、CDC-MAS）：利用轨迹结构但语义盲区明显，无法归因幻觉等细粒度文本类失败；
  - **LLM-as-a-Judge方法**（如ECHO、CORRECT）：能同时考虑结构与语义，但在长轨迹上面临"Lost in the Middle"问题（图1显示随步数增加归因精度显著下降），上下文稀释严重且推理成本高。
- **核心研究问题**：如何在不损失语义和结构信息的前提下，克服LLM长上下文退化瓶颈，实现高效准确的失败归因？
- **整体含义**：本文主张"先检测后归因"（detect-before-attribute）——先通过异常检测压缩冗长轨迹，筛选出可疑执行子集，再交由LLM进行因果归因，从而兼顾精度与效率。

### 二、方法论：DUOTRACE框架

#### 2.1 核心思想

DUOTRACE作为一个即插即用的前端检测过滤器，使用基于Tree-LSTM的变分自编码器（VAE）从大量正常轨迹中学习执行模式，通过重建误差识别异常节点，将Top-K异常节点的结构上下文蒸馏为简洁子轨迹，供下游LLM归因方法使用。

#### 2.2 四个紧密耦合模块（图2）

1. **数据增强模块（Data Augmentation）**——解决正常轨迹稀缺问题：
   - **LLM回放生成**：基于原始任务上下文，约束智能体角色表，从失败参考轨迹出发，由LLM多次（每任务5次）随机采样生成多样、无故障的成功轨迹；
   - **前缀链提取**：将完整成功轨迹切分为变长前缀，显式建模中间操作的时间推进，大幅扩展有效训练空间（最终获得900余条增强轨迹）；
   - **防泄漏设计**：增强过程只看任务真值（GT_task），完全不使用诊断真值（GT_diag），训练与测试集严格隔离。
2. **双视图特征表示模块（Dual-View Features）**——解决单一模态不足：
   - **语义视图（角色感知嵌入）**：使用Sentence Transformer（all-MiniLM-L6-v2）分别对智能体身份和操作符编码为384维稠密向量并拼接（共768维），经线性投影降为128维；
   - **结构视图（拓扑编码）**：通过邻接矩阵 A 建模父-子直接调用依赖关系；
   - 二者融合形成结构感知语义张量，解决开放词汇框架下智能体命名异构、标记类别不可迁移的问题。
3. **轻量结构VAE模块（Lightweight Structural VAE）**——层级编码与异常识别：
   - **Tree-LSTM编码器**：使用Child-Sum Tree-LSTM聚合子节点状态，捕获树状层次依赖；**刻意排除当前节点实际token消耗作为输入**以防止信息泄漏；
   - **潜在空间建模**：通过投影得到高斯后验的均值和方差，利用重参数化采样获得潜在变量 z（64维）；
   - **MLP解码器（多目标重建）**：统一重建（a）语义嵌入（智能体角色与操作，MSE损失）和（b）执行足迹预测（token消耗的条件高斯分布参数 μ、log σ²，NLL损失）；
   - **优化目标（ELBO）**：
        L = MSE(语义重建) + NLL(token预测) + β·KL散度（β=0.01）
   - 设计动机：用"结构预测性能足迹"——即节点的token消耗和操作情境应与其职能角色和树中位置相吻合，偏差即异常。
4. **动态加性计分与集成模块（Dynamic Scoring & Integration）**——从重建误差到可疑排名：
   - 以正常轨迹分布建立基线（μ_S、σ_S），将各节点重建误差标准化为Z分数以消除累积噪声和任务间方差；
   - 监测沿执行树的早期显著突变峰值（而非绝对误差阈值）；
   - 按Z分数排序节点，保留Top-K（经验最优为前20%），借助邻接矩阵保持拓扑依赖，形成紧凑子轨迹 V_sub 供LLM评估。

### 六、主要结论与发现

1. **精度全面提升**：DUOTRACE在六种LLM归因基线上平均提升智能体级和步骤级归因准确率分别**+8.7%和+7.0%**；增强后的CORRECT达到整体Agent Accuracy 69.1%、Step Accuracy 49.0%，超越此前SOTA——AgenTracer。
2. **通用即插即用**：对所有基线和所有数据集均产生一致正增益（如Handcraft子集上Qwen3.5-plus Agent Accuracy +19.0%，GPT-5 +15.5%）。
3. **效率显著改善**：token消耗最多降低76%，推理时间最多减少64%（CORRECT获得2.5×加速）。
4. **结构建模关键**：Tree-LSTM在所有编码器对比中表现最优，说明层级结构归纳偏置对多智能体失败归因很重要。
5. **双视图缺一不可**：去除语义或结构视图在Handcraft子集分别导致20.69%和18.97%的召回率下降。
6. **仅缩短上下文不够**：保留"失败相关信息"才是有效的关键；随机过滤或固定位置截断会严重损害归因性能。
7. **推荐保留率约20–25%**：过高重新触发上下文稀释，过低有排除真实根因的风险。
8. **跨场景迁移有效**：在AgentErrorBench、RealWorld、MP-Bench多根因及held-out任务类零样本场景均表现稳定。
9. 在20%语义掩码下，DUOTRACE增强变体仍优于未掩码的原始基线——表明其具备对局部不可观测日志的鲁棒性。

### 七、方法/实验亮点

1. **范式创新**：将"检测-归因"两阶段分离——异常检测只做候选筛选不作因果归因，充分利用了二者在任务性质上的差异，有效规避了LLM长上下文瓶颈。
2. **表示设计精巧**：用Sentence Transformer编码智能体角色与操作符代替离散ID，天然支持跨框架零样本迁移；从输入中剔除当前节点token数并反向预测它，形成"用结构验证行为"的信息瓶颈，防止编码器直接"偷看"答案。
3. **增强策略有针对性**：LLM重放结合失败轨迹作为参考上下文（生成绕过原逻辑陷阱的成功路径）+前缀链抽取，兼顾了多样性和时间推进建模；还通过严格协议防止训练/测试泄漏和诊断真值泄漏。
4. **评分机制稳健**：Z分数标准化+动态累积突变跟踪，优于静态绝对误差阈值的做法。
5. **实验设计层次清晰**：从整体效果→逐组件贡献→替代设计比较→对手策略对比→多维度泛化→敏感性分析，形成完整证据链。
6. **辅助分析**：通过DTW对齐和BERTScore计算显示增强数据与失败轨迹的前缀保真度高（X<0区域相似），在故障节点处急剧分歧——从定量角度验证了"手术式修正"的增强数据质量。

### 八、不足与局限

1. **树状拓扑依赖**：DUOTRACE以树形表示为基本假设，虽然通过"结构展开"能处理非树场景（共享节点引用），但当前实现仍需树兼容表示，对复杂图结构（如循环调用、多父节点共享）支持有限。
2. **语义缺失鲁棒性有限**：20%语义字段掩码仍造成平均2.6个百分点的性能下降（虽然远小于无DUOTRACE时的5.9%），实际部署中日志缺失率可能更高，该短板可能进一步放大。
3. **正常轨迹依赖**：VAE以正常轨迹建模为根基，论文未充分讨论"正常数据本身含系统偏差"、"正常执行定义模糊"以及缺少正常样本时的冷启动问题（增强只能部分缓解）。
4. **多根因场景有待深入**：论文承认nDCG@5只衡量排序质量，不代表因果责任分解能力；对于多个根因间的交互关系未作进一步分析。
5. **部分实验样本量较小**：零样本跨类别测试仅23个实例、非树结构测试仅21个实例，统计功效和结论稳健性受限。
6. **未报告不确定性**：缺少多次运行的方差、置信区间和显著性检验；Handcraft vs Automated的批次规模差异较大（58 vs 126），加权平均可能掩盖子集特定问题。
7. **伦理考量**：论文自己承认，精确的故障诊断能力也可能被恶意利用（如针对性对抗攻击或提示注入）；LLM本身作为法官存在固有偏见风险；计算成本虽在推理端降低，训练段仍需要前期投入。
