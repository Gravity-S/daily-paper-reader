## 摘要
随着LLM智能体的激增，理解和诊断智能体失败的能力对于实现卓越的有效性和可信度至关重要。由于智能体失败通常通过漫长而复杂的轨迹显现，手动在“大海捞针”中寻找线索是不可行的。然而，传统的软件缺陷诊断技术难以应对LLM智能体失败，而完全依赖LLM作为评判者又会产生不可靠的诊断结果。为克服这些挑战，本文提出AGENTSCOPE，一种用于智能体失败模式诊断的新型神经符号方法。AGENTSCOPE的关键原则是基于其轨迹将智能体行为抽象为结构化表示。此外，AGENTSCOPE引入神经不变量的概念来指定智能体行为属性。AGENTSCOPE利用LLM引导的推理，在结构化表示之上针对神经不变量进行推理，以精确定位轨迹中的失败步骤及其类型。我们在公开可用的智能体失败数据集（Who&When）以及我们创建的更全面的数据集（AgentErrata）上展示了AGENTSCOPE的有效性，其中AGENTSCOPE在故障定位和归因准确性上显著优于当前最先进方法。我们的工作表明，将结构化抽象与LLM引导的推理相结合，能够实现智能体失败的有效、可靠且可解释的诊断。

## Abstract
With the proliferation of LLM agents, the ability to understand and diagnose failures in agents is essential to achieving superior effectiveness and trustworthiness. As agent failures often manifest via long and complex trajectories, manually finding the needles in the haystack is untenable. However, traditional diagnosis techniques for software bugs can hardly address LLM agent failures, while completely relying on LLMs as the judge yields unreliable diagnosis results. To overcome these challenges, this paper presents AGENTSCOPE, a new neuro-symbolic approach for agent failure mode diagnosis. The key principle of AGENTSCOPE is to abstract agent behavior, based on its trajectories, into structured representations. Furthermore, AGENTSCOPE introduces the concept of neural invariants to specify agent behavior properties. AGENTSCOPE leverages LLM-guided reasoning atop the structured representation against neural invariants to pinpoint both the failure step and its type in the trajectory. We show the effectiveness of AGENTSCOPE on publicly available agent failure datasets (Who&When) and a more comprehensive dataset created by us (AgentErrata), where AGENTSCOPE significantly outperforms the current state of the art in fault localization and attribution accuracy. Our work shows that integrating structured abstractions with LLM-guided reasoning enables effective, reliable, and interpretable diagnosis for agent failures.

## 2. 论文提出的方法论

**总体框架**：AGENTSCOPE，一种神经符号（neuro-symbolic）诊断框架，以**三阶段流水线**为核心设计。

### 2.1 核心概念一：行为抽象——Reasoning-Action Graph（ReAG）

论文将智能体轨迹转化为有向无环图 \(G = \{V, E\}\)：

- 每个顶点 \(v_i = \langle id_i, r_i, c_i, I_i \rangle\) 表示一个步骤（含步骤ID、角色、操作内容等）；
- 每条边 \(e \in E\) 表示步骤间的控制流或数据依赖；
- 每个顶点包含**中间语义表示（ISR）** \(I_i = \langle C_i, R_i, S_i \rangle\)，分别编码：
  - \(C_i\)：意图与上下文（任务目标与步骤目的）；
  - \(R_i\)：推理与行动（决策摘要、外部工具调用与输出）；
  - \(S_i\)：信号与验证（置信度、终止信号）。
- ReAG通过插桩API调用/工具交互构造，并辅以语义解析保证步骤边界清晰，使长轨迹可在结构化、语义对齐的层面被分析。

### 2.2 核心概念二：神经不变量（Neural Invariants）

- 借鉴传统程序不变量（如Hoare逻辑）的思想，但将其推广为可由**神经函数**（即LLM调用）编码和验证的语义条件。
- 论文根据10种失败模式（表1：Wrong Context、Instruction Unfollowing、Insufficient Context、Context Miss、Termination Miss、Premature Termination、Step Loop、Action Mismatch、Invocation Issue、Execution Failure）定义了一组对应的不变量违反条件（\(iv_f\)），每种失败模式形式化为一条神经不变量。
- 以**Action Mismatch**为例，其违反条件为：
  \[
  iv_{mismatch} ::= \exists n_t \in N_{action},\ n_{t-1} \in N_{reason}:\ \lnot aligned(purpose_{t-1}, action_t, tool\_name_t, tool\_args_t)
  \]
  其中 \(aligned(\cdot)\) 为LLM实现的二分类神经函数，其Prompt模板判断动作类型是否匹配步骤意图、工具选择是否符合语义、动作是否推进任务。
- 文中附录A列出了全部10类失败模式的正式不变量违反定义，每种均采用量词化的逻辑公式刻画步骤间关系与语义条件。

### 2.3 三阶段诊断流水线

1. **ReAG构建**：将原始运行时轨迹统一转换为带ISR注解的结构化图，降低原始文本的脆弱性和语义漂移；
2. **失败模式检测**：对图中相关步骤施加一组神经不变量检查，各模式用独立、任务特定的判断器做局部验证，保留所有候选失败及其证据；
3. **决定性错误判定**：从候选中筛选出对最终结果影响最大（最能解释劣化输出）的根因步骤，给出最终可追溯的判定。

### 2.4 设计动机

- 原始轨迹一次性推理易受长上下文、位置敏感性及隐式依赖丢失困扰；三阶段设计将“全局开放性诊断”拆分到“图构建→局部不变量检查→全局汇总判定”，从而缓解LLM固有限制。每个检测到的失败都关联局部证据，多候选保留使过程可审计、可扩展。

## 3. 实验设计

- **数据集一：Who&When**（公开基准）

  - 只标注失败步骤，无细粒度失败类型标签。
- **数据集二：AgentErrata**（自建基准）
  - 通过**失败分类法引导的故障注入**构建；
  - 覆盖OpenManus、OWL、Mini SWE Agent三类智能体框架，以及BrowseComp、SWE-Bench Lite、WebArena三类基准任务；

  - 人工验证过滤，现有303条高质量轨迹；失败类别分布均衡（Reasoning约36%，Control-flow约31%，Action约36%）。
- **对比基线**：
  - All-at-once（一次性整体判断法）；
  - Step-by-step（逐步前缀条件推理法）；

- **骨干模型**：GPT-4o（2024-11-20）、GPT-5.1（2025-11-13）、DeepSeek-V3.2，统一温度temperature=0.01、max_tokens=4096，经Azure AI Foundry部署。
- **评估指标**：
  - SLA（Step-Level Accuracy）：精确匹配失败步骤；
  - SLAT（Step-Level Accuracy with Tolerance）：允许偏差δ = ±0/±1/±3步；
  - CA（Classification Accuracy）：正确预测失败模式（含多候选时命中其一即可）。

## 6. 主要结论与发现

- **AGENTSCOPE在故障定位上显著优于基线**：AgentErrata上GPT-4o（w/o Solution）SLA达30.03%，远高于Step-by-step（8.91%）和All-at-once（2.09%），T±3时达49.83% vs 25.74%/23.69%；GPT-5.1下相对优势更大（31.35% vs 1.32%/3.30%）。
- **Whowhen上总体领先但存在标注口径差异**：Who&When Algo-Generated上部分设置与Step-by-step接近（如GPT-5.1下同为25.40%，T±0, w/o），原因是Who&When标注的是第一个错误、决策性错误判定关注对最终结果最关键的失败点——在多错误轨迹中两者可能不一致（附录C有案例分析）。
- **故障归因能力大幅提升**：AgentErrata上SLA从基线1.98%–3.63%提升至28.38%–31.35%（8–16倍增益），CA从18.15%–20.63%提升至41.58%–45.87%（超过2倍）。
- **跨模型稳定性强**：AGENTSCOPE在三种骨干上SLA变化范围仅4.95个百分点（30.03%–34.98%），而Step-by-step对模型切换极其敏感（GPT-4o为8.91%，GPT-5.1骤降至1.32%）；模型通用能力不能简单等价于诊断能力。
- **有无标准答案对结果影响不大**，说明增益来自结构化分解本身而非任务知识泄露。
- **运行时开销可控**：单条轨迹最长约750秒；Step Loop检测因需二次方量级的逐对比较最耗时（约85秒/轨迹）。
- 核心结论是：**结构化行为抽象 + 不变量引导推理 = 更可靠、更可解释、更可迁移的智能体失败诊断**。

## 7. 优点

- **概念创新**：提出ReAG和“神经不变量”（neural invariants），将传统程序验证思想扩展到语义层面，逻辑严谨且具可扩展性——新失败模式只需添加对应不变量即可。
- **系统性设计**：三阶段流水线合理分解了“全轨迹关联推理”难题，多候选保留→决定性选定的机制兼顾覆盖率与可追溯性。
- **可解释性**：每次诊断都关联局部证据，最终判定可回溯到不变量违反及其对应轨迹步骤，而非黑盒式LLM判断。
- **公开贡献**：自建AgentErrata基准包含303条带失败步骤+失败类型双重标注的轨迹，覆盖10类失败模式且分类分布均衡，为后续该方向研究提供公共数据集支撑。
- **评测覆盖全面**：多数据集、多骨干、有/无Answer对照、三档容忍度、模块化运行时剖析，较全面验证了方法有效性与稳健性。
- **运行时工程化思考**：指出失败检查相互独立、可并行化，且可按提示长度打包、利用前缀缓存等优化方向，具备工程部署意识。
- **讨论诚实深入**：对Who&When上的“劣势”情形给出了详细的案例分析，解释标注口径差异而非避而不谈。

## 8. 不足与局限

- **数据集标注口径与评估语义差异**：Who&When标注“首个错误”，而AGENTSCOPE判定“对结果影响最大的决定性错误”，两者目标不完全一致，导致在同一指标上难以完全公平比较，削弱了跨数据集比较的直接可参考性。
- **实验缺口**：
  - 缺乏消融实验，无法逐一量化ReAG、ISR、不变量检查、决定性错误判定各模块的相对贡献；
  - 未见置信区间/方差分析，无法判断改进是否具有统计显著性；
  - 每条件仅使用一种温度设置，未对LLM随机性做鲁棒性测试；
  - 无人类评估者对可解释性/诊断报告质量的独立评测。
- **CA指标的宽松性**：允许多个候选分类命中即判对（存在量词），可能使分类准确率高于实际可用价值。
- **自建数据集偏差风险**：AgentErrata采用LLM辅助判断轨迹与注入失败的适配性且经人工过滤，可能带来选择偏差；故障注入无法完全模拟真实运行环境中自然发生错误的语义多样性。
- **适用范围局限**：仅针对单/多智能体框架中的固定10类失败模式展开验证，对未知/新失败类型或者说超出分类学的新兴故障行为的泛化能力未经检验。
