## 摘要
具有持久记忆的智能体AI系统引入了一种独特的攻击面，称为记忆投毒，其中对抗性构造的内容被存储在长期记忆中，并随后影响智能体未来的行为。此类攻击可以抑制安全警报、促进权限提升、改变信任关系或覆盖安全策略，而无需修改底层模型权重或系统提示。为应对这一威胁，我们提出了 MemSentry，一个形式化、配置驱动的框架，它拦截拟进行的持久记忆写入，并产生确定性的接受、审查或隔离决策。MemSentry 通过共同考虑来源信任、语义风险、在组件依赖 DAG 上的攻击半径、访问风险，以及一个带符号的安全状态增量（用于刻画某项操作是削弱还是增强系统的安全态势）来评估每次写入。我们使用一个包含 20 个资产的随机依赖 DAG 和一个 10 x 20 的用户访问控制矩阵来实例化受保护环境，并在 1,000 个由 GPT-4 生成的场景上评估该框架，采用分层 70/30 的训练/测试划分。语义分类被视为一个可插拔组件，而非主要贡献，我们比较了四种代表性方法：基于规则的 Regex、TF-IDF+SVM、SBERT+LR 和 SetFit。SBERT+LR 取得了最佳整体性能，准确率为 91.7%，宏 F1 分数为 0.908，而所有四种方法都能检测出 100% 的外部隔离类威胁。对于来源信任最大（T = 1）的已验证内部人员，MemSentry 不会自动隔离可疑操作，而是将潜在危险的写入升级提交人工审查，这使得语义分类对于准确捕捉内部人员意图非常重要。

## Abstract
Agentic AI systems with persistent memory introduce a distinct attack surface known as memory poisoning, in which adversarially crafted content is stored in long-term memory and subsequently influences future agent behavior. Such attacks can suppress security alerts, facilitate privilege escalation, alter trust relationships, or override security policies without modifying the underlying model weights or system prompts. To address this threat, we present MemSentry, a formal, configuration-driven framework that intercepts proposed persistent-memory writes and produces deterministic Accept, Review, or Quarantine decisions. MemSentry evaluates each write by jointly considering source trust, semantic risk, attack radius over a component-dependency DAG, access risk, and a signed security-state delta that captures whether an operation weakens or strengthens the system's security posture. We instantiate the protected environment using a 20-asset random dependency DAG and a 10 x 20 user access-control matrix, and evaluate the framework over 1,000 GPT-4-generated scenarios using a stratified 70/30 train/test split. Semantic classification is treated as a pluggable component rather than a primary contribution, and we compare four representative approaches: rule-based Regex, TF-IDF+SVM, SBERT+LR, and SetFit. SBERT+LR achieves the best overall performance with 91.7% accuracy and a 0.908 macro-F1 score, while all four methods detect 100% of external quarantine-class threats. For verified insiders, where source trust is maximal (T = 1), MemSentry does not automatically quarantine suspicious operations but instead escalates potentially dangerous writes for human review, making semantic classification important for accurately capturing insider intent.

- **新型攻击面**：持久记忆引入了 **持久记忆投毒（Persistent Memory Poisoning, PMP）**。智能体常消费来自不可信来源的内容（用户上传文件、网页、邮件、共享文档、仓库文档），这些内容被摘要、转换后可能写入长期记忆。
- **与提示注入的本质区别**：PMP 只需一次成功的记忆写入，即可在无需持续对抗交互的情况下，长期影响未来的推理、规划与动作执行。攻击者可借此压制安全告警、促进权限提升、篡改信任关系、覆盖安全策略，且**无需修改模型权重或系统提示**。
- **核心洞察**：记忆投毒分析不能只判断“内容是否可疑”，还必须判断“它会影响哪些下游组件与安全功能”。因此 MemSentry 追问的是：**如果这条记忆被信任，会发生什么？**
- **整体含义**：论文提出一个形式化、配置驱动、可审计的**提交前（pre-commit）**评估框架，而非事后审计或检索时防御，为智能体记忆安全提供防御基线。

## 二、方法论

### 核心思想
MemSentry 拦截拟提交的持久记忆写入，通过 **9 步确定性流水线**，联合考虑来源信任、语义风险、依赖 DAG 上的攻击半径、访问风险与带符号的安全状态增量，输出 **Accept / Review / Quarantine** 三选一决策。系统被建模为有向图 G=(C,E)，C 为带关键度 q_i∈[0,1] 的组件，E 为依赖边。

### 九步流程与关键公式

1. **来源信任 T(source)∈[0,1]**：由来源（外部/内部）、身份验证状态、通道完整性三因素映射：
   - 外部未验证 = 0.0；外部已验证 = 0.5；内部未验证 = 0.5；内部已验证 = 1.0。

2. **语义分类**：(category, r_sem) = classify(O)。类别带风险分，如 security_strengthening(−0.30)、preference/schedule(0.05)、operational_fact(0.10)、trust_modification(0.70)、alert_suppression/policy_override(0.80)、conditional_trigger(0.85)、credential_storage/authority_claim(0.90)。负值表示增强安全。

3. **攻击半径 AR**：受影响组件集合 C_O = 直接目标 ∪ 沿依赖图深度受限（d_max）可达的下游组件；AR = |C_O| / |C|，即归一化覆盖比例。

4. **访问风险 R_access**：受影响的、主体无权限组件的关键度加权占比：
   R_access = Σ_{i∈C_O} q_i·1[unauthorized(i)] / Σ_{i∈C_O} q_i。

5. **当前安全态势 π(S_i)**：组件强度 s_j∈[0,1] 的关键度加权平均。

6. **投影状态 π(S_{i+1})**：
   - 对增强操作（r_sem<0）：π 上升，增量 ∝ |r_sem|·f_p·T·(1−AR)，即只有可信来源才能正向提升态势。
   - 对有害操作（r_sem>0）：π 下降，增量 ∝ r_sem·f_p·(1−T)·AR·AI，其中放大器 AI = α_base + α_access·R_access。
   - **持久因子 f_pers**：temporary→0.3，bounded→0.6，indefinite→1.0，时长越长影响越大。

7. **安全增量 δ(O) = π(S_{i+1}) − π(S_i)**：负值=态势退化，正值=态势增强。

8. **风险分 R**：
   R = α(1−T) + β·max(0, r_sem) + γ·R_access + ω·min(κ·max(0,−δ),1) + ε·AR。
   仅语义风险的**正部**参与计分，增强型操作不会抬高风险。

9. **决策规则（确定性）**：
   - 外部未验证（T=0）→ 无条件 Quarantine；
   - δ < −τ_Δ → Quarantine；
   - R ≥ τ_Q → Quarantine；
   - 满足 R ≤ τ_R 且 T > τ_T 且 R_access < τ_A 且 r_sem ≤ τ_S 且类别属良性 → Accept；
   - 其余 → Review（含“已授权但危险”的内部人威胁）。

### 输出与可解释性
每次评估生成结构化审计记录（source_trust、semantic_category、attack_radius、access_risk、security_delta、persistence_factor、insider_threat、risk_score、decision、reasons），解释由**模板化自然语言生成**（不使用 LLM），保证同输入同配置下完全可复现。

## 六、主要结论与发现

- **外部威胁防御稳健**：四种语义方法对**外部隔离类威胁检出率均达 100%**，因 T=0 触发无条件隔离规则，与内容无关。
- **整体性能**：SBERT+LR 最佳（准确率 91.7%、宏 F1 0.908、Review 准确率 72.2%）；TF-IDF+SVM 次之（88.0%、0.866，性价比高）；Regex 78.3%；SetFit 整体最弱（76.7%），尤其 Review 仅 22.2%（尽管 Accept/Quarantine 完美）。
- **内部人“天花板”效应**：验证内部人 T=1 使 (1−T)=0，δ 归零，R 永不越过 τ_Q=0.70，因此**内部人危险操作从不自动隔离，而是升级到 Review**。授权扫描中 Quarantine 准确率全程为 0%，这是**刻意的 fail-to-review 策略而非检测失败**；随授权升高，Accept 准确率上升、Review 准确率下降，SBERT+LR 在 100% 授权下仍保持 0.91 的 Review 准确率，SetFit 跌至 0.027。
- **语义推理鸿沟**：无任何方法在对比场景上解决超过 3/10 对（TF-IDF+SVM 3/10，Regex 1/10，SBERT+LR 与 SetFit 0/10）。诸如“已认证 vs 已授权”“临时 vs 永久”“记录 vs 压制”等细微差异需要意图级推理，超出表面词法/嵌入相似度能力。
- **攻击传播**：DAG 建模使攻击半径捕捉下游传播，汇点将 AR 限制在 0.05，高连通节点（asset_15 可影响 11 个资产）放大潜在影响。

## 七、优点

- **提交前评估定位新颖**：与多数事后审计/检索时防御（SMSR、MemAudit、MEMSHIELD、MIVL、A-memguard）不同，MemSentry 在记忆提交前拦截，可防止记忆状态被污染。
- **形式化 + 确定性**：完整公式化流水线，同输入同配置输出一致，模板化解释（非 LLM）保证可复现与可审计，适合合规场景。
- **影响感知（impact-aware）**：将依赖 DAG 攻击半径与安全状态增量纳入决策，超越纯语义判别，回答“若被信任会怎样”。
- **强制策略约束独立于学习分数**：外部未验证无条件隔离、关键组件强制 Review 等硬规则不受启发式/学习风险分影响，避免被绕过。
- **模块化设计**：语义分类作为可插拔组件，便于替换为更强的 LLM/NLI 意图推理器。
- **诚实的自我批判**：明确暴露内部人天花板与语义对比失败，并将其定位为开放问题，学术态度可取。

## 八、不足与局限

- **内部人防御薄弱**：T=1 导致退化项归零，危险内部人操作一律 Review，无法自动隔离；作者承认需引入额外基于内容的硬规则。这是框架的**结构性依赖**。
- **语义推理能力不足**：对比场景全面失败，表明现有轻量方法无法区分表面相似、安全含义相反的操作，实际部署中可能产生大量误放行（Review 队列膨胀）。
- **实验覆盖有限**：
  - 数据为单一 GPT-4 合成语料，存在分布偏差与“合成-真实”鸿沟风险；
  - 无消融实验、无权重/阈值敏感性分析、无多拓扑与多访问矩阵的鲁棒性验证；
  - 无真实攻击或人工红队验证，无端到端系统集成评估。
- **静态假设**：安全态势与依赖结构在评估期间视为静态，未考虑记忆随时间累积、系统拓扑演化、协调式多步攻击活动。
- **单操作视角**：仅评估单个记忆操作，未建模协同多条目投毒（与 MEMSHIELD 等针对协调攻击的差异）。
