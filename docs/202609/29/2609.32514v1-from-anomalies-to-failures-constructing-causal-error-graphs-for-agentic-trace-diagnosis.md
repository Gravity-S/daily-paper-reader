## 摘要
由LLM驱动的智能体越来越多地部署在复杂应用中，其中冗长的智能体轨迹使失败难以诊断。现有的轨迹诊断方法常常将异常、错误和失败混为一谈，导致诊断目标模糊；它们也缺乏对因果相关错误如何传播并放大为最终任务失败的结构化建模，从而导致不可靠的失败归因。为了解决这些问题，我们提出CEG-Agent，一个用于智能体轨迹因果诊断的工具增强型智能体框架。具体而言，CEG-Agent引入了异常、错误和失败的显式分类体系，并构建因果错误图（CEGs），这是一种统一的类型化表示，通过因果关系将执行事件、诊断节点和失败结果连接起来。为了评估因果轨迹诊断，我们进一步构建CEG-Bench，这是一个完全由智能体标注的基准，包含通过对抗式智能体裁决协议（AAAP）获得的高置信度、共识衍生的CEG标注。我们依据专家整理的人工金标准集验证了所得标注，结果表明其与自动标注高度一致。在CEG-Bench上的实验表明，CEG-Agent在语义宽松和结构精确两种评估标准下均达到最先进性能。我们的代码已公开。

## Abstract
LLM-driven agents are increasingly deployed in complex applications, where long agentic traces make failures difficult to diagnose. Existing trace diagnosis methods often conflate anomalies, errors, and failures, making diagnostic targets ambiguous; they also lack structured modeling of how causally relevant errors propagate and amplify into final task failures, resulting in unreliable failure attribution. To address these problems, we propose CEG-Agent, a tool-augmented agentic framework for causal diagnosis of agentic traces. Specifically, CEG-Agent introduces an explicit taxonomy of anomalies, errors, and failures, and constructs Causal Error Graphs (CEGs), a unified typed representation that links execution events, diagnostic nodes, and failure outcomes through causal relations. To evaluate causal trace diagnosis, we further construct CEG-Bench, a fully agent-annotated benchmark with high-confidence, consensus-derived CEG annotations obtained through an Adversarial Agentic Adjudication Protocol (AAAP). We validate the resulting annotations against an expert-curated human gold set, which shows close agreement with the automatic annotations. Experiments on CEG-Bench demonstrate that CEG-Agent achieves state-of-the-art performance under both semantically relaxed and structurally exact evaluation criteria. Our code is publicly available.

  - **缺乏因果结构建模**：现有方法多为扁平错误分类或步骤打分，无法刻画错误如何在轨迹中传播、放大并最终导致任务失败，归因不可靠，开发者难以判断应优先干预何处。
- **核心含义**：论文主张把轨迹诊断重新定义为对"类型化异质因果图"的受约束推断问题，提出 **CEG-Agent** 框架与 **CEG-Bench** 基准，推动智能体轨迹诊断从"现象描述"走向"因果归因"。

## 2. 方法论

### 2.1 核心思想
- 引入显式三分诊断体系：
  - **Anomaly（异常）**：现象级不规则性；
  - **Error（错误）**：与失败因果相关的过程级偏差；
  - **Failure（失败）**：结果级任务崩溃。
- 用 **因果错误图（CEG）** 作为统一类型化表示，将执行事件、诊断节点与失败结果通过类型化因果边连接。

### 2.2 形式化建模
- **问题形式化**：将轨迹诊断建模为受约束的最大后验（MAP）估计：
  - `G* = arg max_{G∈G*(T)} log p_θ(G | T)`
  - 约束集 `G*(T)` 强制三条诊断要求：(R1) 异常/错误/失败类型分离；(R2) 每个诊断节点须落地到具体执行事件；(R3) 错误与失败之间须有显式因果结构。
- **CEG 定义**：异质多关系图 `G = (V, E, τ_V, τ_E, x)`：
  - **节点类型** `T_V = {E, A, R, F}`，分别为事件、异常、错误、失败节点；
  - 错误节点属性 `x(r) = (ε(r), μ(r), ν(r), ρ(r), d(r))`，包含落地事件、粗粒度机制、细粒度子机制、结构角色（ROOT / PROPAGATED / AMPLIFICATION）、轨迹证据描述；
  - **边类型** `L = {EVENT-NEXT, ATTACHED-TO, CAUSES, AMPLIFIES, CONTRIBUTES-TO}`，并通过合法端点关系 Ω 强制类型一致性；
  - **因果子图** `G_C` 由 `{CAUSES, AMPLIFIES, CONTRIBUTES-TO}` 投影得到，用于定义失败可达集 `Reach_G(r)`。
- **良构性流形（Well-Formedness Manifold）** 四个谓词：
  - W1：类型化边一致性；
  - W2：每个错误须有事件落地；
  - W3：每个错误须能因果连通到某个失败；
  - W4：异常与错误不得文本等价。

### 2.3 工具增强推断流程
- 将 MAP 近似为受约束的工具增强推断：顶层 LLM 维护诊断状态 `S_t = (T, G_t, H_t, Q_t)`，迭代采样工具 `u_t` 与参数 `a_t`，执行状态转移，至多 K 轮，最终由 `finalize` 触发 schema 投影 `Π`。
- **7 个核心诊断工具**：事件构建、失败分析、错误假设生成、因果图归纳、异常检测、图验证、修复价值估计。
- **5 个辅助工具**：轨迹/状态检查、进度跟踪、子智能体委派、图可视化、终止。
- **确定性 schema 投影 Π**：自动修复非法边、悬挂端点、重复边、缺失 EVENT-NEXT/ATTACHED-TO、角色–拓扑不匹配等结构违规；Π 幂等，保证最终图满足 W1∧W2∧W3。
- **LLM 批评循环**：对语义问题（异常–错误混淆、重复失败、角色误判等）生成紧凑补丁 `p = (Δ+_E, Δ−_E, Δ−_R, Δ−_F, Δ−_A, Δ_attr, Δ_merge)`，每轮应用补丁后投影回 schema，受批评预算 C 限制。
- **反事实修复价值估计**：为每个错误分配 HIGH/MEDIUM/LOW，综合四个结构信号（反事实切断度 σ、放大信用 α、上游危害 η、角色先验 π）与有界词汇信号 h，加权裁剪后分桶；并有两条硬性覆盖规则（不在失败贡献集则强制 LOW；存在上游危害则上限 MEDIUM）。

## 3. 实验设计

- **CEG-Bench**：100 条失败的 GLM-4.6 智能体轨迹，来自三个真实基准各 50 条候选、最终保留：

### 3.2 评估指标
- **SRE（语义宽松评估，CEG-Sim）**：基于匈牙利二分匹配对齐节点，按结构（error_node、causal_edge、main_chain 各 20%）、文本（failure、attribution、anomaly 各 10%）、效用（event、consistency 各 5%）分层加权。

### 3.3 对比方法
- **raw 基线**：Claude Code / Codex 直接给原始轨迹与 CEG schema，端到端诊断。
- **+Process 基线**：提供确定性事件分段与 EVENT-NEXT 边，隔离解析与诊断。
- **CEG-Agent（ours）**：同一 backbone 下的完整框架。
- **跨 backbone 泛化**：Claude-Opus-4.7、GLM-5.1、GPT-5.5、Gemini-3.1-Pro、Qwen3.7-Max。
- **闭环修复实验**：4 种反馈（generic、CEG: failure、CEG: errors、CEG: priority errors），在 Tau2Bench、BrowseComp、SWE-bench 上测 pass@1。

## 6. 主要结论与发现

- **整体性能最优**：CEG-Agent 在两个 backbone 家族的 SRE 与 SEE 均取得最佳总分。
  - Claude：CEG-Claude 相比 +Process 基线提升 +2.0 SRE、+1.2 SEE；
  - GPT-5.5：CEG-Codex 提升 +13.6 SRE、+6.5 SEE，增益更大，说明结构化工具使用与验证可补偿较弱的基础诊断能力。
- **增益集中于核心结构能力**：SRE main_chain、causal_edge、anomaly 与 SEE error、attached_to、causes 提升最明显；即"区分异常与因果错误、重建错误传播链"是主要受益点。
- **非空子集上优势更显著**：在 85 条有实质因果结构的轨迹上，Claude 提升 +5.6/+1.4、GPT-5.5 提升 +13.0/+6.2（SRE/SEE）。
- **AAAP 与人类金标高度一致**：整体 CEG-Sim = 71.5；error/failure/anomaly 一致性 76.3/76.3/88.1；SEE 一致性随轨迹复杂度上升（小/中/大 = 43.0/45.8/52.4）。
- **跨 backbone 泛化**：即使最弱 backbone Qwen3.7-Max 的 SRE 43.7 也高于最强 Codex 基线 32.9；SRE 与 SEE 排名在头部之后出现分化，说明"流畅诊断描述"与"精确因果结构重建"是不同能力。
- **闭环修复**：CEG 反馈在交互式 Tau2Bench 上最有效（failure 提示 91.7 vs generic 77.8）；BrowseComp 上 error 提示更优（17.2 vs 10.3）；SWE-bench 上 priority-error 过滤反而有害，提示修复价值校准尚不完善。
- **仍具挑战**：最佳系统仅 51.6 SRE、20.5 SEE，说明长轨迹因果诊断仍是难题。

## 7. 优点

- **概念清晰**：首次将轨迹诊断中的异常、错误、失败显式分离，诊断目标与优化目标明确，避免笼统 "error" 标签带来的语义混淆。
- **表示力强**：CEG 作为类型化异质多关系图，同时支持事件落地、因果传播、失败归因与修复优先级，兼顾机器评估与人类可视化调试。
- **工程严谨**：确定性 validator + schema 投影 Π 幂等保证输出必然良构，配合 LLM

批评循环兼顾结构合法性与语义正确性，工具集模块化（诊断工具 + 辅助工具分离）便于扩展与消融。
- **评估设计完备**：同时给出语义宽松（SRE/CEG-Sim）与结构精确（SEE/CEG-Exact）两套指标，前者容忍表达多样性、后者惩罚结构错误，避免"指标即结论"的循环论证；并用 AAAP 自动标注 + 8 位人类专家金标双重审计，对标注质量做了独立验证。
- **因果—修复闭环**：不止于"诊断得更好"，还通过修复价值估计与下游闭环修复实验，验证诊断结果能否转化为可执行的干预收益，使框架具备实际调试价值。
- **成本可控**：迭代式工具增强推断并未显著抬高 token/计费成本（甚至略低于 raw 基线），说明结构化诊断的收益不是以暴力增加推理预算换取的。
- **诚实报告负结果**：明确披露 SWE-bench 上 priority-error 反馈反而有害、SEE 因文本风格与 gold-empty 偏差需拆分分析等不利发现，学术诚实度较高。

## 8. 局限与批判性评价

- **基准规模与代表性有限**：CEG-Bench 仅 100 条轨迹、来自 3 个基准、且全部由 GLM-4.6 单一模型产生。跨模型（尤其闭源旗舰与小型开源模型）失败模式的分布差异未经验证，结论的外部效度存疑。
- **标注者同源风险**：Drafter、Reviewer、Adversary 虽角色分离，但核心模型高度重叠（Claude-Opus-4.6/4.7、GPT-5.5）。AAAP 的"共识"可能反映模型间的共同偏见，而非客观真值；人类金标虽为独立审计，但 8 位专家对 100 条长轨迹的交叉标注成本极高，可推测每条轨迹获得的专家深度有限。
- **缺乏严格同构基线**：作者自认不存在输出同 schema 类型化因果图的外部系统，+Process 基线是"最接近"而非"等价"的对照。这使得 CEG-Agent 的相对增益中，有多少来自框架思想、有多少来自工具与 validator 的工程实现，难以彻底解耦。
- **闭环修复证据偏弱**：每源仅 29–36 条样本，作者自称"方向性而非统计决定性"；且不同来源最优反馈策略不一致（Tau2Bench 偏好 failure 提示、BrowseComp 偏好 error 提示、SWE-bench 上 priority 过滤有害），说明修复价值估计尚未稳健泛化，目前更像经验性启发而非可迁移的通用原则。
- **SRE/SEE 的内在张力未完全解决**：SRE failure/attribution 与 SEE contributes_to 存在系统性偏差（文本风格、gold-empty 导致的机制性扣分），虽通过拆分分析缓解，但指标本身的构造效度（是否真正衡量"诊断质量"而非"与 gold 的格式相似度"）仍待更严格的效度验证。
- **可解释性与可复现性的权衡**：7 个诊断工具 + 5 个辅助工具 + 确定性投影 + 批评循环构成较复杂的推理流水线，超参数（K=24、C=2、四个结构信号的权重与分桶阈值）较多，论文未充分报告这些超参的敏感性分析，复现与调参门槛偏高。

## 9. 对领域的启示与未来方向

- **概念层面**：把"异常/错误/失败"三分并形式化为受约束 MAP 推断，为智能体可观测性（observability）提供了一个可复用的本体论（ontology），可推广到 agent 评测、RLHF 归因、自动化调试等多个下游场景。
- **方法层面**：类型化异质因果图 + 确定性 schema 投影 + LLM 批评循环的组合，是"让 LLM 输出结构化、可验证、可修复中间产物"的一种通用范式，不限于轨迹诊断。
- **评估层面**：语义宽松与结构精确双指标并行、自动标注 + 人类金标双重审计、对 gold-empty 与文本风格偏差做专门拆分的做法，值得作为智能体评测类工作的参考模板。
- **潜在扩展**：将 CEG 从"事后诊断"拓展到"在线监控与早期预警"；把修复价值估计与真实修复动作（而非仅提示）耦合形成 agent 自愈闭环；构建多模型、多任务、跨领域的更大规模 CEG-Bench 以检验泛化性。

## 10. 总体评价

论文针对 LLM 智能体长轨迹失败难诊断这一真实且日益重要的问题，提出了概念清晰、表示力强、工程严谨的 CEG-Agent 框架，并配套构建了带有人类金标审计的 CEG-Bench 基准。其最大贡献在于**把"现象描述式"错误分析推进到"类型化因果归因"**，并用双指标与消融实验较为扎实地支撑了这一转变的有效性。同时，论文对自身局限（基准规模、基线同构性、闭环修复证据强度、指标偏差）保持了较诚实的披露。综合而言，这是一篇问题定义好、方法体系完整、实验设计规范的高质量工作；其主要提升空间在于扩大基准规模与模型多样性、寻找更严格的外部基线、以及提升修复价值估计的稳健性与超参透明度。当前最佳系统仅约 51.6 SRE / 20.5 SEE 的结果也表明，长轨迹因果诊断仍是开放难题，为该方向留下了充足的研究空间。
