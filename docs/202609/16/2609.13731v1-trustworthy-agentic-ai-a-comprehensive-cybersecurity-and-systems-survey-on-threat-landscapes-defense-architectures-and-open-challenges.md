## 摘要
从被动基础模型向自主、目标导向的智能体AI系统的转变，通过耦合递归认知推理循环、持久记忆架构、实时工具执行平面和多智能体协作拓扑，带来了前所未有的能力。然而，将执行权限授予概率性神经核心并使其跨越文件系统、网络和云基础设施，消解了经典安全边界：自然语言同时充当输入数据、内部控制代码和通信协议，暴露出一个图灵完备的爆炸半径，其中不可信数据即代表可执行指令。本综述为可信智能体AI提供了一个全面的系统安全参考框架，综合了206项基础研究与监管标准。我们将通用智能体架构形式化为有状态五元组，并建立了一个涵盖安全性（security）、安全（safety）、隐私、可解释性、公平性和问责制的六维可信性分类体系。我们系统分析了执行循环内部与交互平面上的威胁面，提出了一种集成双LLM隔离、基于能力的访问控制、内核eBPF探针和沙箱运行时的多层零信任纵深防御架构，综述了标准化评估基准，并将技术控制措施映射到国际AI治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

## 六、主要结果与发现

> 以下为综述**汇总与提炼**的结论，而非作者原创实验所得。

### 1. 威胁态势结论
- **提示注入是"智能体时代的缓冲区溢出"**：由于 `数据 ≡ 控制逻辑`，任何可被智能体读取的自然语言输入都构成潜在攻击面，防御难度高于传统 XSS/SQLi，因为不存在可参数化的"指令-数据"语法边界。
- **攻击面随能力单调扩张**：工具权限（Shell/云 API/MCP）越多、记忆越持久、多智能体拓扑越复杂，爆炸半径 BRI 越大；安全性与自主性呈结构性张力。
- **间接注入（IPI）比直接注入更危险**：攻击者可潜伏于网页、文档、RAG 语料甚至对等智能体消息中，形成**零点击、跨会话、可自复制**的持久威胁（Morris II 即为其形态学证明）。
- **供应链与协议层成为新前沿**：MCP 工具描述、向量嵌入、DID/VC 凭证均可被投毒或抢注，攻击从模型内部迁移至编排与协议栈。

### 2. 防御态势结论
- **单点防御必然失效**：任何单一护栏（如输入过滤、输出审查）都无法应对概率性控制流与多步规划的攻击链，必须采用**纵深、零信任、跨层协同**的架构。
- **四大防御支柱的有效性排序（文献综合判断）**：
  1. **系统沙箱 + 最小权限（CapBAC）**——最高性价比，能硬性约束爆炸半径；
  2. **认知护栏（Dual-LLM / 注意力掩码）**——对提示注入直接有效，但延迟与 token 成本显著；
  3. **记忆密码学溯源（签名嵌入 + Merkle 审计）**——对投毒与篡改检测强，但对语义级污染（合法签名的错误内容）无效；
  4. **多智能体零信任协议（DID/mTLS/PBFT）**——抗 Sybil 与 Byzantine，但 `O(n²)` 通信开销限制规模。
- **硬件 TEE 是"最后防线"**：机密计算可将密钥与敏感推理置于加密内存，但 2–8% 性能损失且不防御语义层攻击。

### 3. 跨维权衡结论
- **安全 vs 延迟**：Dual-LLM +1.5–3.0s、eBPF <0.5ms，需要在不同风险等级下动态编排。
- **安全 vs 效用**：过度严格导致 FSRR 上升（False Safety Rejection），损害可用性，需以 FSRR 与 UPR 双指标联合调优。
- **隐私 vs 任务性能**：DP 噪声与嵌入加密降低检索精度，需在 ε 与任务效用间做 Pareto 选择。

## 七、开放挑战与未来方向

- **语义级完整性**：现有密码学溯源只能证明"内容未被篡改"，无法证明"内容本身无害"，需要**语义验证 / 事实一致性证明**机制。
- **概率性控制流的可验证性**：如何对 `a_t ~ P(a_t | H_{t-1})` 的采样结果给出形式化安全保证，是开放难题；需要**概率程序验证**与**运行时监控**的结合。
- **跨智能体信任的可扩展性**：PBFT 的 `O(n²)` 与 DID 生态尚未成熟，大规模异构智能体联邦的轻量共识与声誉机制亟待研究。
- **对抗鲁棒性与对齐的融合**：提示注入、后门、幻觉、越狱共享同一"语义操控"根源，需统一的**对抗对齐**理论。
- **标准化与治理落地**：如何将 NIST AI RMF、EU AI Act 的合规要求映射为可执行的工程控制（如 CapBAC 策略、审计日志格式），仍缺行业共识。
- **评测基准的统一**：ASR/UPR/FSRR/BRI/CFP 五指标的跨基准可比性需标准化，避免"各自最优、无法横比"。

## 八、结论

- 本综述首次系统性地将**智能体 AI 安全问题形式化**为一个横跨认知、记忆、行动、协作四平面的**系统安全子领域**，并提出：
  1. 统一的**五元组智能体模型**与**对抗性 POMDP** 威胁建模框架；
  2. **六维可信性分类**及其系统不变量；
  3. **执行内 / 交互双平面全谱威胁图**；
  4. **四层零信任纵深防御架构**（认知护栏 → 记忆溯源 → 系统沙箱 → 多智能体零信任协议），并辅以硬件 TEE。
- 核心论断：**智能体的安全边界必须从"数据与控制分离"的旧范式，转向"能力最小化 + 全链路零信任 + 跨层协同验证"的新范式**；任何单层防护都不足以应对以自然语言为载体的任意代码执行等价威胁。
- 最终立场：可信智能体 AI 不是单一技术问题，而是**架构、协议、密码学、形式化验证与治理规范**的系统工程，需在安全、效用、隐私、延迟之间做显式 Pareto 权衡。

## 九、局限与批判性评价

- **无原创实验**：作为综述，其防御架构未经实证；工程开销为引用估算，缺乏自身复现验证。
- **归一化不足**：跨基准 ASR/UPR 口径不一，汇总数据可能高估或低估真实风险。
- **防御架构的完备性存疑**：四层架构对**语义级攻击**（合法但恶意的自然语言指令、语义投毒）防御能力弱；Dual-LLM 本身亦可能被高阶注入绕过。
- **可扩展性未论证**：PBFT、DID、TEE 在超大智能体联邦下的可行性与成本未做量化分析。
- **时间敏感性**：智能体与 MCP 生态演进极快，综述结论存在快速过时风险。
- **贡献定位**：其价值主要在于**框架整合与分类学贡献**，而非新的攻击或防御技术本身。
