## 摘要
本文研究执行器约束、外部扰动和虚假数据注入（FDI）攻击下未知非线性多智能体系统的安全领导-跟随编队问题。将图耦合的协调误差动力学建模为局部零和微分博弈，其中非二次输入效用函数产生与饱和兼容的安全策略，而执行器通道的FDI和扰动则作为对抗性输入。为消除对未知非线性漂移项的显式依赖，积分Bellman-Isaacs恒等式使得仅利用有限轨迹数据进行评论家（critic）学习成为可能。一种双幂状态代价结构和截止时间参数化的评论家更新将最优学习与预定义时间镇定联系起来。与稳定时间上界由预先选定的增益决定的固定时间方法不同，所提框架首先分配总体截止时间，并将其在数据信息性、评论家学习、强化窗口和编队收敛之间进行分配。在初始条件无关的意义下，建立了评论家误差和编队误差到有界残差集的实用预定义时间收敛性，同时通过构造保证了安全执行器约束的满足。仿真在FDI攻击、扰动、输入约束和不同初始条件下验证了该框架。

## Abstract
This paper addresses secure leader-follower formation of unknown nonlinear multi-agent systems under actuator constraints, external disturbances, and false-data-injection (FDI) attacks. The graph-coupled coordination-error dynamics are formulated as local zero-sum differential games, where a nonquadratic input utility yields saturation-compatible secure policies and actuator-channel FDI and disturbances act as adversarial inputs. To eliminate explicit dependence on the unknown nonlinear drift, an integral Bellman-Isaacs identity enables critic-only learning from finite trajectory data. A two-power state-cost structure and a deadline-parameterized critic update connect optimal learning with predefined-time stabilization. Unlike fixed-time methods whose settling-time bound is determined by preselected gains, the proposed framework assigns the overall deadline first and allocates it among data informativity, critic learning, the reinforcement window, and formation convergence. Practical predefined-time convergence of the critic and formation errors to bounded residual sets is established independently of initial conditions, while secure actuator constraints are satisfied by construction. Simulations validate the framework under FDI attacks, disturbances, input constraints, and different initial conditions.

## 2. 论文提出的方法论

### 2.1 核心思想

将图耦合的协调误差动力学分解为**未知漂移、自身与邻居安全控制通道、局部与邻居对抗通道**，并构建**饱和感知的局部零和HJI博弈**。通过**双幂状态代价**生成预定义时间分析所需的耗散结构，利用**积分Bellman-Isaacs残差**消除对未知漂移的依赖，采用**有限回放数据**替代持续激励条件，最终通过**点式–积分Lyapunov分析**建立评论家与编队的实用预定义时间收敛。

### 2.2 关键技术细节

**(1) 问题建模与图论基础**

- 领导-跟随网络：一个领导者和N个非线性跟随者，动力学分别为 $\dot{x}_0 = f_0(x_0)$ 和 $\dot{x}_i = f_i(x_i) + g_i(x_i)u_i + d_i(x_i)\omega_i$。
- 控制通道FDI模型：$u_i(t) = u_{ci}(t) + u_{ai}(t)$，其中 $u_{ci}$ 为防御者生成的安全控制，$u_{ai}$ 为FDI信号。
- 对称输入约束：$|u_{ci,\ell}| < \bar{u}_{i\ell}$，约束仅施加于防御者生成的命令，不包含饱和映射。
- 协调误差定义：$e_i := x_i - x_0 - h_i$，$\chi_i := \sum_{j\in N_i} a_{ij}(e_i - e_j) + b_{i0}e_i$，满足 $\chi = (H \otimes I_n)e$。
- 图连通性假设：领导者全局可达，$H$ 非奇异，存在正对角矩阵 $\Pi$ 使 $H_s > 0$。

**(2) 局部零和微分博弈与HJI方程**

- 局部图博弈代价函数（式17）：
  $$J_i = \int_0^\infty \left[ Q_{ii}(\chi_i) + U_i(u_{ci}) + \sum_{j\in N_i} U_{ij}(u_{cj}) - \gamma_i^2 \varpi_i^\top T_{ii}\varpi_i - \gamma_i^2 \sum_{j\in N_i} \varpi_j^\top T_{ij}\varpi_j \right] dt$$
- 其中 $Q_{ii}$ 为状态惩罚，$U_i, U_{ij}$ 惩罚安全控制努力，负二次项表示扰动与同通道FDI攻击的最大化角色。
- 值函数：$V_i^*(\chi_i(0)) = \min_{u_{ci}} \max_{\varpi_i, \varpi_{-i}} J_i$。
- Nash鞍点条件（引理1）：标准零和动态博弈的鞍点刻画。
- 名义局部HJI方程（命题1）：$0 = \min_{u_{ci}\in U_i} \max_{\varpi_i, \varpi_{-i}} \bar{H}_i$。

**(3) 预定义时间比较与双幂结构**

- 归一化预定义时间比较定理（定理1）：若 $\dot{V} \leq -\frac{\gamma_{p,q,r}}{T_s}[\alpha V^p + \beta V^q]^r$，则原点全局预定义时间稳定，$T(x_0) \leq T_s$。
- 精确双幂稳定时间积分（引理2）：$\dot{Y} \leq -aY^{(\gamma_1+1)/2} - bY^{(\gamma_2+1)/2}$ 的稳定时间上界与 $Y(t_0)$ 无关。
- 关键设计：$Q_{ii}(\chi_i) = \chi_i^\top Q_i \chi_i + \lambda_x \kappa_{i1}\|\chi_i\|^{2\gamma_1} + \lambda_x \kappa_{i2}\|\chi_i\|^{2\nu}$，其中 $0 < \gamma_1 < 1 < \gamma_2$，$\mu = (\gamma_1+1)/2$，$\nu = (\gamma_2+1)/2$。

**(4) 饱和兼容的非二次输入效用**

- 输入效用：$U_i(u_{ci}) = 2\sum_{\ell=1}^m \bar{u}_{i\ell} r_{i\ell} \int_0^{u_{ci,\ell}} \tanh^{-1}(s/\bar{u}_{i\ell}) ds$。
- 鞍点安全策略：$u_{ci}^* = -\bar{U}_i \tanh\left(\frac{1}{2}R_i^{-1}\bar{U}_i^{-1}G_{ii}^{\chi\top}(x_i)\nabla V_i^*\right)$，**由构造满足 $u_{ci}^* \in U_i$**。

- 归一化回归量：$\psi_i = \Delta\phi_i/(1+\Delta\phi_i^\top\Delta\phi_i)$。

**(6) 双幂评论家更新律**

- 残差目标：$E_i(\hat{W}_i) = \frac{|\delta_i|^{\gamma_1+1}}{(\gamma_1+1)\mu_i} + \frac{|\delta_i|^{\gamma_2+1}}{(\gamma_2+1)\mu_i} + \sum_{k=1}^{M_i}\left(\frac{|\delta_{ik}|^{\gamma_1+1}}{(\gamma_1+1)\mu_{ik}} + \frac{|\delta_{ik}|^{\gamma_2+1}}{(\gamma_2+1)\mu_{ik}}\right)$。
- 评论家更新律（式30）：
  $$\dot{\hat{W}}_i = -\Gamma_i\left\{\psi_i\left[k_{i1}|\delta_i|^{\gamma_1}\text{sgn}(\delta_i) + k_{i2}|\delta_i|^{\gamma_2}\text{sgn}(\delta_i)\right] + \sum_{k=1}^{M_i}\psi_{ik}\left[k_{i1}^r|\delta_{ik}|^{\gamma_1}\text{sgn}(\delta_{ik}) + k_{i2}^r|\delta_{ik}|^{\gamma_2}\text{sgn}(\delta_{ik})\right]\right\}$$
- 选取 $\Gamma_i = \alpha_{c,i}I_{N_i}$，其中 $\alpha_{c,i}$ 由指定的评论家学习时限 $T_W$ 反设计确定。

**(7) 预定义时间稳定性分析**

- **评论家预定义时间学习（定理2）**：
  - 精确残差情形：若 $\alpha_{c,i} \geq \frac{\Gamma_E(A_\gamma)\Gamma_E(B_\gamma)}{T_W(\gamma_2-\gamma_1)\varsigma_i^2(k_{i1}^r)^{A_\gamma}(k_{i2}^r)^{B_\gamma}M_i^{(1-\gamma_1)(1-\gamma_2)/(2(\gamma_2-\gamma_1))}}$，则 $\tilde{W}_i(t)=0, t\geq T_E+T_W$。
  - 非零残差情形：$\alpha_{c,i}$ 满足类似条件时，$V_{c,i}$ 在 $T_E+T_W$ 内进入前向不变集 $B_{W_i}$，评论家误差有界。
  - 引理5（扰动符号幂不等式）和回放强制性是证明关键。

- **预定义时间闭环稳定性（定理3）**：
  - 定义移动窗口理想值能量 $I_i(t) = \int_{t-T_i}^t V_i^*(\chi_i(\tau))d\tau$。
  - 引理6（导数受限低阶窗口界）：$\int_{t-T}^t y^{\gamma_1}(\tau)d\tau \geq \rho_{\gamma_1,T}\left(\int_{t-T}^t y(\tau)d\tau\right)^\mu$。
  - 混合积分–点式Lyapunov泛函：$\mathcal{J}(t) := I_\chi(t) + V_c(t)$。
  - 得到 $\dot{\mathcal{J}} \leq -C_1\mathcal{J}^\mu - C_2\mathcal{J}^\nu + \Delta_\mathcal{J}$，其中 $C_1 := \min\{a_\chi, h_1\}$，$C_2 := 2^{1-\nu}\min\{b_\chi, h_2\}$。
  - **截止时间分配**：$T_p = \bar{T}_E + T_W + T_{\max} + T_X$，其中 $\bar{T}_E$ 为数据信息性上界，$T_W = \vartheta_T(T_p - \bar{T}_E - T_{\max})$ 为评论家学习时限，$T_X = (1-\vartheta_T)(T_p - \bar{T}_E - T_{\max})$ 为编队收敛时限。
  - **反设计增益选择**：
    - 状态侧：$\lambda_x \geq \max\left\{\frac{\Lambda_X}{\min_i\{c_{i1}\rho_{i,T}\}}, \frac{(2N)^{\nu-1}\Lambda_X}{\min_i\{c_{i2}T_i^{1-\nu}\}}\right\}$
    - 评论家侧：$\alpha_{c,i} \geq \max\{\alpha_{W,i}, \alpha_{X,i}\}$
  - 最终结论：$\mathcal{J}(t)$ 在 $T_p$ 前进入前向不变集 $B_\mathcal{J}$，编队误差 $\|e(t)\| \leq r_e$，评论家误差 $\|\tilde{W}_i(t)\| \leq r_{W_i}$。

**(8) 主要贡献（四点）**

1. **端到端弹性架构**：集成图耦合安全编队、饱和感知图博弈、IRL、FDI/扰动抑制和预定义时间认证。
2. **代价诱导的预定义时间HJI构造**：利用低阶和高阶状态惩罚生成所需双幂耗散，不对未知理想值函数施加限制性条件。
3. **仅评论家积分学习律**：从指定评论家学习时限显式合成增益，有限回放信息性替代持续激励。
4. **统一点式–积分Lyapunov分析**：结合导数受限移动窗口不等式与显式截止时间分配，建立学习与编队的实用预定义时间收敛，同时保持执行器约束。
