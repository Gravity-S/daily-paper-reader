## 摘要
针对具有未知动态、外部扰动以及执行器通道上虚假数据注入（FDI）攻击的非线性多智能体系统，研究了领航者-跟随者编队控制问题。将该问题建模为零和微分博弈，并采用积分Bellman-Isaacs方法求解。为处理输入饱和约束，将非二次控制代价函数引入优化问题，从而得到有界控制律。此外，本文提出了一种代价函数构造方法，并设计了一种评价器学习律，二者共同保证了系统的实用固定时间稳定性，同时克服了现有固定时间强化学习形式的局限性。最后，严格证明了评价器权重估计误差和领航者参考编队跟踪误差均能在实用固定时间内收敛到有界残差集。仿真结果验证了所提方法在外部扰动、FDI攻击和输入约束下的有效性。

## Abstract
The leader-follower formation control problem is investigated for nonlinear multi-agent systems with unknown dynamics, external disturbances, and false data injection (FDI) attacks on actuator channels. The problem is formulated as a zero-sum differential game and solved using the Integral Bellman-Isaacs approach. To address input saturation constraints, a non-quadratic control cost function is incorporated into the optimization problem, leading to a bounded control law. Furthermore, this paper proposes a cost function construction method and develops a critic learning law, which together guarantee the practical fixed-time stability of the system while overcoming the limitations of existing fixed-time reinforcement learning formulations. Finally, the practical fixed-time convergence of both the critic weight estimation error and the leader-referenced formation tracking error to bounded residual sets is rigorously proven. Simulation results demonstrate the effectiveness of the proposed method under external disturbances, FDI attacks, and input constraints.

- **研究背景**：编队控制广泛应用于协作机器人、自动驾驶车辆和分布式信息物理系统，但分布式协调所需的通信与执行通道构成了攻击面。虚假数据注入（FDI）信号可污染测量值、交换信息或控制指令，并通过交互图传播，从而破坏集体行为。
- **核心问题**：在**未知非线性动态、外部扰动、执行器通道FDI攻击以及输入饱和约束**同时存在的情况下，如何实现非线性多智能体系统的安全编队控制。
- **关键难点**：
  - 非线性系统的Hamilton-Jacobi-Isaacs（HJI）方程一般难以解析求解，且需要已知系统漂移项；
  - 输入饱和需在最优控制问题内部处理，而非外部截断；

  - 现有固定时间强化学习工作（如文献[14]）仅针对较简单的二阶MAS模型，且对固定时间相容的性能结构作了较强假设。

## 2. 方法论

### 2.1 核心思想

- **零和微分博弈建模**：将安全控制策略 \(u_{ci}\) 视为最小化方，将外部扰动 \(\omega_i\) 与同通道FDI信号 \(u_{ai}\) 视为最大化方，用Nash鞍点条件刻画最优性。
- **代价诱导的固定时间结构**：不在未知HJI值函数上强加固定时间耗散不等式，而是**将收敛速率项嵌入博弈的运行代价**中，使HJI方程自然产生所需的双幂次耗散项。
- **积分Bellman-Isaacs残差**：将逐点HJI等式重铸为有限窗口上的积分恒等式，从而在评价器学习中**消去未知漂移** \(F_{\chi_i}(\xi_i)\)。
- **经验回放替代持续激励**：利用预攻击阶段收集的记录数据满足初始激励条件，避免对持续激励的苛刻要求。

### 2.2 关键技术细节

**（1）协调误差动态分解**

跟随者动态为 \(\dot{x}_i = f_i(x_i) + g_i(x_i)u_i + d_i(x_i)\omega_i\)，其中 \(u_i = u_{ci} + u_{ai}\)。定义分布式协调误差：
\[
\chi_i = \sum_{j\in N_i} a_{ij}(e_i - e_j) + b_{i0}e_i, \quad \chi = (H\otimes I_n)e
\]
将 \(\dot{\chi}_i\) 分解为**未知漂移、自身安全控制通道、邻居安全控制耦合、局部与邻居对抗通道**四部分。

**（2）饱和相容的非二次效用**

安全输入效用采用：
\[
U_i(u_{ci}) = 2\sum_{\ell=1}^m \bar{u}_{i\ell}r_{i\ell}\int_0^{u_{ci,\ell}} \tanh^{-1}\!\left(\frac{s}{\bar{u}_{i\ell}}\right)ds
\]
由驻点条件 \(\partial \bar{H}_i/\partial u_{ci}=0\) 得到**双曲正切有界策略**：
\[
u_{ci}^* = -\bar{U}_i\tanh\!\left(\frac{1}{2}R_i^{-1}\bar{U}_i^{-1}G_{\chi_i i}^{\top}\nabla V_i^*\right)
\]
从而保证 \(u_{ci}^*\in\mathcal{U}_i\) 由构造满足。

**（3）两幂次状态惩罚**

\[
Q_{ii}(\chi_i) = \chi_i^{\top}Q_i\chi_i + \kappa_{i1}\|\chi_i\|^{2\alpha_i} + \kappa_{i2}\|\chi_i\|^{2\beta_i}, \quad 0<\alpha_i<1<\beta_i
\]
结合值函数上界 \(V_i^*\le \bar{c}_i\|\chi_i\|^2\)，HJI方程贡献的 \(-Q_{ii}\) 自动产生 \(-(V_i^*)^{\alpha_i}\) 与 \(-(V_i^*)^{\beta_i}\) 耗散项，实现固定时间比较条件。

**（4）积分Bellman-Isaacs残差与固定时间评价器更新**

- 积分恒等式：\(0 = V_i^*(\chi_i(t)) - V_i^*(\chi_i(t-T_i)) + \int_{t-T_i}^t \hat{r}_i\,d\tau\)
- 在线残差：\(\delta_i(t) = \hat{W}_i^{\top}\Delta\phi_i(t) + \int_{t-T_i}^t \hat{r}_i(\tau)d\tau\)
- 残差目标函数采用双幂次形式 \(|δ|^{p+1}+|δ|^{q+1}\)（\(0<p<1<q\)），与固定时间Lyapunov构造同构
- 评价器更新律：
\[
\dot{\hat{W}}_i = -\Gamma_i\left(\psi_i s_i + \sum_{k=1}^{M_i}\psi_{ik}s_{ik}\right) - \sigma_i\Gamma_i\hat{W}_i
\]
其中 \(s_i = k_{i1}|\delta_i|^{p_i}\mathrm{sgn}(\delta_i) + k_{i2}|\delta_i|^{q_i}\mathrm{sgn}(\delta_i)\)，带泄漏项和经验回放。

**（5）稳定性证明框架**

- 定理2：证明评价器权重估计误差 \(\tilde{W}_i\) 固定时间实用稳定，收敛界与 \(\tilde{W}_i(0)\) 无关；
- 定理3：构造混合积分-逐点Lyapunov泛函 \(J_i(t) = \int_{t-T_i}^t V_i^*(\chi_i(\tau))d\tau + \lambda_{W_i}V_{W_i}(t)\)，证明 \(\dot{J}_i \le -c_{i1}J_i^{\rho_i} - c_{i2}J_i^{\theta_i} + \Delta_{ci}\)，从而编队误差与评价器误差均固定时间实用有界；
- 功率匹配条件：\(p_i=\alpha_i\)，\(q_i=2\beta_i-1\)，使被控系统与评价器共享同一对固定时间幂次。

**（6）初始容许策略的数据复用构造（附录A）**

利用已存储的回放数据构造Koopman-Riccati控制器 \(u_{ci}^{(0)}=-K_{0i}\eta_i\)，在局部子水平集 \(\Omega_i^0\) 上证明其为容许策略，避免仅假设初始容许策略存在。
