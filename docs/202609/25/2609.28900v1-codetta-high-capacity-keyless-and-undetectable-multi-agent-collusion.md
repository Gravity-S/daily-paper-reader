## 摘要
基于大语言模型（LLM）的多智能体系统正越来越多地部署于金融、医疗和软件工程等高风险场景中，其中智能体通过自然语言消息进行协调。然而，同样的信道也使合谋智能体能够泄露机密信息或协调未经授权的行动，而隐写术可以将此类通信隐藏在对于阅读通信记录的审计者而言看似普通的输出中。

现有可证明不可检测的 LLM 隐写协议并不适合现实部署。高容量方案假设接收方能够复现发送方输出分布的对称设置；面向非对称智能体的当前最优协议容量非常低；并且大多数方法依赖预共享秘密密钥。

我们通过 Codetta 将不可检测智能体合谋的威胁具体化，这是一种面向现实非对称设置中独立部署智能体的高容量隐写协议。Codetta 结合了一个用于估计通信信道的共享公共模型、一种保持发送方输出分布的采样机制，以及一种自适应纠错码。它还通过隐写密钥交换去除了预共享密钥，使独立部署的智能体能够建立共享密钥，同时让通信记录在计算上与普通模型输出不可区分。

在三种智能体工作负载和三种发送方模型上，Codetta 达到了当前最优非对称协议容量的最高 94 倍，其密钥交换以约 80k 可见 token 建立了共享密钥，并经实证认证的失败概率至多为 4.1×10^{-3}。这些结果表明，独立部署的智能体之间实现实际上不可检测的合谋正变得可行，因此审计必须超越对通信记录的检查。

## Abstract
Multi-agent systems built on large language models (LLMs) are increasingly deployed in high-stakes settings such as finance, healthcare, and software engineering, where agents coordinate through natural-language messages. The same channels, however, let colluding agents exfiltrate confidential information or coordinate unauthorized actions, and steganography can hide such communication inside outputs that look ordinary to an auditor reading the transcript.   Existing provably undetectable LLM steganography protocols are not suited to realistic deployments. High-capacity schemes assume a symmetric setting where the receiver can reproduce the sender's output distribution, the state-of-the-art protocol for asymmetric agents has very low capacity, and most approaches rely on a pre-shared secret key.   We make the threat of undetectable agent collusion concrete with Codetta, a high-capacity steganographic protocol for independently deployed agents in realistic asymmetric settings. Codetta combines a shared public model that estimates the communication channel, a sampling mechanism that preserves the sender's output distribution, and an adaptive error-correcting code. It further removes the pre-shared key through a steganographic key exchange that lets independently deployed agents establish a shared key while keeping the transcript computationally indistinguishable from ordinary model outputs.   Across three agent workloads and three sender models, Codetta achieves up to $94\times$ the capacity of the state-of-the-art asymmetric protocol, and its key exchange establishes a shared key with about 80k visible tokens at an empirically certified failure probability of at most $4.1\times 10^{-3}$. These results show that effectively undetectable collusion is becoming feasible between independently deployed agents, so auditing must go beyond inspecting communication transcripts.

- **现有隐写协议的三重不匹配**：
  - **模型与上下文非对称**：高容量可证明安全方案假设收发双方共享模型、提示上下文与智能体状态（对称设置），而独立部署的智能体不具备这一条件。
  - **容量过低**：面向非对称场景的当前最优实用协议（ARS，Bai et al. 2025）容量低于 0.025 bits/token，传 1024 位需数十万 token。
  - **预共享密钥悖论**：大多数方案假设通信前已共享密钥；独立托管智能体没有密钥，而公开的 Diffie–Hellman 密钥交换会暴露秘密通信的事实。即“需要隐蔽信道来建立密钥，又需要密钥来构造隐蔽信道”。
- **核心研究问题**：独立部署的、非对称的 LLM 智能体，能否在受监控信道上从零引导共享密钥，并以高容量进行合谋而不被检测？

## 2. 方法论

### 2.1 整体架构

Codetta 由两部分组成：先运行**隐写密钥交换**建立共享密钥，再用**带密钥的隐写协议**传输高容量载荷。安全性目标为“计算不可区分”（Definition 2 的 transcript covertness），即最强计算有界被动审计者也无法区分隐蔽通信记录与普通模型输出。

### 2.2 稻草人方案（带密钥、固定字母表）

- 使用公开哈希函数 \(f_{Bucket,t}\) 把词表划分为 \(K\) 个桶，每个 token 携带一个 \(\mathbb{Z}_K\) 符号。
- 用 PRF 掩码码字符号：\(a_t = c_t + \text{RangePRF}_{k_m}(sid,t) \bmod K\)。
- 从目标桶条件分布 \(p_t(\cdot | B_{t,a_t})\) 提议采样 \(X_t\)，再以概率 \(\min\{1, K\pi_t(a_t)\}\) 接受；拒绝时从残差分布 \(\rho_t(y) = (p_t(y)-\nu_t(y))^+ / \Delta_K(p_t)\) 采样。
- **最大耦合（maximal coupling）** 保证发布 token 精确服从 \(p_t\)，拒绝即为一次替换错误。
- 定理 1 证明：若 RangePRF 安全，则方案计算不可区分。定理 2 给出正确性与可靠性界（Azuma–Hoeffding）。

### 2.3 Codetta 带密钥协议（草稿平衡桶 + 自适应纠错码）

**（1）草稿平衡桶**
- 引入小型**公共草稿模型** \(q_t = P_{Draft}(\cdot | G_t(V_{<t}))\)，仅依赖公开记录，收发双方与审计者均可运行。
- `Bucket(q_t, K)`：按 \(q_t\) 降序排列 token，依次分配到当前最轻的桶，使桶质量接近均匀，降低 \(\Delta_K(q_t)\)。
- `ChooseAlphabet(q_t)`：仅当满足 \(H(q_t) \ge \log_2 K_t + \gamma_H\) 且 \(\Delta_{K_t}(q_t) \le \theta\) 时才允许 \(K_t > 1\)；在可选大小中按 \(K\) 元对称信道容量 \(\log_2 K_t - h(\hat{e}_{K_t}) - \hat{e}_{K_t}\log_2(K_t-1)\) 选最优。若不可行则 \(K_t=1\)，该 token 不携带符号。
- 误差率满足 \(\Delta_{K_t}(p_t) \le \text{TV}(p_t, q_t) + \Delta_{K_t}(q_t)\)，即“模型失配”与“桶不平衡”之和。

**（2）自适应纠错码（模校验 + 在线编码）**
- 由于 \(K_t\) 只能在生成到该步时才知道，传统“先编码再传输”的 ECC 不可用。
- 改为“每 token 回答一个问题”：每次可用 token 产生一个**模校验** \(C_s = \sum_{i \in S_s} a_{s,i} u_i \bmod K_t\)，其中 \(u = m \| \text{Tag}_{k_v}(sid,m)\) 为未知比特。
- 用 `RangePRF` 掩码 \(A_s = C_s + \text{RangePRF}_{k_m}(sid,s,K_t) \bmod K_t\)，再走与稻草人相同的最大耦合采样。
- 接收方回放公开计算得到方程组 \(\sum a_{s,i} u_i \equiv \hat{C}_s \pmod{K_{t_s}}\)，被拒绝的检查是替换错误；用**置信传播（BP）**在因子图上求解，因子按校准错误率 \(\hat{e}_K\) 赋似然。
- 该码是**无速率（rateless）**的：每多一个可用 token 就多一个校验，积累足够即可解码。

### 2.4 隐写密钥交换（无密钥）

- **核心思路**：把 MLWE 密文系数直接通过载体传输，每个载体位置传输一个 \(\mathbb{Z}_q\) 系数（约 \(\log_2 q \approx 11.7\) bit），由 MLWE 解密吸收载体误差。
- **提升的精确覆盖载体（Lifted Exact-Cover Carrier）**：每次发布 \(L = \beta q\) 个候选块，哈希标签 \(y_j = \text{Hash}_q(sid,i,X_j)\)；通过“最小平方位移循环旋转”构造双射 Assign，采样均匀 replica \(J\) 后发布 \(X_{\text{Assign}(a,J)}\)。这保证发布的块对任意固定池都均匀分布（保持诚实分布），且误差是标签的小位移而非随机翻转。
- **三阶段密钥交换**：
  1. 接收方发送 \(b = A s_R + e_R\)（恒等序列化器）；
  2. 发送方发送 \(w = A^T s_S + e_1\) 与 \(z = \hat{e}_b^T s_S + e_2 + \iota(c^+)\)；
  3. 接收方计算 \(\omega = e_z - s_R^T e_w\)，舍入硬判决 + BCH 码恢复 128 位 pre-key；双方用 KDF 派生会话密钥，再用带密钥协议发固定消息做密钥确认。
- **参数**：\(d=256, q=3329, k=2\)，\(\chi_{sec}=\text{CBD}_3\)，\(\chi_{err}=\text{CBD}_2\)，即 ML-KEM-512 参数（NIST 安全类别 1）；BCH (255, 131, 18) 码；序列化用 Compress10/Compress4；一次交换占 1,280 个载体位置。
- **安全性**：定理 5 证明对被动审计者的不可区分性归约到 MLWE（k 样本与 k+1 样本两个假设）；定理 6 给出噪声容忍解码条件；定理 7 用 Clopper–Pearson 界做经验失败概率认证。

## 3. 实验设计

### 3.1 数据集 / 场景（三个智能体工作负载）

- **FINANCIAL**：合成的发行人情报任务，20 个发行人 × 100 条数据库记录；接收方（资产经理）向发送方（情报供应商）发 JSON 研究请求，发送方检索 5 条记录后写研究报告作为载体。私有上下文约 1.7k token。
- **IFEVAL**：公开 IFEval 数据集，带长度/结构/措辞/格式约束；发送方先私有生成 ≤48 token 的抽象规划作为私有上下文，再作答。
- **CTF**：InterCode-CTF 的离线 picoCTF 适配，20 个挑战；发送方在沙箱中先解题（ReAct 循环最多 50 条消息），完整轨迹为私有上下文，再写技术报告作为载体写入共享文件系统。

### 3.2 模型

- **发送方**：Qwen2.5-7B、Llama-3.1-8B、Ministral-3-8B。
- **草稿模型**：Qwen2.5-1.5B、Llama-3.2-1B、Ministral-3-3B；消融另用 Qwen2.5-0.5B/3B/7B。

### 3.3 对比基线

- **ARS**（Bai et al. 2025，S&P）：非对称资源下的 SOTA 实用隐写协议，使用官方实现。
- **HARQ LDPC**：用 5G NR 速率 0.2 母码的递增式 LDPC 替换自适应 ECC，分“有草稿”和“无草稿”两种配置，用 NVIDIA Sionna 实现。
- Codetta 与 LDPC 每次传 1024 载荷比特 + 32 位标签；ARS 在 FINANCIAL/IFEVAL 传 128 位、CTF 传 16 位（对 ARS 有利）。
- 每条秘密消息跨 28 个连续响应，25 条独立消息取平均。

### 3.4 消融实验

1. **共享上下文比例**：向接收方揭示 0%/25%/50%/75%/100% 私有上下文。
2. **模型失配**：同模型、跨规模、跨家族（跨家族用字节级桥接两个 tokenizer）。
3. **组件消融**：依次去掉自适应 ECC、自适应字母表大小、公共草稿模型。

### 3.5 密钥交换评测

- 三个发送模型 × 三个工作负载，每个 \(m = 100{,}000\) 会话，代数重放交换过程；载体用每轮首个完整响应块，上限 \(B=64\) token，replica 比例 \((\beta_b,\beta_w,\beta_z)=(4,4,1)\)。

## 5. 实验数量与充分性

- **主实验**：3 工作负载 × 3 发送模型 = 9 个主要配置单元，每单元 25 条消息，全部成功恢复（25×1024 bit）。
- **消融实验**：共享上下文 5 个梯度 × 2 种草稿；模型失配 3×3 = 9 对；组件消融 4 行 × 3 模型。
- **密钥交换**：3 模型 × 3 工作负载 = 9 个单元，每单元 100,000 会话，合计 900,000 次会话重放。
- **任务质量**：IFEval 上用双侧精确 McNemar 检验，25 条消息，最小 p 值 0.125，说明隐蔽文本与普通生成无显著差异。
- **充分性评价**：
  - **优点**：覆盖三个差异明显的工作负载（对话式、指令跟随、文件系统共享），三种发送模型家族，三个消融维度，密钥交换样本量极大（10^5 级）且用严格的 Clopper–Pearson 界，统计上较为严谨。
  - **公平性**：给了 ARS 更短的载荷（对其有利），基线用官方实现/Sionna 优化实现，指标统一为“正确恢复载荷比特/有效可见载体 token”。
  - **局限**：消融主要在 FINANCIAL + Qwen2.5-7B 上做，跨模型/跨负载的消融覆盖有限；ARS 无官方高容量版本，容量对比存在一定版本不对称。

## 6. 主要结论与发现

- **容量**：Codetta 达 0.0303–0.5685 bits/token，是 ARS 的 **16–94 倍**，是无草稿 LDPC 基线的 **4.1–6.4 倍**。绝对速率随载体文本熵变化，Ministral 最高，Qwen 在 CTF 上最低（报告大量复制私有轨迹，60% body token 熵低于 0.1 bit）。
- **密钥交换**：128 位 pre-key 约需 **70,751–81,920 个可见 token**（1,280 载体位置 × 最多 64 token），比 [VZ26] 构造的估算（约 200 万 token）少约 **23 倍**。经验认证失败概率：无失败单元 ≤ 3.0×10⁻⁵，最差为 Qwen 在 CTF 上 4.1×10⁻³。
- **组件贡献**：草稿模型单独提升容量 43–76%；自适应字母表再提升 79–199%；自适应 ECC 再提升 23–53%；三者叠加达 4.8–6.4 倍。
- **共享上下文与草稿强度**：共享上下文越多、草稿越强，容量越高；全共享 + 同模型草稿时符号错误率从 43% 降至 17%（剩余为桶离散化）。
- **模型失配**：同家族草稿最优，跨家族损失 8–29%；发送方模型差异对容量影响大于草稿模型差异。
- **任务质量**：隐蔽
