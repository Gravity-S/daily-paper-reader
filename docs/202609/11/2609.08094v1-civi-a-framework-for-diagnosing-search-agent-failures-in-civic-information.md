## 摘要
大型语言模型正越来越多地部署于公共部门场景，其中错误的指导可能造成不可逆的伤害。我们提出 CIVI，这是首个用于诊断公民信息中搜索智能体失败的框架。其基准实例同时涵盖跨国、跨辖区的政府情境（联邦、州与地方），以及源自一项国际采用的联合国标准的功能类别。我们评估了十种前沿搜索智能体，发现没有一种能达到专注的人类基线水平。除准确率外，CIVI 还测量搜索调用率、选择性不搜索准确率，以及智能体引用权威政府来源的频率。为进行这一诊断，我们提出 ARISE，它将智能体搜索失败分解为四种互斥模式，并通过源注入消融进行隔离。ARISE 将全部观测到的失败中的 72.1% 归因于检索受限原因，而非模型参数化知识的缺口。

## Abstract
Large Language Models are increasingly deployed in public-sector settings, where incorrect guidance can cause irreversible harm. We introduce CIVI, the first framework for diagnosing search agent failures in civic information. Its benchmark instantiation jointly spans cross-national, interjurisdictional government contexts (federal, state, and local) and functional categories from an internationally adopted United Nations standard. We evaluate ten frontier search agents and find that none matches an attentive human baseline. Alongside accuracy, CIVI measures search invocation rate, selective no-search accuracy, and how often agents cite authoritative government sources. To perform this diagnosis, we introduce ARISE, which decomposes agentic search failures into four mutually exclusive modes, isolated via source-injection ablation. ARISE attributes 72.1% of all observed failures to retrieval-bound causes rather than to gaps in the models' parametric knowledge.

## 2. 方法论：核心思想与关键技术细节

### 2.1 CIVI 基准构建

- **三轴分层设计**：4 个 COFOG 政府功能（公共秩序与安全、经济事务、卫生、社会保障）× 3 个国家（加拿大、美国、澳大利亚）× 3 个司法层级（联邦、州/省、地方）= **36 个分层单元**。
- **来源页精选**：3 名具有公共部门经验的领域专家逐单元筛选，仅保留官方政府域名或政府资助公共部门域名的页面，剔除导航页与限制 AI 使用的页面。每单元目标 16 页，最终形成 **576 个来源页**。
- **问题生成**：使用 Claude Opus 4.6（温度 0）生成多选题（8 选项、多选），每条问题满足四项标准：
  - *来源可推导性*：可由单一来源页直接回答；
  - *具体后果*：涉及资格、截止日期、费用、流程等对居民有实际后果的信息；
  - *辖区精确性*：仅对应一个特定辖区，答案唯一；
  - *来源归因*：附带逐字引用作为答案依据。
- **干扰项设计**：两类来源——对页面内容进行受控扰动（改阈值、翻转条件、改截止日期、替换实体、重排步骤）与常见误解；去重以保证每个干扰项测试不同误解。
- **人工验证**：2 名公共部门 AI 领域研究者独立审阅全部 4,354 条生成问答，原始一致率 **96.8%**，双人接受率 **94.1%**，最终保留 **4,097 条问答对**。

### 2.2 评估协议与指标

- **智能体搜索条件**：所有模型通过 Exa 统一搜索基座，最多 3 轮搜索、每轮不限查询数、总共最多检索 10 个 URL。
- **四个指标**：
  - **Accuracy**：精确集合匹配（顺序无关、大小写不敏感），必须完全选中正确选项集。
  - **Search invocation rate**：至少调用一次搜索的问题比例，并按辖区层级分层报告。
  - **Selective No-Search Accuracy**：模型选择不搜索的问题中的正确率；并定义 **Δskip** = 选择性不搜索准确率 − 关闭搜索时的全基准准确率，用于跨模型比较搜索策略校准。
  - **Authoritative Hit Rate (meanAHR)**：按辖区层级定义权威域名集合（联邦问题仅限联邦域名；州问题允许州+联邦；地方问题允许地方+母州+联邦），计算每题引用 URL 中权威来源比例，再对引用至少一个 URL 的问题求均值，并用 1000 次非参数 bootstrap 给出 95% CI。

### 2.3 ARISE 失败诊断

- **核心思想**：结合**源注入消融**（source-injection ablation）与**搜索轨迹分析**，将每个错误回答确定性地归入四类互斥且穷尽的失败模式。
- **两步流程**：
  - **Step 1 源注入**：关闭搜索，将金标准来源页作为额外上下文提供给模型重跑。若仍答错 → 归为 **Comprehension failure（理解失败）**。
  - **Step 2 轨迹分析**：对源注入后答对的问题，检查原始智能体搜索轨迹：
    - 轨迹显示未调用搜索 → **Search bypass（搜索绕过）**；
    - 调用了搜索但未检索到金标准 URL → **Retrieval failure（检索失败）**；
    - 检索到金标准 URL 但仍答错 → **Grounding failure（接地失败）**。
- **诊断含义**：四种模式指向不同干预目标——搜索触发/意图路由、查询改写/权威源索引、答案-证据一致性检查、推理支持或人工升级。

## 6. 主要结论与发现

- **无模型达到人类基线**：最强模型 Gemini 3.1 Pro 全基准 78.28%（95% CI ±1.3 pp），低于人类基线 **14.4 pp**；在 150 题匹配子集上差距为 **15.3 pp**。
- **准确率随辖区层级下降而单调下降**：联邦 65.6% → 州/省 62.6% → 地方 56.7%，联邦-地方差距 **8.9 pp**。
- **模型间差距在低层级扩大**：联邦层级模型差距 26.4 pp，州 34.9 pp，地方 38.1 pp。
- **跨辖区鲁棒性差异巨大**：GPT-5.4 在地方层级反而提升 1.9 pp，而 Claude Haiku 4.5 下降 22.5 pp；GPT 家族整体平稳（均 <5 pp）。
- **跨国差异小于跨辖区差异**：美国 63.4%、澳大利亚 62.0%、加拿大 59.1%，国家间差距仅 4.3 pp。
- **搜索行为差异极大**：搜索调用率从 13.5%（Gemini 3 Flash）到 ≥99%（DeepSeek V3.2、Claude 系列），跨度 86 pp；搜索调用率随辖区层级下降而上升（联邦-地方差距 23.4–62.0

pp）。
- **搜索决策校准与准确率强相关**：Δskip 越正（即模型选择跳过搜索的问题确实更容易），选择性不搜索准确率越高；表现最好的模型在"选择不搜索"的问题上准确率显著高于其关闭搜索时的全基准准确率，说明其具备一定的"何时该查"的元认知判断力；而部分模型 Δskip 接近 0 甚至为负，表明其搜索触发与问题难度不匹配，存在无效检索与无效跳过并存的双向浪费。
- **权威接地率（meanAHR）整体偏低且分化明显**：各模型在引用来源中命中权威域名的平均比例与准确率呈正相关，但多数模型 meanAHR 未超过 0.7，意味着相当比例的引用来自非权威或次级来源；按辖区层级看，地方层级的 meanAHR 最低，与其准确率最低相互印证，暗示"找不到地方权威源"是地方失败的重要中介。
- **meanAHR 与外部排名的相关性有限**：meanAHR 与 LMArena Elo 的相关性为弱到中等正相关，说明通用对话能力排名并不能可靠预测政务场景下的权威接地行为；模型家族内部一致性高于跨家族一致性，提示训练数据与检索策略的后处理选择对权威引用倾向影响更大。
- **ARISE 失败模式分布**：在全部错误回答中，**检索失败占比最高**，其次为**接地失败**，再次为**理解失败**，**搜索绕过**占比最小但并非可忽略。这意味着多数失败并非模型"读不懂"官方文本，而是"没找到"或"找到了却没用好"，指向检索层与证据一致性校验层是主要瓶颈。
- **失败模式随辖区层级迁移**：联邦层级的错误更多归因于理解失败与接地失败，地方层级则显著更多归因于检索失败与搜索绕过；这与地方源分散、索引覆盖差、命名不统一的现实一致。
- **单次检索 RAG 与智能体搜索的差距**：智能体搜索在多轮查询改写与检索预算上优于单次检索 RAG，但在部分模型上差距有限，说明收益主要来自少数需要多次迭代的复杂问题；对简单问题，多轮检索带来的额外噪声可能抵消收益。
- **人类基线并非不可逾越但差距稳定**：人类在地方层级同样表现下降，但降幅远小于模型，且人类更倾向于直接访问官方页面而非依赖搜索引擎摘要，这解释了人类在高权威接地要求下的优势。

## 7. 讨论：失败根源、干预含义与局限

- **核心论断**：当前前沿 LLM 在公民信息场景的主要短板不是语言理解，而是**权威信息获取与证据使用链条的工程化可靠性**。CIVI 的价值在于把"总体准确率"这一单一数字拆解为可定位、可干预的四类失败。
- **干预映射**：
  - *搜索绕过* → 改进搜索触发策略与意图路由，对高后果问题（资格、截止日期、费用）强制检索；
  - *检索失败* → 增强权威源索引覆盖（尤其地方层级）、查询改写与多语言/多命名变体扩展；
  - *接地失败* → 引入答案-证据一致性检查、引用强制对齐、冲突来源仲裁；
  - *理解失败* → 提供结构化推理支持、表格与条件逻辑解析、必要时人工升级。
- **对公共部门部署的建议**：不应仅以通用基准或供应商宣称的能力选型；应要求披露辖区分层准确率、搜索调用行为与权威接地率；对地方层级问题设置更高的人工复核阈值；对无法给出权威引用的回答应默认弃答而非生成。
- **伦理与社会影响**：错误政务信息可能剥夺合法福利、导致违规或延误，危害对低数字素养与语言少数群体尤甚；因此"拒答 + 转人工"在低置信情形下比"自信作答"更符合公共利益。
- **论文自身局限**：
  - 仅覆盖 3 个英语国家、4 个 COFOG 功能，未涉及非英语辖区、多语言公民与更多政策领域；
  - 模型与搜索基座版本具时效性，结论不宜外推为长期规律；
  - 权威域名集合由人工按层级定义，边界情形（如政府资助但独立运营的机构）可能引入主观性；
  - 人类基线样本小、非随机、无报酬，代表性有限；
  - ARISE 的源注入假设"金标准页足以回答"，对需要跨页综合的问题可能高估理解失败；
  - 多选题格式虽便于自动评分，但与真实公民开放式提问存在生态效度差距。

## 8. 对后续研究的启示与可复用资产

- **可复用资产**：576 个来源页、4,097 条专家验证问答、分层单元划分、干扰项构造方法、ARISE 诊断流程与 meanAHR/Δskip 指标定义，均可作为后续政务 AI 评估的标准组件。
- **扩展方向**：
  - 纳入非英语国家与多语言公民场景；
  - 引入开放式生成评估与真实用户研究，检验多选题结论的生态效度；
  - 将 ARISE 从"诊断"推进到"训练信号"，例如用失败类型做定向微调或检索器重排；
  - 研究检索预算、轮次与准确率的边际收益曲线，为部署成本提供依据；
  - 探索"弃答—转人工"策略的最优阈值与用户体验影响。

## 9. 总体评价

- **贡献层面**：CIVI 首次把公民信息搜索智能体的评估从"单国单辖区 + 单一准确率"推进到"跨国×跨辖区×跨功能 + 失败模式诊断"，其分层设计与 ARISE 归因方法具有较强的可迁移性。
- **方法层面**：源注入消融与轨迹分析的组合简洁且确定性高，避免了仅凭行为观察推断失败原因的模糊性；meanAHR 与 Δskip 提供了准确率之外的两个互补维度（权威接地与搜索决策校准）。
- **实证层面**：10 个前沿模型、统一搜索基座、三次稳定性运行、双人人工验证，实验规模与受控程度在同类工作中属较高水平。
- **主要不足**：地理与语言覆盖有限；人类基线薄弱；部分模型搜索调用率饱和导致关键指标缺失；模型版本时效性强，长期结论需谨慎。
- **一句话结论**：CIVI 表明，公民信息场景的可靠 AI 并非"更会答题"的问题，而是"能否稳定找到权威来源并忠实使用它"的问题；当前最强模型距人类仍有约 15 pp 的差距，且失败集中在检索与接地环节，这为公共部门选型、监管要求与后续研究指明了明确的优先方向。
