## 摘要
从被动基础模型向自主、目标导向的智能体AI系统的转变，通过耦合递归认知推理循环、持久记忆架构、实时工具执行平面和多智能体协作拓扑，带来了前所未有的能力。然而，将执行权限授予概率性神经核心并使其横跨文件系统、网络和云基础设施，消解了经典安全边界：自然语言同时充当输入数据、内部控制代码和通信协议，暴露出一个图灵完备的影响范围，其中不可信数据即代表可执行指令。本综述为可信智能体AI提供了一个全面的系统安全参考框架，综合了206项基础研究与监管标准。我们将通用智能体架构形式化为有状态五元组，并建立了一个涵盖安全性、安全、隐私、可解释性、公平性和问责性的六维可信性分类体系。我们系统分析了执行内循环与交互平面中的威胁面，提出了一个多层零信任纵深防御架构，集成了双LLM隔离、基于能力的访问控制、内核eBPF探针和沙箱化运行时，回顾了标准化评估基准，并将技术控制措施映射到国际AI治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

### 2.1 总体方法论
- 采用 **PRISMA-S 系统性文献综述协议**，检索 IEEE Xplore、ACM DL、USENIX、NDSS、IEEE S&P、NeurIPS、ICML、ICLR、ACL、arXiv 等，最终形成 **206 篇已验证基础文献** 的语料。
- 布尔检索式：`Q = (Agentic AI ∨ LLM Agent ∨ Autonomous Agent) ∧ (Trustworthy ∨ Security ∨ Prompt Injection ∨ Zero-Trust ∨ Memory Poisoning ∨ Byzantine Consensus)`。
- 围绕五个研究问题（RQ1–RQ5）组织：系统形式化、六维可信分类、全谱威胁建模、零信任防御工程、实证评测与监管合规。

### 2.2 系统形式化：有状态五元组 + 对抗 POMDP
- 将通用智能体形式化为离散时间**有状态五元组**：
  - `A = ⟨C, M, T, E, Π⟩`
  - `C`：认知推理核心（基础模型权重 θ）
  - `M = {M_work, M_episodic, M_semantic}`：层级记忆子系统
  - `T = {t1, t2, ..., tk}`：工具与动作平面，每个工具 `tj = ⟨Schema_j, Exec_j, Perm_j⟩`
  - `E`：外部运行环境（文件系统、网络、数据库、云 API、人类操作员、同伴智能体）
  - `Π`：智能体执行策略/编排协议
- 在部分可观测马尔可夫决策过程（POMDP）`⟨S, A_act, T_trans, R, Ω, O, γ⟩` 下建模执行。
- **信念状态贝叶斯更新**：智能体维护 `b_t(s) = Pr(s_t = s | H_t)`，执行动作并收到观测后按递归贝叶斯公式更新 `b_{t+1}(s′)`。
- **对抗信念散度**：攻击者通过污染观测似然 `O(o_adv | s′, a_t)`，使 `D_KL(b_true || b_adv) ≫ 0`，从而让策略在模型内部仍“自信”的情况下执行越权工具动作。
- 提出“**系统边界崩塌原则**”：自然语言同时是数据、控制逻辑与进程间通信。

### 2.3 认知推理与记忆、工具、多智能体架构
- **推理范式**：CoT（开环）、ReAct（推理-行动交错闭环）、ToT/GoT/LATS（搜索式规划，BFS/DFS/MCTS + 启发式评估 `V(v)`）、Reflexion/Self-Refine（语言化自我批判 + 情节记忆）、具身规划（VOYAGER、SayCan、DEPS）。
- **记忆子系统**：
  - 工作记忆（注意力上下文，存在“lost in the middle”退化风险）
  - 情节向量记忆（HNSW/FAISS 索引，top-k 余弦相似检索）
  - 语义/程序记忆（参数知识 + 知识图谱）；MemGPT 式虚拟上下文分页。
- **工具平面**：结构化函数调用 + JSON Schema 校验；**Model Context Protocol（MCP）** 基于 JSON-RPC 2.0，提供 Prompts/Resources/Tools 三类原语，支持 stdio 本地管道与 HTTP+SSE 远程传输；运行时隔离包括容器命名空间、无头浏览器、Firecracker/gVisor 微虚拟机。
- **多智能体拓扑**：层级编排（MetaGPT、AutoGen）、点对点通信网格（CAMEL、AgentVerse、DyLAN）、共享黑板/辩论共识（ChatDev、Generative Agents、多智能体辩论）。

### 2.4 六维可信性分类体系
- **Security（CIA）**：机密性（系统提示与密钥防泄漏，`Adv_leak_A(λ) ≤ negl(λ)`）、完整性（规划与工具调用不可篡改）、可用性（防 sponge 样例、递归循环、工具死锁）。
- **Safety & Operational Robustness**：有界动作包络与可逆性（不可逆动作需人类授权 `Exec(a_t) ⇔ Authorized_human(a_t)=True`）、工具幻觉抑制、OOD 环境鲁棒性。
- **Privacy & Data Protection**：零泄漏工具调度、嵌入反演抵抗、多租户上下文卫生。
- **Explainability & Verifiability**：动作链审计可追溯、神经符号 SMT 验证（Z3、CVC5）、推理链忠实性（因果中介分析）。
- **Fairness & Non-Discrimination**：工具调度公平、多智能体市场反合谋。
- **Accountability & Provenance**：W3C DID 签名、Merkle 审计树、不可否认性。
- **跨维 Pareto 权衡**：安全-延迟、隐私-任务效用、安全严谨性-创造性自主。

### 2.5 全谱威胁建模（双平面）
- **执行内平面（Intra-Execution）**：
  - 感知层：直接提示注入、目标劫持、提示/密钥泄漏、GCG 对抗后缀、AutoDAN、PAIR/TAP 黑盒红队、多模态隐写与视觉越狱。
  - 大脑层：潜伏后门/Sleeper Agents、BadChain 思维链后门、幻觉雪球效应、线性 vs 搜索式规划的错误放大路径。
  - 动作层：shell 参数注入导致 RCE、混淆代理（Confused Deputy）权限滥用、SSRF 窃取云 IMDS 凭证、MCP 供应链风险（工具抢注）、sponge 样例 DoS。
- **交互平面（Interaction）**：
  - 环境交互：间接提示注入（IPI）、Markdown 渲染零点击外泄、云元数据 SSRF、上下文轰炸、具身传感器欺骗。
  - 记忆交互：RAG/向量库投毒（PoisonedRAG 少于 5 篇文档即可 >90% top-1 劫持）、嵌入反演（可重建 >70% 原始私密文本）、跨会话上下文泄漏、分布式记忆异步不一致。
  - 智能体间：级联错误放大（多智能体流水线失败率 >65%）、Morris II 自复制生成式蠕虫、Agent Smith 单图感染百万智能体、拜占庭共识颠覆（f ≥ n/3）、Sybil 渗透与策略性欺骗。

### 2.6 四层零信任纵深防御架构
- **Layer 1：认知护栏**
  - **Dual-LLM Inspector-Executor 隔离**：无特权 Inspector 只解析外部数据并输出结构化 JSON，特权 Executor 仅接收经系统提示包裹的已验证实体。
  - **Tokenizer 级指令-数据注意力掩码**：在注意力矩阵中禁止数据 token 影响指令 token 查询。
  - 运行时语义护栏：NeMo Guardrails、Llama Guard、SmoothLLM、LLM Self-Defense、Constitutional AI。
- **Layer 2：记忆完整性与密码学溯源**
  - 签名向量嵌入：`Σ = Sign_sk_authority(H(d) || E(d) || Timestamp || AuthorID)`，检索前验签。
  - Merkle 审计树：`Root_t = H(Root_{t-1} || H(th_t || a_t || o_t))`。
  - 差分隐私噪声注入：`Ẽ(d) = E(d) + N(0, σ²I)`，抵抗嵌入反演与成员推断。
- **Layer 3：系统沙箱与最小权限执行**
  - **CapBAC**：`CapToken = ⟨AgentID, ToolURI, Scope, Expiry, Sign_sk_auth⟩`，短 TTL（<60s），逐次工具调用授权。
  - Firecracker/gVisor 微虚拟机、WebAssembly 插件沙箱。
  - 内核 **eBPF** 探针实时监控 `execve`、`connect`、`openat`，终止越权进程树。
- **Layer 4：多智能体零信任协议**
  - W3C DID + 可验证凭证 + mTLS（TLS 1.3）。
  - PBFT 共识：`n ≥ 3f + 1`，阈值签名。
  - 群体熔断器与自动隔离，防止蠕虫与级联幻觉扩散。
- **硬件辅助机密计算**：Intel SGX、AMD SEV-SNP、ARM TrustZone、NVIDIA 机密 GPU，保护模型权重、上下文与密钥。
- **防御开销对比矩阵**：Dual-LLM 延迟 +1.5–3.0s、token 成本 2.0×；注意力掩码 <5ms 但仅白盒；签名向量 <10ms；DP 零延迟但降低检索精度；CapBAC <2ms；微 VM 35–50ms；eBPF <0.5ms 但仅 Linux；PBFT 高（O(n²)）且 token 成本 n×；TEE 2–8% 开销。
