## 摘要
递归LLM智能体可以通过生成专家来拓宽搜索范围。某些分支后来会请求发送数据或部署代码的工具。分支何时应获得行动的权限？我们区分沙盒生成（外部控制防止特定伤害）与能力激活（所选分支跨越不可逆行动边界）。渐进风险归属（PRV）将轨迹级风险预算置于托管中，并在分支激活时予以扣除。我们证明了自适应生成树的任意时间伤害界限。分支结果可能相互依赖，但每个局部证书需要在完整激活前历史（包括用于选择请求的信息）条件下保持有效。当激活门控、分支费用和计算约束固定时，延迟归属保留了不可撤销生成收费下可用的每个策略。边际风险估计在分支选择后仍可能失败。在一个风格化的分支模型中，当权威再生数 $\mathcal{R}_A$ 跨越1时，轨迹伤害发生变化。随着局部风险 $p$ 趋近于零，轨迹伤害在临界性以下与 $p$ 成比例，在临界性时与 $\sqrt{p}$ 成比例，而在其之上保持正下限。一个有限类型占据模型产生风险和计算的影子价格。对于边际价值随单位风险递减的嵌套扇出模式，这些价格产生阈值规则。分支计算和分裂样本实验说明了结果。这些综合研究并不估计部署智能体的安全性。分析提出了一条设计规则：在沙盒中广泛搜索，并谨慎地授予递归权限，且明确收取风险费用。

## Abstract
Recursive LLM agents can broaden their search by spawning specialists. Some branches later request tools that send data or deploy code. When should a branch receive authority to act? We distinguish sandbox spawning, in which external controls prevent the specified harm, from capability activation, in which a selected branch crosses an irreversible-action boundary. Progressive Risk Vesting (PRV) holds a trajectory-level risk budget in escrow and debits it as branches are activated. We prove an anytime harm bound for adaptively generated trees. Branch outcomes may be dependent, but each local certificate needs to remain valid conditional on the full pre-activation history, including the information used to select the request. When activation gates, branch charges, and compute constraints are held fixed, delayed vesting preserves every policy available under irrevocable spawn charging. Marginal risk estimates can still fail after branch selection. In a stylized branching model, trajectory harm changes as the authority reproduction number $\mathcal{R}_A$ crosses one. As local risk $p$ approaches zero, trajectory harm is proportional to $p$ below criticality, proportional to $\sqrt{p}$ at criticality, and retains a positive floor above it. A finite-type occupancy model yields risk and compute shadow prices. For nested fanout modes with decreasing marginal value per unit risk, these prices produce a threshold rule. Branching calculations and a split-sample experiment illustrate the results. These synthetic studies do not estimate safety in deployed agents. The analysis suggests a design rule: search broadly in the sandbox and grant recursive authority sparingly, with an explicit risk charge.

## 1. 核心问题与研究背景
递归式 LLM 智能体可通过不断生成子智能体（spawning）来拓宽搜索：根问题被逐层分解后，由多个专门化的“分支”并行探索、诊断并返回候选方案，如代码修复、深度搜索等场景。然而分支可能在探索中请求权限、读取敏感数据或执行部署等不可逆动作，一旦某分支被授予超越“沙盒”的能力，便为提示注入或工具故障提供了通向真实世界伤害的通道。

论文的核心问题是：当智能体树的生成与控制均具有自适应性和开放性时，如何在广泛探索（broad recursive search）与受控不可逆授权（controlled irreversible authority）之间取得平衡？也就是说，何时才应授予一个分支不可逆行动的权限，以及如何从整条探索轨迹的维度分配风险预算。

作者将上述问题提炼为“沙盒生成”（spawning in the sandbox，仅消耗计算资源）与“能力激活”（capability activation，授予会影响真实环境的不可逆权限）这两类动作的本质区分，并通过引入渐进风险归属（Progressive Risk Vesting, PRV）框架给出安全的授权纪律。

## 2. 方法论：渐进风险归属
### 2.1 核心思想
PRV 把“生成子节点”和“授予不可逆权限”分开处理：所有分支在受强制隔离的沙盒中自由生成、探索、提交候选动作；仅在某个分支被选中并跨越不可逆行动边界时，才从根部共享的风险托管账户中借记一笔概率风险额度。未激活即被丢弃的分支只消耗算力，不消耗灾难概率预算。

### 2.2 关键技术细节与保障
- **风险托管账户**：根节点持有总风险预算 δ（∈(0,1)），所有已批准分支的分次风险额度之和在任何时刻不超过 δ。
- **条件性证书**：每次激活前，系统须验证条件概率 P(灾害事件 | 完整激活前历史) ≤ aᵢ（即第3节式(1)）。该历史包含智能体树生成过程、请求内容、已有信息和“被选中”这一筛选动作本身；因此证书必须对分支选择后的“筛选”敏感，防止校准失效。
- **任意时间保证（定理1）**：即使智能体树的拓扑自适应生成、分支结果相互依赖，只要每个本地证书在完整历史条件下有效且总预算受限，则整个轨迹发生任意指定灾难的概率仍被 δ 控制。证明利用 Boole 不等式、塔性质与单调收敛定理。
- **延迟授予的价值（命题1）**：当沙盒形状、激活门控、计算约束以及各分支的风险费率都固定时，延迟授予覆盖了生成时即扣费（spawn charging）的全体可行策略；由于只有被选中的分支才从风险总预算中扣费，系统的预期效用不会更差。
- **权威再生相变（定理2）**：权威授代树可用分支过程刻画，权威再生数 R_A=平均沙盒后代数 m × 获得授权的概率 s 是关键序参量。在极限 p ↓ 0 时：
  - R_A < 1：轨迹总危害 ~ p/(1-R_A)（线性）；
  - R_A = 1：轨迹总危害 ~ √(2p/β)（平方根律）；
  - R_A > 1：轨迹总危害衰减到“非灭绝”幸存树的正下限（即危害概率有不可再降的噪声层）。
- **影子价格与阈值规则（定理3）**：对有限类型动态规划，构造占据测度线性规划，解出风险预算和算力预算的影子价格 λ、ν。若存在嵌套扇出模式且“每单位风险边际价值递减”，则最优扇出数服从门限规则（risk-filtered base-stock policy）。

### 2.3 治理器实现（Algorithm 1）
流程：根节点以沙盒权限启动 → 对每个激活请求按原子顺序登记 → 先执行确定性规则拒绝或要求人工收窄 → 否则计算选择条件证书 aᵢ → 若超出当前谱系未被占用的托管余额则拒绝，否则原子性地借记 aᵢ 并授权一次执行；重试需重新作为新的门禁请求进入，一次授权仅针对固定动作与参数范围。

## 6. 主要结论与发现
- 递归智能体系统应把“探索生成”和“授权执行”分开——搜索可以广泛进行，但对不可逆权威的授予应保持谨慎。
- 治理器应在每次批准跨边界动作前借记风险预算（PRV）；只要各分支证书在“全套历史+选择信息”的意义上有效，托管机制就能限制整条轨迹的灾难概率，且不受拓扑结构和分支间依赖关系限制。
- 延迟授予可缓解提前扣费造成的虚假探索成本，且保障“不影响任何已有可行策略”。
- 权威再生率 R_A=1 是危险相变点。若 R_A ≥ 1，仅靠把局部单次伤害 p 做小无法把总伤害压到可忽略水平（临界时只能做到平方根级，R_A>1 时则存在非零下限）。
- 有效设计参数不应只看总体平均候选数 m，而应是 m × s（即能继续拥有授权资格的真实子链期望数）；通过影子价格可以动态控制不同分支类型的展开数。
