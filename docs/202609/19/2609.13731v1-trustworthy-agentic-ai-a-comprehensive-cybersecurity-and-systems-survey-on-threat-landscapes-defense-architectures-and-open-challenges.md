## 摘要
从被动基础模型向自主、目标导向的智能体AI系统的转变，通过耦合递归认知推理循环、持久记忆架构、实时工具执行平面和多智能体协作拓扑，带来了前所未有的能力。然而，将概率神经核心的执行权限授予文件系统、网络和云基础设施，消解了经典安全边界：自然语言同时充当输入数据、内部控制代码和通信协议，暴露出图灵完备的影响范围，其中不可信数据即代表可执行指令。本综述为可信智能体AI提供了一个全面的系统安全参考框架，综合了206项基础研究与监管标准。我们将通用智能体架构形式化为有状态5元组，并建立涵盖安全（security）、安全（safety）、隐私、可解释性、公平性和问责性的6维可信性分类体系。我们系统分析了执行内循环与交互平面中的威胁面，提出了一个多层零信任纵深防御架构，集成双LLM隔离、基于能力的访问控制、内核eBPF探针和沙箱化运行时，综述了标准化评估基准，并将技术控制映射到国际AI治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

### 2.1 核心思想
- 将智能体系统形式化为**有状态离散时间5元组**，并在**对抗性POMDP**框架下刻画闭环执行动力学，进而建立**6维可信性分类体系**，系统剖析**双平面威胁面**，最终提出**多层零信任纵深防御架构**，并将技术控制映射到国际治理框架。

### 2.2 形式化系统模型
- **5元组**：`A = ⟨C, M, T, E, Π⟩`
  - `C`：认知推理核心（基础模型权重θ，如GPT-4、Gemini、LLaMA 3、Mistral、Claude 3）。
  - `M = {M_work, M_episodic, M_semantic}`：分层记忆子系统（工作上下文、稠密向量情节记忆、语义/参数知识）。
  - `T = {t_1,...,t_k}`：工具与动作平面，每个 `t_j = ⟨Schema_j, Exec_j, Perm_j⟩`。
  - `E`：外部运行环境（文件系统、网络套接字、数据库、云API、人类操作员、同伴智能体）。
  - `Π`：智能体执行策略/编排协议。
- **POMDP 7元组**：`⟨S, A_act, T_trans, R, Ω, O, γ⟩`，智能体维护信念状态 `b_t(s)=Pr(s_t=s|H_t)`，通过递归贝叶斯更新（式5）演化，策略 `Π*(a_t|b_t)` 最大化期望折扣回报（式6）。
- **对抗性信念发散**：攻击者通过污染观测似然 `O(o_adv|s',a_t)`，使 `D_KL(b_true || b_adv) ≫ 0`，从而在模型内部保持高置信度的同时，将策略导向灾难性、未授权或违反策略的工具动作（式7）。
- **认知推理范式**：线性/交错推理（CoT、ReAct，式8–10）；搜索式审慎规划（ToT、GoT、LATS，将思维序列泛化为搜索图G=(V,E)，用BFS/DFS/MCTS及启发式评分V(v)）；言语强化学习与情节自纠正（Reflexion、Self-Refine）。
- **记忆检索**：情节记忆经神经嵌入投影至 `R^d`，用HNSW/FAISS索引，top-k余弦相似度检索（式11）；MemGPT式虚拟上下文分页。
- **工具集成**：结构化函数调用与JSON Schema校验；**MCP（Model Context Protocol）**基于JSON-RPC 2.0，提供Prompts/Resources/Tools三原语，支持stdio与HTTP+SSE两种传输；分布式集群执行采用容器命名空间、无头浏览器、微虚拟机（Firecracker、gVisor）等隔离。
- **多智能体拓扑**：层级编排（MetaGPT、AutoGen）、点对点通信网格（CAMEL、AgentVerse、DyLAN）、共享黑板群体与博弈论共识（ChatDev、Generative Agents、多智能体辩论）。

## 六、论文的主要结论与发现

- **核心结论**：授予概率神经引擎跨物理与数字环境的自主执行权限，彻底打破了经典安全边界。自然语言同时作为用户界面、内部控制代码、数据格式和智能体间通信协议，形成**图灵完备的影响半径**——任何不可信外部输入都代表未编译的可执行代码。
- **威胁结论**：智能体威胁同时存在于**执行内平面**（感知、大脑、动作）与**交互平面**（环境、记忆、多智能体群体），涵盖直接/间接提示注入、对抗后缀、多模态隐写、潜伏后门、BadChain、幻觉级联、工具参数RCE、SSRF、混淆代理、MCP供应链、RAG向量投毒、嵌入反演、Morris II蠕虫、拜占庭颠覆、Sybil渗透等。
- **防御结论**：不能依赖表层提示过滤或启发式护栏；必须建立**智能体系统安全（Agentic Systems Security）**这一融合学科，将基础模型的自适应认知能力与经典系统安全的数学严谨性、硬件隔离、密码学完整性和零信任原则相结合。四层防御（认知护栏、记忆完整性、系统沙箱与最小权限、多智能体零信任协议）+ 硬件TEE构成可行蓝图。
- **治理结论**：技术控制可映射到NIST AI RMF、EU AI Act、ISO/IEC 42001等国际框架；Merkle审计树满足可追溯性，CapBAC与微虚拟机满足最小权限，自动化红队满足持续风险管理。
- **开放挑战结论**（六大方向）：
  1. 神经符号动作链的形式化验证（语义到符号的保真瓶颈、状态空间爆炸，PSPACE完全性）。
  2. 终身动态对齐与不可逆副作用困境（上下文内对齐漂移、灾难性遗忘、需影子执行与可验证记忆清洗

2. 终身动态对齐与不可逆副作用困境（上下文内对齐漂移、灾难性遗忘、需影子执行与可验证记忆清洗机制），以及在不中断服务前提下实现模型热更新与策略回滚的工程挑战。
3. 多智能体零信任的可扩展性与去中心化信任锚定：PBFT共识的O(n²)通信开销在大规模群体中难以承受；Sybil抵抗、跨组织DID互操作、群体熔断器的误报/漏报平衡均缺乏成熟方案。
4. 多模态与物理世界感知的攻击面收敛：视觉隐写、传感器欺骗、具身智能体的物理副作用、跨模态注入检测等，要求安全机制从文本域扩展到连续感知空间。
5. 隐私增强技术与任务效用的帕累托前沿优化：差分隐私噪声对top-k检索精度的损害、TEE的侧信道与性能开销、联邦记忆共享中的梯度泄露，均需更精细的权衡设计。
6. 标准化评估、可复现性与治理落地：当前基准（如InjecAgent、AgentBench）覆盖有限，动态威胁演化下需持续红队与自动化审计；监管合规的自动化映射与跨司法辖区互认仍是空白。

综上所述，本文系统性地将智能体AI安全从零散的提示注入研究提升为涵盖认知、记忆、执行、通信与治理的融合学科，其四层零信任架构与量化指标体系为后续研究提供了可操作的参考基线。然而，该框架的实证有效性、跨平台通用性及长期演化安全性仍需学术界与工业界协同验证。
